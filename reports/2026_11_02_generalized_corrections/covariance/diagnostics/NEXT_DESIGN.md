# Parsimonious next calibration and validation design

ALGO07 remains the production default. If B improves some scans and harms others, use the numerical repair A as an experimental comparator pending its measured benefit. The next uncertainty experiment should reduce the age mismatch and test one shrinkage strength toward the incumbent covariance. It should not add orbital modes or use scan RF residuals to choose a family-specific uncertainty width.

## Separate the three explanations first

**Mean orbit discrepancy:** the present uncentered second moment contains both spread and squared mean displacement: `E[a a^T] = Cov(a) + E[a] E[a]^T`. A persistent signed catalog difference can therefore inflate B even when it resembles a bias. Catalog revisions are not truth, and three to six correlated versions do not justify fitting a per-satellite mean correction. Keep the zero mean unless a pre-scan forecast of signed innovations predicts disjoint historical updates. Any eventual mean experiment must be separate from the variance experiment, using the existing physical coordinates and the same phase treatment.

**Variance discrepancy:** historical elements are propagated longer than the nominal element. The diagnostic shows within-context age dependence, but does not explain the cross-family cap count by age alone. Build the next variance proxy from **pre-scan historical prediction revisions with forecast horizons matched to the current nominal age**, rather than from every old element propagated to the current scan. For example, compare an older element propagated to a later historical element's epoch when their epoch separation matches that nominal horizon. Both elements and their collection receipts must already exist before the scan cutoff. Propagate both to the same epoch, remove orbital phase and use the same three physical directions. These remain revision proxies, not measured orbit errors.

Use one shrinkage strength to mix that age-matched expansion with the incumbent covariance floor, retaining zero mean, proper Gaussian normalization and explicit support fallbacks. Freeze its admissible range and archive-only selection rule before RF evaluation. Do not learn a new width for each scan or tune it using geographic outcomes. Insufficient age-matched support should return the incumbent prior.

**Phase or receiver degeneracy:** a family correction that trades against phase or receiver calibration is not an orbit estimate. Retain the existing phase coordinate; do not introduce another along-track timing parameter. Require other families to identify the receiver terms and support the proposed positional movement. Disagreement shared across families on one receiver/band warrants a separate receiver-model diagnosis. An unresolved direction warrants fallback, even if broader covariance improves the full-data RF score. Target-excluded evidence must be assessed with all relevant nuisance terms reestimated.

## Validation that can reject the idea

1. Freeze archive receipts, age-matching tolerances, support rules, three-mode projection, shrinkage selection, observations, identities, starts and budgets before examining new endpoints. Every evaluated scan uses only evidence available before its own start. Hyperparameters for an untouched evaluation set must be frozen from archive evidence available before that set's earliest cutoff; archive revisions acquired later cannot calibrate earlier scans.
2. Validate the archive proxy using randomized whole update/forecast groups, keeping reused TLE transitions together and accounting for repeated satellites. This tests prediction of another revision, not prediction of orbit truth. Report signed-innovation prediction separately from variance-density prediction; include normalization and an unchanged-prior control. If grouping leaves too few disjoint cases, report insufficient support.
3. Evaluate RF performance on whole recordings unused for development, with synchronized observations and aliases kept together. Use reproducible randomized recording/session groups for retrospective checks. Reserve subsequently available, untouched on-disk scans as an additional prospective check; do not replace randomized validation with a chronological split or initiate collection.
4. Compare A, the frozen B and the age-matched candidate under matched c=0/fitted-c arms. Report phase closure, physical/ownership checks, held-group frequency density, target-excluded information, runtime, fallbacks and all recording denominators. Seal decisions before geographic evaluation. Geographic error, tails and regressions are a separate report, never a selection rule.

Do not assume a stable error distribution across satellites, receiver sessions or catalog regimes. Show those groups separately, declare the archive coverage on which calibration was supported, and fall back outside that coverage. These recordings cannot establish transfer to an unobserved site. A result that improves only revision prediction or in-sample RF fit remains insufficient for promotion.

This appendix proposes future work only. No code, covariance, fitting policy or scientific input was changed.
