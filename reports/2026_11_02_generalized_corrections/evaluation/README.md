# Bounded evaluation harness

The RF-only roster retains all 205 available recordings from the original 229-member source inventory, including the five fresh scans. Its per-cohort counts are DS24 25, DS26 148, DS27 13, DS28 14 and FRSH 5. Twenty-four unavailable source members remain outside the metric denominator. `rf_roster.json` removes position errors, geographic truth and outcome ranks before numerical work.

The paired policies are A, A+B and A+B+C. A is a numerical repair and falls back to exact saved ALGO07. B uses one predeclared causal-history covariance rather than choosing covariance by fitted RF score, and falls back to the selected A output. C evaluates the same B endpoints with a separate frozen other-family geometry guard and also falls back to selected A. Both calibration arms must qualify together. Raw rejected endpoints and RF-score changes remain separate from policy-selected outputs. The three existing guarded ALGO07 identity replacements are retained exactly. The two inherited likelihood/owner mismatches are explicit unsupported fallbacks rather than silently repaired comparators.

`run.py` requires the parent's frozen protocol with an `evaluation` object matching `proposed_configuration.json`, plus absolute source hashes. It checks source and input hashes, enforces BLAS=1, and schedules cohorts in lexical round-robin order with lexical case IDs inside each cohort. Eight worker processes share one 1,200-second total window. Each model-arm fit has 120 seconds; each preparation and geometry-arm stage has 60 seconds. Timeouts and failures are terminal. A completed A stage remains available if B is capped. Checkpoints are atomic, all workers are joined, and an existing execution receipt prevents a second launch.

Geography is absent from the runner and qualification helpers. The parent evaluates selected RF endpoints only after the complete decision ledger is sealed. Complete likelihood evidence includes kept curved points, conditional entries and phase-mixture entries, with cross-piece duplication rejected. Incidental membership extensions remain unadopted proposals and receive no coverage credit.

Seven component tests cover exact fallbacks, common-reference A scoring, score-independent B choice, paired qualification, deadline propagation, balanced scheduling and full native-union inventory. `preflight.json` records successful no-fit objective/owner replay for the first lexical member of every cohort before protocol freeze.
