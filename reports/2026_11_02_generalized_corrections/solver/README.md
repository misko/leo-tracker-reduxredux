# Numerical repair prototype

The measured reverse-transfer failure has a reproducible central-versus-forward finite-difference discrepancy. Replaying the saved DS26-0309 SD4 endpoints gives exactly their saved objectives and identical repeated evaluations. Central gradients have maximum magnitude 0.00483 / 0.00452 per km, while the original forward differences reverse both component signs. Both exceed the inherited position solver's `gtol=1e-4`. This motivates a central-Jacobian intervention; it does not establish the sole cause of the original abnormal termination.

`numerical.py` retains every observation, alias, identity, prior, likelihood power and physical mode. It checks the saved endpoint's raw phase gap and its projected central gradient at 0.001 and 0.01 km. Either phase gap above 0.01 s or a stable gradient above 1e-4 triggers a paired numerical experiment, with the same saved fitted-c position/reference start in both calibration arms. Phase-reference updates use half damping and the original absolute-phase priors.

Each fixed-reference position solve first runs the inherited forward-difference L-BFGS-B. An abnormal termination or stable central nonstationarity triggers one L-BFGS-B solve using an explicit central Jacobian at 0.001 km. A rescue is adopted only on solver success and fixed-reference objective nondegradation. Central stationarity remains a separate mandatory final qualification. All objective calls, including Jacobians and probes, count against an 800-call per-reference ceiling. Forward and central solves have 35-iteration and 140-evaluation ceilings; the enclosing model-arm cell has a separate 120-second deadline. There are at most 15 phase rounds.

Qualification requires optimizer success, stable projected central gradient at most 1e-4, phase closure, converged inner Gamma precision, an interior position, every inherited base/exact-orbit/mixture gate, phase-mixture boundary mass below 0.01, exact complete native-ID/fitted-owner preservation, and no lost or reassigned published owner. The A policy compares the candidate position with the saved arm's position under the **same final reference and context**. Saved-versus-new objectives across different references remain diagnostics because the approximations differ.

The reverse-transfer inspection performs no fits. Five component tests check gradient projection, the measured rescue trigger, solver-flag preservation, rescue nondegradation and actual objective-call accounting. The earlier fixed SD4 and predictive experiments remain unchanged.
