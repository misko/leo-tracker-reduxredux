# Fresh early-symbol confirmation before accepting tracks

This separate controller composes the frozen NativeTradeoffDetector with an
engine adapter. Native nuisance-aware blind discovery is unchanged. Only its
positive proposals are rescored on raw IQ, at nearest integer timing, through
the verified early-symbol native scorer. Final pairing and cache establishment
use the new confirmation, not the original diverse-symbol score. Discovery
timing remains fitted with explicit integer quantization. Guided predictions
must pass both existing fresh guided evidence and new early-symbol evidence;
they remain unfitted and never teach timing drift. Failed confirmation triggers
the existing blind fallback; failed discovery clears the key's state.

yet add rescue or a wider proposal search. It must not be promoted merely for
suppressing extras while increasing misses. Counters from the original
controller omit adapter confirmations, so record the additional call count and
complete-call time explicitly. No frozen artifacts or production code change.
