# Disjoint-record frozen geometry confirmation

The first pilot showed S>D but did not compare either arm against a pure clutter baseline. The subsequently observed clutter-only advantage prevents promotion of geometry as useful association. This stage asks whether the frozen static model supplies predictive target information on additional records, beyond both D and a fixed no-target model.

Select four already-derived, pose-bound roof recordings disjoint from all ten pilot recordings, using the metadata-only rule and exact inventory recorded in INVENTORY.md. Historical work on these recordings must be disclosed; disjointness from this fit does not make them globally blind. No old candidate identities or residual outcomes are used for selection or new catalogue ranking.

Keep the original fitted coefficients, nuisance signal width, clutter intensities, prior scales, feature centering/scaling and receiver-sign convention unchanged. The frozen scorer must enforce model/training-dataset provenance and reject overlap by default. Its explicit overlap switch is permitted only for a separately labelled regression replay of the original evaluation records, never for confirmation.

For each confirmation recording use grouped whole-window 60% training, 20% reception, 20% held roles, with boundary embargo unchanged. All four recordings have recording_split=evaluation; this never makes the first 60% a shared-coefficient calibration sample. Reconstruct tracks and search the causal catalogue on that recording's initial training prefix only, using the same latest-three-track cap and top-three candidate shortlist. Recover alias provenance and per-lane receiver offset from training only, using the prior thresholds without tuning. Snapshot authority may retain historical source/TLE/site bindings but not old candidate ranks or residuals.

Construct the same exact-lane, one-per-paired-window candidate sets. Preserve alternative raw detections and empty views. Apply frozen D/S/T and controls without fitting. A no-target reference uses the original frozen RX clutter intensities and uniform canonical-circle density for every raw candidate, with the same count normalization as the primary set score. It has no fitted confirmation parameters and cannot update an identity.

Report unique held-window counts, per-record and equal-record mean S-D and S-clutter, T-S and tilt controls, association posterior changes and all exclusions. Positive S-D without S-clutter is insufficient to enable the model as an association default. Tilt still requires outperforming static, swapped-axis and reversed-trajectory comparisons. No frequency gate, catalogue expansion, coefficient adjustment or second selection after seeing results.

Every numerical stage is serialized, one thread, nice19, 4GiB address-space, maximum300seconds. Expected stages: raw opportunity export; grouped partition creation; training-only candidate bank; training alias/RX mapping; common-lane dataset; frozen scoring and analytical no-target audit. Preserve failures with receipts; do not rerun on an observation timeout while the process is live. No RF, rawIQ collection or QNAP mutation.
