## Cache validity

For **annotations with no clipped update in any saved round**, reference30 follows the same updates as reference15. `fit_training` remains the existing five-round, 48-step **Gauss–Newton** procedure, not patched L-BFGS-B. Reusing its frozen candidates, aliases, partitions and scores is therefore valid under unchanged scientific inputs. This is reuse of conditional evidence, not a new catalogue search or independent validation.

For **default shared-family trials**, `regional_unconstrained` also uses the existing Gauss–Newton fitter. The centered-L-BFGS-B patch does not affect this route. An unchanged annotation plus no clipped trial update leaves the numerical dependency unchanged; copying the exact fit bytes and its existing exact-owner audit is valid. Changed annotations or any historical trial overflow correctly invalidate the shared cache. This reasoning does not automatically extend to other position modes or future fitter changes.

The source audit found **zero completed-target filtering/index mismatches**: retaining only original completed annotations does not renumber an original target's stage charge in this dataset. It also found **zero shared sources with `control.json` present but missing protocol, target or exact-owner audit**. The runner's current minimal existence test therefore encounters no incomplete source trial here. These are empirical guarantees for the frozen source, not generic guarantees for future datasets.

The remaining operational limitation is **receipt-version reuse**: `batch` skips an existing `receipt.json` without itself checking the numerical-code/input hash closure. For this immutable run, the parent hash audit must invalidate any canary made with a different helper version. A later resumed run after code/input changes must not silently reuse stale or `replay_failed` receipts. This review does not request a mid-run runner edit.

## Published owners and budgets

The adoption guard uses **published terminal ALGO03 owners** in each arm when a selected result exists; otherwise it uses the terminal's published baseline source support. Any missing or changed owner rejects adoption. It does not substitute the smaller ALGO02 inventory ownership for an already published ALGO03 selection. Historical production read-audit failure also prevents an update. The current result is explicitly a research replay and does not fabricate a new production OS read audit.

Cached stages charge at least their original measured wall time, with actual cache overhead retained if larger. Recomputed stages consume current wall time and the original stage/case/discovery deadlines. The centered L-BFGS-B path counts all physical objective evaluations against its hard **240-call** cap, in both c arms, with at most 48 iterations. The 240-call statement applies to that patched optimizer; unchanged annotation/shared **48-step Gauss–Newton** fits have their own existing evaluation behavior. Raising line-search `maxls` to 40 changes how the same total L-BFGS-B call cap is spent, not the total objective-call allowance.

Sixteen-worker CPU contention can change actual wall time and which later stages fit the original discovery budget. Preserve and report actual schedules, omissions, timeouts, cached charges and case failures. The replay only revisits targets with completed original annotations; it does not newly search originally unexecuted or failed targets. These limits belong in the dataset result's scope. Paired masks, priors and algorithmic budgets remain matched between c=0 and fitted-c; frequency-score effects must remain separate from reporting-only position accuracy.
