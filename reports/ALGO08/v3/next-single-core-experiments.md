# Where the next single-core experiment can save time

The latest matched warm raw pair took 9.075 s in total versus 12.108 s on named ALGO08v3. The median paired ratio was 0.568 and the ratio of totals was 0.750. Both must reach 0.500. This pair consists of one tiny withdrawal and one weak fix. The medium and dense saved replays below measure different boundaries. [Complete pair](unified-short-layout.md) · [Medium saved publication](cumulative-medium.md) · [Dense saved publication](cumulative-dense-graph.md)

On dense DS30-0008 the earlier complete receiver spent 17.351 CPU s inside native detection and 15.053 CPU s elsewhere in acquisition. With the latest saved numerical solve, the first-four uniform-rate model allows 28.913 s for this 8,182 MB acquisition. The earlier run spent 32.403 CPU s and 60.449 elapsed s. Removing 12% of native CPU and 10% of the other CPU would save **3.59 s**. That example just clears the **3.49 s zero-wait shortfall** and allows only about **0.10 s** of wait. These percentages illustrate the scale of change needed. A faster solver also increases the acquisition allowance. On the two measured originals, holding the tiny withdrawal at 0.437 s leaves 5.617 s for a weak fix that currently takes 8.638 s.
