# A short all-channel survey followed by continuous listening on selected channels

Use the first sixth of the admitted stereo visits (rounded up) to measure where the installed two-scan receiver finds repeatable signals. Determine the survey length from the authenticated recording schedule. Rank only RF groups encountered during that survey. An RF group is a channel at one actual tuning. Sort groups by actual radio frequency and channel and divide them into lower and upper halves, with the lower half taking the extra group when the count is odd. Keep one group per nonempty half until the recording ends. Both antennas always run together. All survey observations remain available to the solver.

Divide the survey visits into four consecutive intervals using the integer part of four times the zero-based visit index divided by the number of survey visits. Rank each group by its least selected-signal fraction across those four intervals, then its pooled selected-signal fraction. A missing interval has fraction zero. Both fractions count antenna opportunities, one per admitted antenna, whether or not a factor was found. Break ties by ascending RF then channel. The rule uses only verified continuation selections already available during the survey. No site coordinates, region, satellite labels or future signal observations enter the choice.

Freeze this single rule before the first evaluation. Run the full signed joint solver on dense DS30-0008 and the southern containing and distant omitted offers. Keep the eight-second continuation and every original probe slot. Retained groups have continuous histories and need no warmup. Bind the same changed packet across both southern offers. Compare returned decisions, position error and RF residuals in the zero and fitted calibration arms against the existing full signed and installed v3 controls. Include numerical evidence and any fallback in saved solve time. Estimate dense acquisition CPU by charging the previously measured fixed work plus retained calls at the full-recording mean rate, and state the limitations of that model. Passing the first screen requires the original decisions, at most 0.25 km extra error per arm on both containing cases and a modeled dense CPU cost through evidence below half the historical complete warm CPU time. Further qualification would require actual raw timing and publication. Stop this rule at these three saved offers if it misses either screen.
