# Lightweight writer for legacy map audit JSON

The indexed raw entry used the scientific serializer for an audit whose values are already ordinary JSON. After a genuine withholding, this imported `leo.application.localization_v3_engine` and SciPy after the receiver had recorded its lazy-import witness. A dedicated writer removes that import from the audit boundary and keeps the same field values, sorted order, numeric representation, whitespace and single trailing newline.

| Issued audit written in a fresh process | Original serializer wall range | Dedicated writer wall range | Extra modules, original / dedicated |
| --- | ---: | ---: | ---: |
| DS30-0107 all-member withholding | 300.043–309.514 ms | 1.033–1.059 ms | 658 / 1 |
| DS30-0016 all-member fix | 305.070–307.282 ms | 1.332–1.368 ms | 658 / 1 |

In each case two children used each writer after normal receiver setup stopped at scanner construction. The full issued audit was read as JSON before timing, and all eight outputs matched the respective issued audit byte for byte. The positive fixture prices the writer in a no-solver process. A normal positive solve already imports many of the measured modules. No raw child or solve ran for this change, and neither clock alters the published full-process cohort.

The [dedicated writer](legacy_map_receipt.py) serializes the entire object before exposing the destination. A local hard link publishes the complete file exclusively and leaves any existing receipt untouched. Tests cover exclusive publication, sorted encoding, nanosecond UTC and floating-point precision, the trailing newline, and rejection of non-finite values before a file appears. The issued all-member runtime and its prior receipts are preserved in the original branch. [Writer-only evidence](measurements/legacy-map-receipt-diagnostics.json.gz)
