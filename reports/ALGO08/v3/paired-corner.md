## Exact boundary

The native code uses the original interpolation/rotation helper once per satellite and epoch for the nominal, plus-step and minus-step orbit states. It also shares their observer-independent finite differences. Each original observer independently receives those states and evaluates the sequence of range, radial, vertical, and derivative sums used by the installed C kernel. Python retains the original full elevation angle conversion. Candidate sources were checked against the installed C and Python hashes and built using the release flags with floating-point contraction disabled. Both the installed object and candidate compiler identify GCC 15.2.0. The ordinary result comes from the installed binary, not a relinked substitute. The optional serial scope holds a second separately owned output triple for the next requested location. A mismatch, mutable stencil or memory bound takes the original evaluator, without carrying partial results across requests. [Native code](paired_corner.c) · [Python scope](paired_corner.py)

No catalogue was repropagated, and the scope did not run the complete corner exploration or any fit.
