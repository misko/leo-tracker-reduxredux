Use the existing 12-opportunity, eight-second carrier continuation vote unchanged, on each original radio, channel and RF. The reverse pass negates only the hardware counter passed to the vote and traverses the original opportunities in reverse. Return original factors, signed frequencies, time stamps, and ordering. This rule is usable after capture; a streaming version would need bounded lookahead. It uses neither stock selections nor site coordinates.
