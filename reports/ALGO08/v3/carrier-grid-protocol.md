# Saved signed carrier precision screen

ALGO08v3's compiled timing-first acquisition uses 4096 FFT bins, a 10 MHz sample clock and stride four. Its 2.5 MHz working rate gives a natural spacing of 610.3515625 Hz and a quarter spacing of 152.587890625 Hz. The compiled path maps the upper half of the FFT to negative frequencies, restores the native mixer center and uses a verifier residual. The Python exporter writes the resulting signed baseband `v.hz` to `fractional_tracking_cfo_hz`. The native mixer center comes from the search bounds. This screen deliberately uses zero as the lattice origin and starts with the already selected exported values. Preserve every other candidate field, empty window, exact timing, sample clock, timeline, rank, margin and RF lane. Bind the transformed detector stream to a fresh analysis-manifest digest and run ID. Preserve its released binary provenance as the source of the admitted data. Use the exact same transformed southern packet for the containing and omitted offers. Keep the causal archive, regional bounds, independent evidence and all solver and search gates fixed. Both calibration arms receive identical transformed observations. The driver has no geographic scoring references or original ownership labels in its inference path.

Run one full repaired signed joint attempt per spacing on DS30-0008. Run both southern offers for both spacings. Inference retains the joint route's existing veto, numerical evidence, retry and installed-v3 fallback on the same transformed packet. Measure total saved solve CPU and wall time, including any fallback. Preserve any terminal error and charge work through the failure. No extra dense controls or raw reads. Serialize each solve on the same low-priority one-thread Gauss worker.

Score only once all six outputs are sealed. Compare with the pinned archived exact-CFO signed run and archived full installed-v3 inputs. Keep the exact-CFO signed comparison and any optimization differences in its archived timing provenance visible. This is an optimistic precision-isolation experiment. It gives the synthetic receiver the exact original existence, rank, verification values, dropout pattern, continuation and nearest bin to the released fine estimate. It does not exercise a coarser receiver, the effects of scout peak errors or epoch changes, underlying signal selection, or acquisition and publication speed.
