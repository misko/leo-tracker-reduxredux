# Can compressed member size identify cheap gaps in a recording?

Compressed and uncompressed byte counts are known from the original signed accession before any waveform is opened. Test whether the member with the smallest compressed-to-uncompressed size ratio in a group of four contributes unusually little scientific support. This hypothesis uses no receiver location, site reference, orbit, channel preference or trained threshold. A smaller ratio could reflect digitizer gain, noise, invalid visits or codec behavior. It is an observable proxy.

Use the first eight assigned DS30 recordings as the development cohort. Report each verified pair with eligible groups, including a solver failure when its authenticated detector packet is available. Within each group, nominate one member for omission. Break ties by ordinal. Compare with the mean of all four fixed-phase one-in-four schedules and with a separate retrospective lower bound that can pick the minimum true count independently per metric. Denominators cover all issued visits or scored lanes in the recording, including tails. Original and successor packets must have matching original raw authority and identical issued/admitted stereo lanes. Actual exclusions are preserved.
