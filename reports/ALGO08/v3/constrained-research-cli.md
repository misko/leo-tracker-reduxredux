# Portable named ALGO08v3 constrained refits

`named_constrained_research.py` takes a recording, causal TLE archive, explicit geographic offer and fresh local output directory. The installed named ALGO08v3 scanner, detector and standard renderer provide the publication. Stock is the default. The explicit `--constrained prepared` option enables the reviewed prepared noise and whitening checks inside the existing constrained optimizer. `--constrained c0-first` and `--constrained fitted-first` add the reviewed proof that ends a constrained trial before its second calibration arm only after a complete first arm fails a mandatory track check. Configurations without that proof still run both arms. The accepted solution and standard publication keep the named provenance. `named-constrained-research.json` adds an independent research identity tied to the chosen policy, source digests, original detector and input identities, actual nomination counts, ordered owners and work performed.

The existing case-study drivers and their measured source pins remain valid. The portable prepared declarations contain the measured arithmetic and original release checks. A test compares each Python declaration structurally with its measured counterpart. The existing generic pair guard is called directly. The runtime contains no prior case coordinates, fixture paths or expected outcomes. The original named source validation and local output confinement still apply.

```bash
/opt/leo-algo08/bdb869682a2ea63af4b198a920b763a4c6a78c4c/venv/bin/python -IB \
  reports/ALGO08/v3/named_constrained_research.py \
  --recording "$recording" --archive "$causal_archive" --region "$offered_region" \
  --output "$fresh_output" --constrained fitted-first \
  --saved "$saved_detections" --saved-digest "$sealed_digest" \
  --saved-inventory "$original_inventory"
```

Use the sealed named 20 ms detection digest with `--saved`. The optional `--saved-inventory` binds that packet to the canonical original inventory and avoids opening the original recording for metadata. The named acquisition port reads original manifest metadata when the saved inventory is omitted. Without the three saved-input arguments, the same command uses ordinary named acquisition. The installed release and research CLI were exercised in saved mode.

The independent `--optimized-publication` option enables the previously measured ordered graph and polynomial fit reuse, exact causal phase forecast, and direct residual and orbit rendering. It can be combined with any constrained policy. On DS30-0402 the combined option took 53.403 s against 55.752 s for fitted-first alone and retained the original science. Two dense gray orbit layers fell below the registered-pixel acceptance threshold. [Matched scientific and figure audit](named-combined-0402.md)

For a wider likelihood retry, pass the operator-built shared library with `--wide-private-likelihood` and its independently trusted digest with `--wide-private-likelihood-sha256`. This changes inference only for an unsupported original layout. The selected-packet and grid paths retain their stock implementation. DS30-0316 activated all 82 retries and reproduced the full scientific and visual publication. [Build, invocation and transfer result](named-wide-likelihood.md)
