## What ran on Gauss

One member could be prefetched on the same core during acquisition. The unfiltered solver used the installed track graph and supplied region, processed guaranteed regional probes in groups of four, kept the scalar fallback, reused exact cold rows and grid phase states, and bypassed the exterior catalogue only if the constructed graph was empty. All launches used fresh processes, one low-priority Gauss core and one numerical thread, original signed recordings, and fresh tmpfs publication roots. Each pair started with all compressed input pages resident for both arms. The CPU and elapsed measurements include the standard publication through process exit.
