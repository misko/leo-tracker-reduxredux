# Same-build Huffman assembly on one signed member

Enabling upstream BMI2 assembly saved **7.38–7.64 ms of decoder read CPU** on the authenticated 64-visit public North member. Through native detector seal and readback, elapsed time **increased 0.26 ms** in the first order and **decreased 1.39 ms** in reverse. Every arm published the same 59 factors and identical detector bytes. A decoder-only transfer of the smaller saving is **0.78 s** at 6,772 visits, conditional on equivalent frame content and execution. The complete acquisition pairs leave the speedup unresolved, so the result does not advance a decoder specialization. ## Huffman-heavy block cost

The 802 blocks were also decoded directly through the same library's block API, retaining normal table reuse and checking all 64 original window hashes and the full decoded digest after each pass. Four passes per arm in both orders averaged **65.308→55.986 ms** and **65.354→56.030 ms CPU**, reducing that isolated work by **14.3%**. This boundary excludes native waveform work, frame streaming and the frame checksum. Both block and full-stream paths use upstream code with ordinary support for matching sequences. [Upstream Huffman dispatch](https://github.com/meta/zstd/blob/v1.5.7/lib/decompress/huf_decompress.c#L1587-L1615)

Exact machine-code matching located both native assembly loop ranges in the shared ELF. The block CPU samples hit the assembly X2 loop 195 times and X1 15 times with dispatch allowed, with 13 other samples unresolved. With assembly disabled, all 261 samples fell outside the matched assembly ranges. The shared build is stripped and these disabled-arm PCs remain unattributed to specific C symbols. The installed bundled extension's earlier census directly identified its X2 fast C symbols. The block microbenchmark's roughly 9.32 ms per member would transfer to about **0.99 s** at dense scale under its narrower boundary. The actual streaming read delta transfers to 0.78 s using `7.382378 ms × 6772 / 64`. [Stock bundled extension census](zstd-structure.md)
