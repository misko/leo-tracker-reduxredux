# Can the held-out Graph residual select wrong positive short carriers?

Start with the already sealed DS30-0049 development and DS30-0086 held odd-short interpolation proposals. Their chronologically odd per-stream visits were empty in both radios before winner selection and Graph membership. Use the released signed CFO branch, the exact physical window and the original unique same-piece neighbors. Rebind the original mask and sealed forecast to each original candidate packet. Score any installed answer only after the selection list is sealed.

Consider only omitted short lanes with an actual original short winner. On each lane with a sealed forecast, nominate if the absolute difference between the signed candidate measurement and forecast is strictly greater than 250 Hz. Keep the forecast center unchanged and retain the measured target's original arrival when testing a carrier-only correction. Also score the archival forecast's own arrival as a secondary comparison. Select a per-recording equal-count control from all eligible positive lanes with a forecast, sorted by SHA-256 of the ASCII prefix `held-cfo-innovation:v1:` and target observation ID. Apply the same forecast center to the hash control. No temporal re-election, wrapped CFO distance, position input, extra detector calls or response to any installed label.

Report all omitted positive lanes with and without a reference winner. Define a genuine signed-CFO disagreement as absolute error greater than 250 Hz against the installed winner on the identical hardware lane. Partition the other installed-present lanes into delay-only misses or exact joint window hits. For the residual rule and hash control, report the counts of true CFO disagreements, reductions or increases in absolute CFO error, old misses brought within 250 Hz, old CFO hits spoiled, and strict joint changes using both the unchanged measured epoch and the forecast epoch. The strict joint limits are 250 signed Hz and two circular arrival samples at 40,000/3 samples per period. Count the number of unchanged positive lanes, all uncovered positives, and all original short calls. This experiment can change metadata on a retrospective copy and saves no original source, acquisition or detector work.

Use held DS30-0086 for the decision. Extend the identical rule to the already bound DS30-0019 and DS30-0274 capture pairs only if fewer than ten eligible installed-present positive lanes genuinely disagree in CFO or fewer than ten selected lanes have an installed winner, or if all three criteria hold with the existing counts. The residual rule must flag more true CFO disagreements than the equal-count hash, return more of those disagreements inside 250 Hz, and have a positive net gain in strict matches when arrival stays unchanged. Ten is a minimum descriptive count for this limited continuation decision. It does not imply statistical significance. If none of the continuation conditions hold, stop after the two existing seals. Do not run receiver, solver, waveform, orbit or backing-storage work, and do not take a timing lease.
