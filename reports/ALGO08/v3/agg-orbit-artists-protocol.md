# Fixed-view orbit artist replay

The two-band shared Agg renderer builds both axes layouts and always explicitly sets the horizontal limits to 0–300 s and the vertical limits to the centered alias band. The trial preserves the axes, legend, titles, point and curve order, transforms, clipping, Agg rasterizer, background copies, dynamic overlays, and existing PNG encoder. The candidate takes a fixed-view path for creating the orbit artists. It skips calculating general-purpose data limits the fixed axes subsequently replace. The constant circular scatter path can also be constructed once per replay. The installed figure factory remains the fallback for other styles, modes, or axes limits.
