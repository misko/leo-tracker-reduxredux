# Does losing the ends of Doppler curves explain the position difference?

Use the frozen first 24 paired recordings in the [fallback study](field-fallback-budget-protocol.md). DS30-0049 is a development example. Use the other shared fixes for the primary comparison. Reserve the next three recordings in the original order for a separate check. Measurements on the first 24 are retrospective. Use only saved detector packets, association lists and verified position receipts.

For each fixed-zero and fitted candidate solution, group its owned detections by satellite, radio, tuned RF, edge and channel. Start a new group after an interval longer than eight seconds. Split the groups once using the complete candidate list. The installed detector corroborates a candidate observation if the signed winners agree within 250 Hz and two wrapped timing samples. This tests agreement between detectors at the same physical opportunity. The installed satellite assignment is generally unavailable.

For equal-weight samples at times (t), count observations, sum squared times about their group mean, and sum squared residuals after regressing (t^2) on an intercept and (t) inside each group. These quantities measure support for a level, slope and quadratic coefficient with free lower-order coefficients. Refit the nuisance terms after subsetting and sum each measure across groups. The primary predictor is the fraction of quadratic support lost when keeping only corroborated owners. Compare it with the fractions of count and slope support lost. A second calculation retains only the candidate’s scheduled full-length anchors and uses no installed detections.

For each predictor, report Kendall tau-b with the candidate-minus-installed horizontal error across recordings. Positive values mean that greater loss ranked with greater error. Count shared fixes per arm, report unavailable endpoints, and keep the release benchmark timings and survey separate from feature calculation. These are design-matrix diagnostics. They assume equal precision within each curve and do not estimate satellite geometry or true signal identity. No survey-based offsets or fitted thresholds enter the method.
