## The approximate rule and when it can save time

Run the four original centre seeds in their fixed order. The first two must have distinct input calibrations and agree bit for bit on their full ordered assignment rows, signed integer aliases, centre decision score, receiver offsets/drift, smooth coefficients, satellite phases and any extra modes. The original minimum centre-score parent must match that full state. Then run the first ordinary corner, southwest in the offered coordinate frame, with the same parent and keep its original alias construction. Only consider omitting the other three corners if this corner gives the same signed assignment. The decision sees no reference location, dataset labels or published satellite IDs. It compares equality on the actual candidate outputs, irrespective of the label values.

The observed nodes would go through the original stable deduplication and fixed-zero ranking and the ordinary finalist budget. A viable trial would require exact full-observation qualification of both calibration arms and the original geographic check, with ordinary continuation on any unavailable state, ambiguity, qualification failure or active face. Losing candidates still could have passed those checks if evaluated. This is an approximate proposal screen. Code implementation would need to resume the ordinary search from untouched paid centre and corner state on rejection, pay any provisional fit that cannot be reused and rerank before retrying. The existing rank returns its result only after all centres, corners and fixed-origin ordering. Substituting at that return saves no nomination work. No fallback or qualification time is credited as a saving.
