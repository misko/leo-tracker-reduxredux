# Test for a competitive sampled loss at the offered face

Use completed, sealed two-arm position grids. For each calibration arm, subtract the minimum finite published grid score anywhere in the square from the minimum finite score at an exactly sampled point on any of the four offered faces. An arm reports competitive face contact when this difference is at most `−2 log(0.05) = 5.991464547` in negative-twice objective units. Abstain on a paired fix if either arm reports contact. Independently report each arm and the more permissive both-arms-contact sensitivity. These are fixed support-level readouts inspired by a nominal 95% two-dimensional likelihood contour. The conditioned variational objective and repeated tracks do not give a calibrated confidence set. A sampled point can witness contact. An unsampled tangential location can hide contact. This rule gives no guarantee about fitted likelihood beyond the offer.

Require an exact paired endpoint score in each arm, finite scores for all published grid rows and at least one scored point on each face. Incomplete or unsupported evidence is unassessable. Cross-check the final path against the exact saved grid endpoints, and bind grid, path, arm positions, observations and supplied region to the original terminal or publication receipt. Require matched capture, native detector and sky authority within each pair where archived. Record sampled face gap, which face and point gave it, endpoint clearance and how close the nearest sampled point on that face is to the endpoint's tangential coordinate. Read the existing grid directly. Do not fit a local quadratic, interpolate, generate probes or run inference.

Freeze the named-survivor South containing and 100 m omission pair from its archived active publication. Include the older matched North containing and 100 m omission Q15 pair as a boundary control, plus four original released-v2 controls at the same two sites with wider containing offers or 1.5 km omissions. Reuse public truth only after the decision receipt seals. The calibration arms use the same model policy and matched point locations within each offer. Record pre-gate horizontal error and RF residual separately. The tested builds differ across pairs, and the wider cases use shifted offers on the same saved waveforms.

Call the rule useful on this panel only if it keeps both original 100 m containing fixes and both wider containing fixes while abstaining on both original 100 m omissions. Report larger omission outcomes independently. Use the fixed threshold and report the retrospective interval of thresholds that could satisfy all available rows for each arm and paired policy, without choosing any new value. Analyze only staged tmpfs metadata under the shared low-priority Gauss CPU 2 lock. No waveform, data-store replay, orbit propagation or numerical solve enters the trial.
