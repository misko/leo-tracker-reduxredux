# Screen an adaptive post-fit likelihood map on sealed scores

Use the four existing short-receiver quadratic-graph publications for dense DS30-0008, weak DS30-0016, and the containing and near-omitted offers on the same southern synthetic recording. Verify the original grid, position path and terminal against their published digests. This is a diagnostic grid after the position fit and the region decision. A wrong fix on a near omission stays a wrong fix.

Start with the released layout using five coarse nodes per axis and four local nodes per axis for each endpoint, retaining both endpoints and the offered center. Use actual scores for both calibration arms. Triangulate in the offered east/north coordinates. Sample an original grid point when any enclosing triangle vertex lies within 4.5 objective units of either arm's initial sampled minimum. Refine uncertain triangles with nonfinite vertices and points outside the triangulation. Final output consists solely of genuine sampled locations and both original objective values at each. Interpolated predictions are audit-only.

For both arms require retention of the original sampled minimum, every successful original node within 4.5 objective units of that minimum, and all original failed nodes. Use the omitted true scores only after choosing the nodes. Compare predictions at omitted nodes for missed low-loss regions and measure the count saved. A practical screen also requires at least one quarter fewer evaluations on each offer. Failure precludes a fresh pipeline timing for this layout. Node counts are not an elapsed-time measurement. A passing offline screen permits a saved measurement; retain the original dense layout as a control and keep the runtime default.
