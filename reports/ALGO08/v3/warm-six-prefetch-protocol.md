Choose the first six original consecutive signed members from DS30-0008 if every compressed and index page is resident, otherwise use the first six from DS30-0016. If neither qualifies, try the existing staged public North recording under the same limit. Decide from passive residency only. Inspect every member immediately before and after each fresh arm. Use cache-only positional reads for signed files, with no cache advice, original eviction, prewarming or new source copies. Abort on the first would-block read, cache loss or physical data read during acquisition.

On the selected prefix run serial verified demand–existing one-member prefetch, then prefetch–serial. Both arms use identical native 20/12 ms optics, one call per admitted lane, the original signed scope and exclusions, the paired SHA-256 and the streaming decoder. The prefetched bytes still pass all normal demand-path validation. Run one serial verify-only pass after the pair to locate the available receiver-work ceiling. No solver or raw traversal beyond these six members. Charge all reads within each arm and separate process CPU, acquisition CPU and elapsed, seal overhead, worker CPU and bytes, and physical I/O. Verify the signed index digests, all decoded window and complete member digests, original deliveries, exclusions and original chronological factors. Require byte parity between full-DSP arms.
