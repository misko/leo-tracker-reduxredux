# Exact sparse carrier ranking in the active 8 ms receiver

The existing sparse carrier sweep transferred to the current 8 ms primary and reproduced every exported native factor byte on **212 scheduled DS30-0008 and DS30-0016 lanes**, including empty lanes. It saved a median **11.54 µs per dense lane and 16.33 µs per weak lane** against a same-source PGO rebuild that reproduced the installed short binary byte for byte. All four repeats in each case favored the candidate. The weak-case savings would amount to **20–26 ms** if they transferred across all 1,240 short calls in the complete successor. This remains below **0.9%** of the measured acquisition. [Frozen protocol](short-rank-protocol.md)

## Eligible peak selection

The 8 ms short scout evaluates the score array 12 times for successive timing peaks and calculates two carrier peaks at each proposed phase. The original carrier search writes both modes' powers for all 4,096 bins, then scans the sorted eligible list twice with a circular minimum separation. Its eligibility cache already holds the correct ordered bin indices. The separate timing maxima and carrier ranking instruments reproduced the active DSO's native output, with any performance inference qualified by the non-PGO build. ## Matched 8 ms transfer

The sparse kernel computes powers only for the same eligible bins and records reusable tile maxima while adding the second mode. When the first winner excludes a tile's peak, the code finds the best remaining original bin in that tile. It preserves ascending-index tie rules, circular bandwidth and bin separation, the original normalizer, NaN ordering and fallback to the original sweep for unsupported CPU or eligibility layout. The paired timings pay the complete short native callback. Each case independently rebuilt both timing objects using the original site-free training rows, compiler and flags. The control exactly reproduced the pinned current DSO and both candidate builds produced `c5b57b0602e81a6a85c14caf648eb12341f098d09915b4d3f705094ed309574c`. Build, fixture decode and context setup are outside the measured short call.

## Reproduction

Use the existing installed release interpreter and signed staged files, the original file owners and the shared Gauss lock on CPU2 at nice 15, best-effort I/O priority 7 and one numerical thread. Run `short_rank_trial.py FRESH_PATH --case DS30-0008` or `--case DS30-0016` through the module launcher. The profiled runs used `195f611ae`, and the PGO transfers used `3b94e8bb4`. For the frozen transfer, restore each of the two archived profile JSON files under a staging parent at `leo-v3-short-rank-profile-CASE-02/profile.json`, then pass `--transfer STAGING_PARENT`. The phase gate checks those exact receipts and the later signed factor bytes. Twenty focused and adjacent tests passed. Two early launch attempts stopped before any waveform read on an unused archive import and the original scout wrapper-object pin. The prerun correction removed the import and independently pinned the actual primary wrapper before requiring a byte-exact relink.
