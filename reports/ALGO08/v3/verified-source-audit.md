## Cache component and reproduction

`VerifiedSourceText` caches strings for independently pinned on-disk Python sources. Keys use the actual function, owner module and globals, code object, exact source loader and origin, source pin and file signature. A modified source, rebound function or decorated wrapper goes through the ordinary source reader and its caller's original checks. The component retains no reusable verification outcome, executable, closure or numerical state. The tests cover ownership, changed code and source metadata, nesting of trace timers and tampering with a persisted sidecar. No measured runtime benefit is claimed for the component.

The attribution entry is `verified_source_audit_trial.py` with one fresh top-level tmpfs output directory.
