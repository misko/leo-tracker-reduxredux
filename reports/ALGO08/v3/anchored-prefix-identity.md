# The guarded 32-anchor paths share the same retained prefix

On the held DS30-0169 staged member, **42 of 45** guarded short positives had original short and long recurrence rows that matched **byte for byte**. All **336** qualifying prefix frames matched both the exact and rolled 64-symbol native rows. All 45 accepted factors used the same scout and emitted CFO. The audit reproduced every measured short factor, all 41 empty lanes and every sealed B output reached by the original tail guards. Both guarded routines call the same generated `anchored_correlations` implementation. Its oscillator restarts with the same exact absolute phase every 32 taps within each frame and steps through the intervening taps with the same Float64 complex recurrence. The fractional weights depend on the same rounded absolute positions. Under matched carrier, timing, pilot, lane, I/Q bytes and arithmetic, adding later frames cannot change the earlier rows. Short recurrence was accepted on **44** positives. The long recurrence survived its own exact-fallback guard on **43**. There were no additional signed band-boundary retries.

The three ineligible cases each had eight different final prefix rows. Short visit **50**, lane 1, took the original exact short verifier while the independent long recurrence remained active and updated CFO. Visits **39** and **43**, lane 1, passed the short recurrence guard and took the exact long-tail fallback, which left CFO unchanged. An integrated handoff must use the independent B tail on a short fallback, changed seed, incompatible layout or tail ambiguity. The original tail guards still need to evaluate the composed measurement, and the original signed-band check still applies. The counts are for the actually retained rows, after B's independent guard decisions.

This was one row census with no new detector-seal race, position fit or source-original waveform access. The retained staged intake reported zero process storage read bytes. The first diagnostic stopped after the signed staged intake when its original all-process zero-read assertion also counted dependency input. The retained version confines the manifest, index and compressed source to the pinned tmpfs mount before opening them, while recording application-level dependency reads separately. No timing benefit was measured for a composition of B and prefix sharing.
