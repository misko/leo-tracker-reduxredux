# Project only the epochs used by cold catalogue ranking

The current successor's complete compact rank projects some epochs that belong only to noncurved tracks. A rank-local prototype omits those columns while keeping the released projected values and signed ranking records byte-identical on a small saved physical fixture. On the audited field cases the actual removable share was 8–15%. Applying those shares to the separate archived dense projection clock gives 44–83 ms of nominal projection work before the guard and reindexing. No paid numerical benchmark or whole-run speedup was measured. [Prototype](curved_rank_time.py) · [Sealed field counts](measurements/curved-rank-time-census.json)

## Actual field coverage

The reducer checks the original field result, marker, native authority and both owner rosters as in the prior rank audit. It verifies the retained native bytes and replays the reviewed Graph preparation from those detections alone. Original and observed assigned points, track counts, curved rows, curved points and total epochs agree for each recording. A simultaneous time is omitted only if no curved track uses it. The two original extrema stay for shifted interpolation checks. The earlier upper counts came from subtracting observations and were larger because some noncurved rows share times with curved rows. ## Scientific equivalence on the small fixture

The optional `projected_ranking(audit)` context wraps the existing exact rank factory before its centre/corner statistics, phase projection and compact catalogue hooks. Source pins limit the overlay to the reviewed consumers. It remaps curved-track columns through an ordered set of original sample times, reuses the immutable orbit knot buffers and slices the nominal native stencil. Each original curved observation, signed value, satellite and nuisance state stays available. The original full view is restored on scope exit or error. A request that actually uses a noncurved track reruns the ordinary producer on the original view.

The endpoint checks preserve the kernel's monotone shifted interpolation bounds. Between adjacent position knots the change in range is bounded by the chord length. The prototype admits only matching original knot buffers where this bound places every satellite well above every surface observer, preserving native range validation even at omitted cells. The original nominal-frequency eligibility check also sees the full plane. A 25 km/s bound on all relevant velocity knots ensures the original interpolation and Doppler scale stay below its 1 MHz limit. If these whole-bank proofs fail the ordinary rank uses the full view. Admission frequency and guard CPU on the full field were unmeasured.

The tests use the archived DS30-0008 physical orbit-state capsule (`d5ea1246…`) and original supplied offer (`f7056667…`), one measured curved track, manufactured linear gap controls and the installed projector DSO (`7a183da2…`). The recorded orbit states and measured curved track are genuine. The component case uses a nonmatching earlier element fixture. It compares all three nominal and shifted planes bit for bit on retained epochs at the actual centre and supplied corner, rejects an out-of-bounds shift in both views, and verifies the original exact rank entry's complete ordered records and score bits with the same compact scorer activity. Additional checks exercise duplicate and interior epochs, the unmodified all-track association on fallback, and the restored scan. The parity fixture leaves final geographic and calibration solves outside the experiment. Four owned tests and two earlier rank-audit tests passed on CPU 3 at nice 15. The Graph census opened no waveform or orbit archives, and no CPU 2 lease was taken. [Component tests](../../../tests/pipeline_eval/test_curved_rank_time.py)
