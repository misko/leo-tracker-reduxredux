# Saved first-ranked incumbent ceiling

This is a retrospective cost audit of direction 1 in the [doubling design](next-doubling-design-2026-11-24.md). The checkpoint is the return of `v5_core.ranked_initial_nodes` on the ordinary observations. The first ranked cold node is the incumbent. The checkpoint includes usual proposal generation, original centre and corner association, duplicate-signature reduction and fixed-zero score ordering. The first calibration seed generated inside `fresh_discovery` precedes this checkpoint. The original cold receipts do not preserve that generation order or timing.

Use the already sealed selective DS30-0016 containing and translated procedures, repaired portable plus catalogue-block DS30-0316, and full mixed DS30-0008 with the original final fit. Use the previous independently timed dense control to quantify rank and post-rank disjoint time only after establishing the same cold result. These were known outcomes when choosing the retrospective matrix. This audit acquires no data, replays no solver, and changes no scientific policy. A private receipt fingerprint binds each input and each independently captured rank timer. Where available, separately signed results bind the publication and scientific classification.

For a case with a different eventual winner, retaining only the incumbent fails the exact comparison. If the incumbent wins, credit the sum of measured losing branch prefixes and completed losing refreshes. Also give an optimistic ceiling by subtracting the original required incumbent prefix and completion from the enclosing cold CPU scope, then subtracting the inclusive rank CPU where measured in that same process. This discounts rank work already paid and preserves the winner's original startup and second refresh. The ceiling donates all remaining bookkeeping, verification and fallback costs. For the weak runs with no isolated rank timer, deduct the incumbent alone and donate the entire rank. Deny negative or double-counted timing and verify archived rank identities wherever they are available. Check that rank-1 denotes the exact first returned assignment, with its original tie and order, rather than the leading prefix or another seed that happens to share a location.

Consider a two-input held-visit shadow only with a credible measured upper bound above 0.500 CPU s on a current positive. Visits must be reserved before nomination, disjoint from the discovery input by whole stereo visit, and included in both original calibration arms after a positive proof. The complete ordinary fallback must retain the original offer and all visits whenever the proof is inconclusive, any trial touches the existing boundary margin, or evidence changes. Verify the originally-scored containing and missing-offer decisions and count every rejected shadow's added work. No threshold may use location, expected answer, case identity or comparator outcome. Omitting observations during nomination changes the ranked model input, so an independent verifier cannot rely on a nomination already computed over those same visits. For an exact rank-stage shortcut, upper bounds covering every ungenerated or unevaluated competitor would require their own experiment and costing. Any later timed work needs a new frozen protocol on the shared single low-priority Gauss slot.
