# Optional wider likelihood in the named CLI

The named CLI now accepts `--wide-private-likelihood LIBRARY` with `--wide-private-likelihood-sha256 DIGEST`. The existing stock likelihood handles every call first. When it reports an unsupported layout, the option retries through the width-eight implementation and retains the original dense fallback if the retry fails. The option runs inside original inference. Selected-packet reconstruction, grid and figures use the stock ports. The constrained and optimized-publication options remain independent. ## Executable provenance and cost

Build the reviewed overlay with `named_wide_likelihood.py NEW_BUILD_DIRECTORY` in the installed release's pinned interpreter. Pass its `private_width.so` and a separately trusted binary digest to the named CLI. The CLI hashes the bytes, verifies the matching manifest and regenerated C source, and loads a private copy. Changing the library and sibling manifest leaves the independently supplied digest check in force. The executable is operator-trusted native code. A matching manifest records the claimed build source and does not authenticate the compiler or executable independently.

The reusable build took **0.583 CPU / 0.627 elapsed s** separately. Verification and copying took **2.118 ms CPU** inside the candidate's published process clock. Charging the entire build to this one candidate would put its elapsed cost at **18.508 s**. The option records its implementation and library digests and native attempt and activation counts in the research receipt.
