# Reading orbital element records in one native pass

The saved profiles showed over a million individual element-line checks in the earlier DS30-0374 solver. For a canonical three-line element record, the prototype validates both line widths, prefixes, checksums and catalogue numbers in C, then constructs the same immutable Python record as the reference reader. It handles numeric and standard Alpha-5 identifiers. Other input formats and suspected errors are passed to the original parser, including the complete original input for error reporting. The SGP4 model, archive reads and digests, cutoff rules, candidate selection and numerical precision are unchanged.

| Saved input | Catalogues / validated records | Original → batch preparation CPU | Original → batch solver and grid CPU |
|---|---:|---:|---:|
| DS30-0016, physical | 22 / 226,811 | 2.663 → 2.365 s | 4.556 → 4.156 s |
| Northern simulation, 100 m inside its square | 25 / 260,578 | 3.096 → 2.789 s | 6.887 → 6.452 s |

The initial numeric-only version fell back on every catalogue. The archives include objects with Alpha-5 identifiers. After adding those identifiers, every catalogue in these two runs used the native path. Catalogue preparation saved **0.298 and 0.307 CPU seconds**. Each table row is one timed pair, with reversed order between recordings. The total solver time includes work outside the changed function. Archive history, forecasts, orbital source receipts, both calibration decisions, all trims, RF RMS, assignments, optimizer paths and numerical grids matched. The reader's shortcut depends on the representation of a record and has no location or satellite whitelist. Build for the release CPython ABI with `cc -shared -fPIC -O3 -Wall -I"$python_include" tools/pipeline_eval/variants/experimental/tle_records.c -o _leo_tle_records.so`. Obtain the include directory with `sysconfig.get_path("include")` in that interpreter. On Gauss the tested SHA-256 was `4bdfbfd2440253a624ac2eab3886be48639e9668f58566e2f5edeffc50de469d`. The saved-detection trial takes `--record-parser PATH` in `table` mode. The isolated publication freezer takes `--tle-parser PATH SHA256`, pins both sources and the binary, and loads verified bytes from the child process's private directory. The tests cover Alpha-5, mixed supported formats, alternate line endings, corrupt inputs and pins.
