# Prespecified frame covariance screen

The earlier periodicity screen measured the largest pairwise correlation among five 40,000-sample blocks before receiver processing. This experiment instead reads the fourteen-row covariance already computed after the packed receiver's input conversion, recentering, quarter-rate FIR and per-row RMS normalization. It tests that statistic separately on the original lane and on the actual signed, canceled residual. The frozen 950c receiver remains the reference. [Earlier periodicity experiment](cost-checks.md)

For each timing pass, record the largest covariance eigenvalue and the sum of the two largest, both divided by the covariance trace. These are the energy fractions in the first and in the first two normalized frame modes. Measure CPU through eigendecomposition separately from the rest of the lane call. The candidate gate returns the normal unconfirmed scan result before mode assembly and timing or CFO search when both fractions are at or below their respective white-noise thresholds. No proposed factor or site data enter the gate. A zero or nonfinite covariance goes through the existing search.

Set the thresholds from 256 independent synthetic noise windows per pilot edge. Use NumPy's `default_rng` seed `30261991` and round independent standard-normal real and imaginary samples scaled by 256 to signed IQ16. The same production FIR and frame normalization process the synthetic windows at center offset zero. Each threshold is the element at rank `ceil(0.95 × 256)` of its ascending marginal noise statistic. Fit both thresholds before reading any evaluation I/Q. The two marginal thresholds are a white-noise compatibility heuristic. Decimation, shared frame support, actual receiver noise and interference preclude a general false-negative guarantee.

The exact covariance bound is spectral. If the centered, normalized frame matrix is (A), each unit-norm template (p) satisfies (|Ap|^2 \le \lambda_1(AA^*)). The same inequality holds for the leading-mode projections of that template. This bound concerns the normalized low-rate frame aperture. The verifier checks separate relative scores and signed gates on the original samples, so a small trace fraction does not establish that its threshold cannot be reached.

The prospective physical panel comprises all 30 available visits of DS29-0082, DS29-0174 and DS29-0519 in the 80-visit prospective archive. The weak panel comprises all 18 saved DS26 challenge visits, from separate recordings. Keep both antennas together, reject any duplicate I/Q digest across panels, and use the first 40 scheduled visits of each existing public simulation as separate development checks. Replay the ordinary continuation separately for each case and arm in the archive's order. This split makes no claim about a second physical station.

Use two alternating call-order repeats with four arms: the frozen 950c binary, an instrumented unmodified scout, a gate on the primary pass only, and a gate on the residual pass only. Measure complete native call CPU, including work through the gate, cancellation, verification and any still-required search. The instrumented unrestricted scout must reproduce the frozen factor tuples and continuation state exactly. Each gate is a separate go/no-go candidate. Any lost, added or changed factor or continuation decision rejects that gate. At least a 5% reduction in native CPU on the prospective physical panel is needed to advance a factor-preserving gate. Report all results, including cases with zero selected continuations.
