# Eight retained visits followed by eight skipped visits per RF

The trial asks whether one reduction in waveform processing can also reduce the number of observations entering association and fitting, while preserving the position. Each physical RF has its own counter of valid visits. Keep both antennas for eight successive visits, then skip detection for eight. The burst allows the causal carrier selector to accumulate the three earlier observations required for a continuation vote. Every raw window still passes through the released decompressor, integrity checks and timestamp validation. The algorithm receives the original sample counters and recorded clock. It cannot use the offered region or the scoring coordinate to choose visits.

The development case is the previously published northern simulation with its containing offer. Compare against deployed ALGO08v2 starting from the same 1,200 sealed visits. Use the frozen exact detector, compressed-input buffering and the combined solver. Run the candidate first and time the full normal publication. Count the scheduled skips separately in the research receipt. The plots show only evidence the receiver actually processed.

For this one-recording screen, a lost fix, an increase in horizontal error in either calibration arm, or incomplete publication precludes escalating this design to the four-recording panel. Report the full timings even if it fails. This is a developmental falsification test with an already published reference, and provides no blind confirmation. [Release scores](../regional-release/blind-scores.csv)

**Result: rejected at the first recording.** The candidate read all 1,200 windows, ran detection on 624 and skipped 72 on each of eight channels. It retained 144 post-continuation antenna factors from 72 visits. The full receiver retained 456 factors from 228 visits. Compact v5 withheld both positions with reason `no_active_curvature`. The deployed build returned both fixes and eight PNGs. Elapsed time was 33.58 seconds baseline and 8.83 seconds candidate; CPU time was 33.43 and 8.69 seconds. Withholding removed much of the solver and publication work, so this ratio receives no credit toward the speed target. [Measured pair](measurements/north-bursts.json)
