# Wrapped scout refinement on three archived DS30-0008 lanes

The first fractional CFO change on all three lanes appeared in the floating-FIR PGO build `cc06336a`. Each winning request entered the scout's wrapped-epoch `delay_refine` path with the same inputs as the pre-PGO build. Compiling only `delay_product_kernel.c` with the pre-PGO flags restored the deployed scout and exported timing fields exactly on the three selected lanes. The candidate retains the packed signed cancellation object byte for byte.

## Saved receiver comparison

The experiment replayed only visits 2661, 3298 and 3869 from the sealed DS30-0008 stereo archive, on the lanes and channels below. The trial verified the scan binding, segment manifests, decoded I/Q digests, paired raw authority, lane, channel, valid sample counter and RF center before comparing rank 0. It matched all six exported primary fields bit for bit at both historical endpoints, `f37673f0` for the deployed baseline and `d44c6032` for the paired covariance candidate. The endpoint detection digests, twelve native binary digests, I/Q digests and factor readouts are in the receipt. ## Native refinement boundary

The diagnostic wrapper forwarded the archived native calls and recorded their inputs and outputs. The traced run reproduced every factor and scout output from the uninstrumented run. Per visit, the full-rate Float32 I/Q, decimated FIR output and pilot slice were byte-identical across five tested builds from `c5fca3e2` through the restored candidate. The four ordered refinement requests were also identical. The first request was the winner in all three visits and the sole request with seed epoch zero. It entered the scalar wrap path through `delay_refine`. Its fractional epoch, CFO and scout score changed at `cc06336a`. Its integer epoch and the other three refinement results were exactly preserved. The first observed divergence occurs at the native wrapped refinement output, before peak gating and fractional verification. ## One-object correction

The archived effective `delay_product_kernel.c` in the first PGO and paired covariance stages has SHA-256 `d014fe0670ff7a926bbd302ada1f4d021fe2f488f91b32dae8b4fe1634a07f1c`. The correction first relinks the archived paired covariance objects and the packed `pilot_cancel.o`, requiring byte-identical reproduction of `88b4f3ba6479b287cd581c604afa796992a2e6c7cbd34761d176f24500123f03`. It then compiles the same effective delay-product source using the standard flags from `native/algo08v2/build.json`, including `-O3`, `-fopenmp-simd` and `-ffp-contract=off`, with no profile feedback. It reuses the same linker command and order, changing only the delay-product object. The build receipts include the complete commands, compiler version, header digests and a digest for every object in both libraries. [Rebuild driver](receiver_cfo_restore_object.py) · [Restoration receipt](measurements/receiver-cfo-lineage-restoration.json.gz)

The output is `/tmp/leo-algo08v2-2x-bench/receiver-cfo-lineage-fix/restored.so`, SHA-256 `6f2cc95d835ffcff8226a925dddca9d5b03d8fe6b06c159b165ac0807b805a91`. The correction recovered all four refinement output rows and the complete deployed scout output on each selected lane. Its exported rank, integer epoch, fractional epoch and CFO were bit-identical to the original receiver. The largest remaining primary exact/control score difference from deployment was about `2.34e-14`. The correction is a whole translation-unit substitution with no site condition. The three selected lanes establish local attribution. Runtime cost and generalization to a full receiver run remain unmeasured. ## Reproduce the bounded check

Use the ALGO08 release Python environment with the worktree and release on `PYTHONPATH`. Run the builder with the output directory, `/tmp/leo-algo08v2-2x-bench/site-free-mode-pair-pgo/candidate/objects`, and `/tmp/leo-algo08v2-2x-bench/c803-packed-cancel-trial-v2/candidate`. A diagnostic build can compile `receiver_cfo_refine_readout.c` with `cc -Wall -Wextra -Werror -shared -fPIC -O2 -I tools/pipeline_eval/variants/experimental`. Pass that library as `--refinement-probe` with `--correction` to the trial. Run the raw-reader invocation as the `leo` service account with the paired receipt at `/tmp/ds30-v2-stage-covariance-375895/DS30-0008/pair.json`, its two archived `detections.json` files, the DS30-0008 binding, release assets, the benchmark root and `/srv/bulk`. Each invocation verifies the three selected window digests, with at most a 64-window decoded prefix of any selected compressed chunk. All physical reads and native measurements ran under the Gauss benchmark lock on CPU 2 with low scheduling and I/O priority and one BLAS thread.
