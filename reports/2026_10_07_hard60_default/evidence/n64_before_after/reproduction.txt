Existing outputs require the file owner's access. Do not alter a frozen protocol
to silently accept new code or changed inputs. A changed experiment belongs in a
new report directory. The documented association migration is the one exception
within this report: it archives the pilot, retains unchanged grid computations,
and repeats all final fits with one common association implementation.

The old cohort labels contain N01--N80. This report follows the user's literal
N01--N64 request. It does not substitute the older 64-extension set N17--N80.

Timing names: sigma is the satellite-relative timing prior in seconds. The common
timing prior stays at 3 s. Slope terms are Hz/s. The +/-60 hard box applies to
each fitted stage's affine terms; the frozen calibration plus final correction
and piecewise residual drift are reported separately, without claiming a hard
limit on their sum.
