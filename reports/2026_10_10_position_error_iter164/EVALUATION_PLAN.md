# Full193 evaluation and publication preparation

This reporting work is separate from the already frozen numerical protocol.
It performs no new localization fits, recording reconstruction or RF collection.
Before execution, bind its exact source and tests in `evaluation_protocol.json`
and publish that protocol to remote main. `evaluation.build` refuses to run
without this separate evaluation protocol.

Require every one of the 193 members to have terminal search, native and
zero-led receipts: 579 phase receipts. Authenticate protocol, member and branch
identity; reject undeclared fallbacks. Authenticate both controller claims and
terminal receipts for every resource batch, exact membership/order and matching
phase statuses. Hash all retained raw JSON evidence, including unfinished
intermediate attempts under explicit failed phases. Such attempts remain
failures, never authorization to retry. A live, missing or controller-failed
member blocks cohort geographic evaluation.

Use the inherited 129 summary and 107 geographic evaluation ports only after
this gate. The adapter changes the sealed population from twelve to 193 and
the discovery branch name from fixed to zero. It does not change selected fits
or perform another optimization. Evaluation documents must match sanitized
session/input/analysis/evidence identities and the inference prior. References
remain evaluation-only. Preserve per-endpoint evaluation errors explicitly.

Report DS16, DS17, DS18, newer development and the full193 membership separately.
For each final c arm, compare the matched native and zero-led discovery policies.
Within each discovery policy, also compare matched c=0 and fitted-c finals.
Report mean, median, p95, worst, all paired deltas and regressions. Full-member
metrics require every pair; otherwise show an explicitly labelled available
paired subset and every missing label. Frequency objectives, RMS, qualification,
stage/bank changes and runtime are separate descriptive evidence, not substitutes
for geographic accuracy. No winner is selected by reference error.

Publish Markdown, coverage/failure tables, machine-readable summary and static
plots of per-member position errors, paired changes, and distributions. Preserve
all exposure metadata: this is consumed development, not independent validation.
The historical deployed-policy comparison remains a distinct comparator; do not
splice recovered endpoints into its official mean. This single-pass study does
not by itself establish deployed multiseparation B7 parity or justify rollout.
