# Geometry and the unresolved bandwidth

The actual production horizon is `dot(direction, up) >= 0`, where `up` is the WGS84 ellipsoid normal. It is not geocentric radial up or an antenna cone. See `src/leo/analysis/_regional_orbits.cpp:25–27` and `regional_position_score.py:52`. Satellite position and velocity arrays are independently linearly interpolated. Consequently the derivative of position for an orbit-time shift is `(position[hi]-position[lo])/node_step`, rather than the independently interpolated velocity. Using velocity here would differentiate a different model.

Let `d = (p-r)/D`, `m = d·u` and `a = (u-md)/D`. Then `dm/dx = -a·dr/dx + d·du/dx`, and `dm/dt = a·dp/dt`. Both observer position and normal derivatives are needed. `geometry.py` implements this exact chain rule given physical inputs; its tests include normal rotation and central differences. A research adapter should obtain site and normal from the same production `observer(prior, candidate_point)` and differentiate both with the same 1 m symmetric spatial step already used by `hard60_score.predict_orbits`. The bank, observation times and total satellite orbit shifts must match the frequency predictor. No reference receiver coordinate is needed.

The source-only compact cubic gate is zero for `m <= 0`, one for `m >= width_sine`, and C1 in between. Its slope combines with the likelihood visibility gradient from `soft_visibility.py`; the frequency-gradient chain remains separate. A timing gradient therefore gains `sum(dNLL/dv * dv/dm * dm/dt)`, and spatial gradients gain the analogous two components. RF calibration and receiver clocks do not directly alter geometric visibility. Satellite/common timing do. Below-horizon emission remains forbidden by this candidate law; it represents an effective rising detectability response above the geometric horizon, not a symmetric uncertain-horizon posterior.

**No physically identified numerical width is available yet.** Causal TLE epoch age is provenance, not an orbit covariance. Node spacing is known, but linear interpolation spacing alone is not an error bound without a validated acceleration/trajectory bound. A fitted clock offset or slope is not independent timing uncertainty. Receiver sample rate and sample timestamp quantization can bound quantization, but do not establish antenna horizon response, clock synchronization error, terrain obstruction, refraction or orbit prediction error. The existing boolean prediction contract supplies none of those uncertainty distributions. Choosing a width from position errors would violate the evaluation-only rule.

The lean next experiment is therefore to first declare a physical response model and an independently specified width or bounded sensitivity family, before any outcomes. A uniform marginalization over an explicitly bounded horizon offset yields a different (two-sided) gate and requires its own physical support rationale; it should not be silently substituted for the positive-elevation gate. If no independent width can be justified, retain the hard horizon and test event-aware one-sided feasible steps instead. Either experiment must keep matched c=0/fitted-c observations, bank, starts, priors and budget, retain the unchanged hard control, and compare frequency effects separately from postfit position accuracy. Current prototypes make no accuracy or production claim.
