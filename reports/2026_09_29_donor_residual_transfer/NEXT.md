# Next: resolve RF comparability before broader residual transfer

Unexecuted proposal. Exact receiver/RF matching leaves two dependent cases.
There is therefore no geographic-promotion evidence for the current rule.

First inspect RF provenance and frequency normalization in the public track
exports. Recorded RF values include both nominal tunings and slightly shifted
values. Determine from the actual exporter and capture contracts which changes
represent a different measured band, a tuning/reference convention, or numerical
rounding. Do not invent a tolerance from the held outcome or treat different
bands as interchangeable without a model.

A distinct statistical hypothesis, if the units support it, is a candidate
residual excess above a contemporaneous receiver/RF baseline. Within each donor
group, compare the candidate's slope with other-candidate slopes at that donor's
own RX/RF. Transfer only the candidate-specific excess, and compare target
forecasts against an independently estimated target-RX/RF baseline. This differs
from assuming a raw satellite slope is constant across receivers and bands.
It needs its own frozen eligibility, at least two independent donor groups,
strict chronology and candidate-label controls before any scores are produced.
The current result is exploratory motivation, not confirmation of that model.

Donor geographic error and evolving element sets can still masquerade as a
candidate-specific residual. A useful frequency-error diagnostic must therefore
pass a normalized held-mixture check before any geographic refit, preserve all
targets and state the historical calibration budget. DS7's unsupported targets
still need a separate mechanism.

The alternate track-contamination direction in the donor-weight report remains
available: audit independent pilot/known-symbol feature provenance and baseline
training-visit isolation before allowing waveform evidence to change mixture
priors. Neither short-excerpt pilot failure nor symbol clustering is a satellite
identity or non-satellite label. Do not repeat the failed pilot-frequency point
refinements or collect new RF under this proposal.
