# Spend saved compute on a bounded iteration extension

The optimized-acquisition comparison preserves all three unresolved first-start singles. Their objective histories still decrease near iteration 64, while cold inference takes 19–22 seconds. Hypothesis: allowing up to 96 iterations can recover some of these cases within the existing 90-second process budget, without changing already-converged results. Convergence and geographic accuracy remain separate outcomes.

Freeze six single-scan cases: successful controls DS9-B01-S1, DS10-B01-S1 and DS11-B01-S1, followed by unresolved DS9-B05-S2, DS9-B05-S3 and DS11-B04-S1. Controls must preserve their accepted fits before unresolved cases run. These are exposed development controls and failure-selected cases, not a representative new test set.

Version the existing one-start worker with only the two 64-to-96 changes: reported maximum iterations and the fitter's maximum-iteration argument. Compose it with the same optimized acquisition and preserve startup timing. Structural tests must show that acquisition, priors, observations, height, start count, optimizer, deadlines and all other behavior remain unchanged. Both the original 64-iteration worker and every prior receipt stay immutable.

Each new run acquires from scratch and initializes nuisance coordinates to zero. Keep one start, original eight-point evidence, nuisance priors, uniform 250 km Sacramento disk, fixed 100 ft MSL height, 50-second acquisition deadline and original 85-second internal / 90-second external inference limits. Each separate audit also has a 90-second process cap. Run sequentially under the shared lock. No retry, fallback, tolerance relaxation or additional fitted start.

Compare to the sealed optimized 64-iteration receipts from the completed single-composition controls and failure-composition cases. Require identical model/input bindings and configuration apart from max_iterations=96, exact proposal seeds/counts/spacing, proposal scores within 1e-6, and the complete original objective history as a prefix within 1e-6. Controls must retain their whole history length, state within 1e-5, exact labels, convergence flag, reason and iteration count. For unresolved cases, subsequent state/assignment changes are allowed and reported; finite-difference gradient and stationarity thresholds remain unchanged. Do not call prefix agreement a check of intermediate states, which were not recorded.

Report all six outcomes, numerical acceptance before reference errors, iteration counts, full observed inference CPU/wall time, changes to endpoint assignments and control equivalence. Old-versus-new timing is historical, not a freshly paired timing experiment. If controls fail, stop expansion and diagnose. If an unresolved case remains rejected, preserve it without scoring or replacement. A passing pilot does not by itself establish a fresh full-panel acceptance rate or warrant production promotion.
