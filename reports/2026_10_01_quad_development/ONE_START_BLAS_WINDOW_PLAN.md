# Multi-scan composition extension

The single-scan composition pilot passed all six audits/equivalence checks and reduced observed wall/CPU cost. Extend the same computational change to first pairs and quads from each dataset: DS9/DS10/DS11-B01-D1, then DS9/DS10/DS11-B01-Q. No statistical-model change or geographic selection.

Stage prerequisites by window size. For each window compare all per-track finite/visibility masks and scores, plus the sum of marginalized acquisition scores, at nine fixed Sacramento-prior points and the original acquired seeds. Then run the full optimized acquisition and require identical seeds/requested count/unique count/spacing with proposal scores within 1e-6 of the saved original. Verify source/input hashes. Per-window prerequisite process caps are 90 times scan count seconds; acquisition caps are 50 times scan count. No fits or reference scoring run in these prerequisites.

Only after all three pair prerequisites pass, run paired fresh-process one-start inference with original versus optimized acquisition. Require completed single-pilot gates as well. Pair order is optimized/original for DS9, original/optimized for DS10, optimized/original for DS11. Both arms use unchanged workers and seed limit one, acquiring anew with zero nuisance initialization. Keep the original likelihood, eight-point evidence, prior, height, optimizer and 64-iteration limit. Inference and separate audit process limits are 180 seconds per pair arm. Freeze sources/inputs before launch; retain all failures and no retries.

Inspect all six pair outcomes and their process/numerical/proposal/saved-fit equivalence checks before any quad prerequisite or fit. If they pass, repeat for the fixed quads with order original/optimized for DS9, optimized/original for DS10, original/optimized for DS11 and 360-second per-process limits. The same original state/objective tolerances (1e-5 and 1e-6), exact labels and independent numerical audit apply. All runs are sequential under the shared lock. A failed gate requires diagnosis rather than automatic expansion.

Report wall and CPU cost separately, all acceptance and equivalence outcomes, and error differences only after auditing. Compare fresh paired arms; do not combine historical percentage savings. Each arm has one timing measurement, so this is a bounded development demonstration, not a randomized runtime distribution or geographic generalization test. Do not replace production or overwrite historical results.
