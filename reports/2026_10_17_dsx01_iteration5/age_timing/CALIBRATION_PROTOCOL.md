# Causal orbital-update consistency

The cutoff is the earliest DSX01 source start, 2026-10-16T16:15:42.609910Z (1792167342609909833 UTC ns). Only local archived snapshots collected strictly before it are eligible. No radio values, fitted timing offsets, station locations, candidate hypotheses or reference positions enter this calibration.

For each provider separately, take the latest causal payload and snapshots nearest-earlier to fixed lookbacks0/1/3/6/12/24/48/72/120/168/336/720 hours. Deduplicate identical payload hashes. This uses at most12 distinct snapshots/provider and does not guarantee coverage of every archived payload. Common objects are selected by names beginning STARLINK-, with at most1024 uniformly spaced sorted catalogue IDs per old/new pair. No named target ID is inserted.

The provider's latest selected snapshot is the common consistency reference. Only entries with a strictly newer element epoch in that reference enter the primary comparison; counts of identical and reversed element epochs remain visible. Both models propagate at the reference snapshot's collection epoch, before the measurement cutoff, using public parse/propagation ports. Invalid old/new/joint counts are explicit. Signed old/new element ages, both collection times and both element epochs are retained.

In co-rotating ECEF coordinates, delta_r is old minus newer-reference position. Effective along-track seconds are delta_r dot v_new / |v_new| squared; the orthogonal remainder is reported in kilometers. This is a local linear displacement diagnostic, not a time correction applied to any orbit. The newer element set is not truth. Reference errors, maneuvers, update latency and correlated errors can all contribute; all comparisons sharing the latest reference are statistically dependent.

Provider-separated age bins are0/.25/.5/1/2/4/8/16/32/infinity days. Report signed center, MAD-based core scale, absolute and centered tails, perpendicular residuals and diagnostic counts above1km perpendicular or1s along-track. Those thresholds are descriptions, not filters or a hardware maneuver detector. Do not infer a calibrated physical uncertainty or seconds/day law from age correlation alone. CelesTrak's [2025 SDA TAP Lab talk](https://www.celestrak.org/publications/SDA-TAP-Lab/2025/) also emphasizes that orbit behavior and maneuvers matter to the relationship between age and prediction error.

Source and selected snapshot metadata freeze before archive payload reads. Local reader checks each payload digest. Internal calibration deadline100 seconds, external TERM120/KILL125, zero localization objectives/fits. Three component tests check causal/deduplicated sampling, projection units and target-independent constellation/ID sampling. A later relative-timing prior requires its own declared width rule and qualification; this consistency experiment does not choose widths from DSX fitted tau or localization outcomes.
