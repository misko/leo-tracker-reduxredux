# Review scope — 2026-10-25

This iteration reviews existing fast-scan evidence and performs bounded,
read-only identity and residual-gate diagnostics. It does not select a new
localization algorithm or rerun a broad position campaign.

Three SOL xhigh tasks cover four archived new-family nominees, real-data ACF
rejections, and prior identity/uncertainty experiments. Compute for either
diagnostic is capped at five minutes; no new RF, post-scan TLE inference, GPS
selection, production edit, or gate change is authorized by this protocol.
Existing operational estimates remain unchanged. Geographic results in the
review are previously published evaluation results. If any localization fit
becomes necessary it must use matched c=0/fitted-c controls; none is planned.

The synthesis must separate measured accuracy, local unavailable-information
controls, unresolved hypotheses, and proposed future experiments. It must
retain negative results and explicitly distinguish single-owner conditional
compatibility from validated satellite identity. The current 24 usable DS24
scans have all been exposed to geographic evaluation; none is a fresh holdout.

Review inputs include the channel-half and bottleneck reports; receiver/orbit
controls; movement-policy validation; new-family uncertainty; and fast
identifiability. New artifacts go only beneath this study directory. Remote
publication uses the existing clean publisher, preserving unrelated work.
