# Pilot filter replay protocol

Use DS26-0036 and DS29-0082 with their respective verified installed capture-era worker source, release digest and policy. Profile the existing accelerated detector on local sequences 0 through 3 of segment 3 in each recording to identify the remaining cost. Keep those windows out of the timed confirmation. The confirmation uses local sequences 1, 3, 5 and 7 in each of segments 5 and 11. Keep invalid-capture windows and report them separately from valid-window timing. The two segments provide distinct times within each recording. The recording remains the unit of transfer.

Both arms use the same decoded IQ, receiver order, policy, epoch grid, CFO grid, pilot symbols, refined scores, thresholds, and existing peak-selection and fractional-sampling optimizations. The candidate changes only how the coarse filter bank computes its grid. It accumulates the four real products of each complex dot product independently, then combines them to form the real and imaginary result. This gives the compiler four fused multiply-add chains with their intermediate values held in registers. It can change single-precision rounding. A development-only trial on generated IQ found that loading IQ for two filters together was slower and was dropped before confirmation. Compile the baseline and candidate libraries with the same compiler options. Capture a profile of the baseline separately from timing.

Time three paired repeats per window with one CPU of affinity and one thread per numerical runtime. Alternate the first arm by window and repeat. Decode and authenticate input outside the detector timer. Report valid-window medians and P95s of CPU and wall time, and distributions of paired ratios using the median of each window's three ratios. Treat repeat timing as replication within a window.

For every pair compare the canonical payload of the complete fast-scan result, including capture status and reason, receiver order, ranked integer peaks and frequency, all integer and fractional scores, fractional status, and integer and fractional margin decisions. Check retained coarse peak epoch and CFO in an extra untimed pass. After timing, independently audit the selected fractional observations and capture exclusions against the archived producer outputs. Any mismatch remains in the result. Release a detector-equivalence claim only if each payload and peak key agrees. Report any coarse score differences as well.

If the complete outputs agree, splice only the selected authenticated windows into the stored detections and run v5 on both composites with matched `c = 0` and fitted `c` settings. Both composites use archived detections outside the panel. Report position errors and Doppler RMS separately. The claim covers the measured partial-IQ boundary. A full original-rate raw-IQ replay and board real-time measurements require separate evidence.
