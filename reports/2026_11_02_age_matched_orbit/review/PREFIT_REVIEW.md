# Independent pre-fit review

The implementation is ready for the prospectively approved bounded experiment.
This is a same-site development comparison of a fixed revision proxy; no orbit
covariance calibration or independent predictive validation is established.

- `inventory_audit.json` independently binds all 205 cases to the previous RF
  ledger and generic nominations. All 30 ready priors reproduce the exact causal
  source receipts, maximum disjoint age matching and fixed covariance arithmetic:
  five satisfy the primary three-pair rule; 25 satisfy only the exploratory
  two-pair rule. No selected family was reranked.
- Historical coefficients use physical mean motion, inclination and RAAN at each
  historical newer epoch, then the current declared SDs. Current physical columns
  reproduce the existing bank within the prescribed tolerance. The prior mean
  stays zero; `.5 I + .5 E[aaᵀ]` is bounded to eigenvalues `[1, 16]`.
- `construction_invariance.json` records exact FRSH-0001 covariance/receipt
  equality after poisoning CFO values and making RF methods, tracks, saved
  endpoints, owners and GPS-like fields inaccessible. This reconstruction did
  not optimize a position. The model owner's separate actual-context audit
  changes only the target's three existing physical columns in both c arms.
- Strict-issuance archive preprocessing excludes held newer elements. All 145
  nominated satellite families are connected through shared snapshots, leaving
  one independent group. The 25-forecast auxiliary density comparison therefore
  remains descriptive, includes the Gaussian volume term, and scores only the
  three represented coefficients. Its residual state error is reported separately.
- The runner reuses one paired endpoint per supported case for Age3 and Age2.
  The original fitted-c start/reference, observations, owners, other priors and
  maximum budgets are shared across c arms. Adoption requires paired numerical
  qualification and the prospective support count; RF objective differences
  remain diagnostic. Every failure falls back to the exact saved selected A.

The independent result auditor is `audit_age.py`. It will verify frozen hashes,
the whole 205-case ledger, per-case and raw-cell receipts, covariance reconstruction,
numerical qualification, matched c arms and exact policy fallback before new
geographic evaluation. Four auditor tests and two cached diagnostic tests pass.
No scientific review source has pending edits.
