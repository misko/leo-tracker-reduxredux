# DS10 pooled N24 relative-scale weighting pilot

Begin with the fixed DS10 N24_h0 panel, using its original qualified location/timings as the single initialization for each of two arms. Preserve all 1443 tracks, masks, candidates, zero height and q020 mixture. Use only the donor-fitted RX0/RX1 calibrations from the completed common-transfer experiment and target training-only paired-difference features. Do not use target held errors or reference distance to select scales.

For each supported track, compute each paired feature's relative scale `exp(a+b log(feature)-a_constant)` for its RX and use the median log ratio across its pairs. Unsupported tracks retain ratio one. Freeze these ratios before fitting. The variable arm uses each track's ratio. The constant control applies the median log ratio per RX across the same supported tracks, leaving unsupported tracks at one. This matches population and typical scale while removing track-specific variation. No clipping or post-result tuning.

Implement a normalized likelihood: transform observations and candidate predictions by dividing by each frozen ratio; retain signal noise 100 in transformed units; divide background slope-prior scale 2000 by that same ratio. Restore the contrast-density Jacobian for training and held scores. This is equivalent to a track-specific noise scale 100*ratio with unchanged physical background slope prior. No slope correction is subtracted.

Test unity equivalence, direct-density/Jacobian agreement and gradient agreement on synthetic tracks. Verify unity replay on the full real panel. Then use the unchanged original L-BFGS helper and scientific gates, with one process per arm capped at 180 seconds, no retries. Report absolute held likelihood under each fitted model and original-model held likelihood at each new position. Do not select or promote based on reference distance. This is an exposed-data research pilot, not equal-budget independent generalization or certified accuracy. No new RF, export, propagation or production change.
