# DS21-039: next four investigation priorities

The target remains below 0.5 km on every eligible CH1–8 DS21 recording. It is not achieved. DS21-039's original joint-model errors were 3.759 km for CH1–4, 2.557 km for CH5–8 and 4.291 km for CH1–8. Seven stationary warm continuations improved the training-selected all-band result to 4.073 km. This demonstrates an optimization deficit but leaves most of the position error unresolved. See the [existing investigation record](README.md).

These priorities update the original four directions using the completed negative controls. They do not authorize reference-derived seeds, per-case model selection, or changes to frozen experiments. New science retains fitted `c` only.

| Priority | Direction | Evidence and next discriminating test |
| --- | --- | --- |
| 1 | Preserve the physical corrections when combining bands | The DS21-013 saved-function diagnostic found that separate band slopes and shared-clock curvature cannot be represented by successive receiving models. Removing bounds does not remove the loss. First establish whether the same incompatibility occurs on DS21-039, using its own training frames and saved functions. If confirmed, compare a narrowly specified compatible representation against the original under matched starts, observations and budgets. Report held-block prediction and position accuracy separately; accurate reproduction of a seed is not proof that the seed is physically correct. |
| 2 | Separate satellite timing, calibration and position | DS21-039 timing/calibration profiling reduces the weakest position curvature by roughly 140–300 times. Finite-displacement and nuisance-profile checks retain asymmetry. Identify which parameters and observations constrain this direction, then test a physically supported timing parameterization with synthetic recovery and held-block prediction. Do not tighten timing priors merely to improve reference error; fitted time shifts are not measured orbit errors. |
| 3 | Resolve satellite and frequency-ambiguity disagreement | Full-band and half-band fits change a material fraction of satellite/clutter assignments. Existing temporal grouping lacks persistent emitter identity, and the tested temporal and detector-prior controls did not improve accuracy. Separate changes in geography, calibration and timing when examining posterior changes; identify training-supported candidate exclusions or ambiguity mistakes before changing the association model. Any association intervention must retain an unchanged-bank control and be evaluated on held observations. |
| 4 | Distinguish incomplete search from an inadequate objective | DS21-039 has a demonstrated missed feasible objective, but refinement alone leaves approximately 4 km error. DS21-013 independently exposed a severe initialization coverage failure: improving coverage recovered all-band results from approximately 267–269 km to 1.51–2.02 km. Audit DS21-039's candidate coverage, seed domains, stationary endpoints and objective ranking. Apply an unchanged-policy coverage transfer before inventing further optimizer heuristics, and distinguish better search from changing candidates or priors. |

SOL agents own evidence review and experiment implementation; root integrates and owns the bounded execution queue. Reviews and implementation can run in parallel. Heavy dataset experiments run one at a time so contention does not alter their time budgets. Each proposed numerical intervention needs its own frozen inputs, component tests, execution cap and retained failure receipts.

For direction 3, the smallest next experiment is per-window objective and posterior attribution at six already saved DS21-039 states: the original and refined endpoints and four fixed-position nuisance-profile outcomes. It needs no location optimization. Persist satellite/clutter and native-frequency responsibilities, support changes and per-window likelihood differences, with totals reproducing the saved objective. This would identify the observations behind the aggregate assignment changes before adding another model term.

For direction 4, the existing coverage runner accepts the generic parent chain available for DS21-009/011/013. DS21-039 has older receipt authority. Its transfer therefore requires a separately tested adapter that verifies the original inputs and source history; old receipts must not be relabelled as new-policy results. The current DS21-009 transfer comparison continues before that extension.

Generic reweighting is lower priority: equal-band, equal-block and combined weighting did not resolve DS21-039; quarter-likelihood weighting also failed the five-case transfer. A receiver-specific RF contrast slightly worsened accuracy. Those results argue against repeating broad sweeps without new evidence.

## Full DS21 acceptance sequence

1. Diagnose DS21-039 and test only evidence-supported changes on the existing development cases. Include matched CH1–4, CH5–8 and CH1–8 comparisons; explicitly identify half-band results that inherit all-band initialization.
2. Evaluate the selected candidate on all 34 fast CH1–8 development recordings. Preserve failures and report per-recording error, median, upper quantiles, maximum and the count below 0.5 km. A lower frequency residual alone is insufficient.
3. Freeze one algorithm and its selection rule before evaluating the 20 locked fast recordings. Reference coordinates enter after fitting and selection are sealed. No choosing whichever model is closest to the reference for each recording.
4. Publish all 54 eligible fast recordings, with failures counted as misses. The 54 adaptive CH1–4 recordings receive a separate coverage report; they cannot establish CH1–8 performance. Disclose any reuse of locked cases after a failed release.

Accuracy currently means distance to the configured reference, which is not independently surveyed ground truth. The 0.5 km requirement remains a release gate rather than a guaranteed outcome. No new RF collection is required for this plan.
