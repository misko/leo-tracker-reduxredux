# Twenty-seed synthetic position sensitivity

This bounded control replaces interpretation of one 300 Hz noise draw with a
predeclared 20-seed sensitivity distribution. It remains a shared-model
synthetic control, not real-position evidence, a calibrated confidence
interval, or an attainable-resolution claim. Sub-300 m real positioning remains
unproven.

The run reused the earlier control's 476 fixed known-identity tracks and 8,285
first-six TRAIN observations. For each seed from 2026092300 through 2026092319,
it generated one independent 300 Hz Gaussian frequency-noise vector. The paired
epoch case used that same vector and one independent sigma-0.3-second shift per
satellite, shared across its tracks and clipped at one second. All shifted
signals were generated by direct SGP4 at every exact shifted epoch from the
scan's recorded causal snapshot. Three of 2,360 realized satellite shifts hit
the clip.

The synthetic coordinate remained unavailable to the fitter. All 80 fits used
the unchanged corrected single-seed settings: fixed epoch zero, analytic
training-only CFOs, known identities, original prior disks, and starts at the
Sacramento and Reno prior centres. Coordinates, objectives, and convergence
records were sealed before truth or held residuals were calculated. All 80
optimizations reported success.

| Case and fixed start | Median error | P90 error | Below 300 m | Maximum error | Median train / held RMS |
| --- | ---: | ---: | ---: | ---: | ---: |
| 300 Hz, Sacramento | 319.6 m | 558.7 m | 45% | 772.8 m | 283.5 / 314.4 Hz |
| 300 Hz, Reno | 319.6 m | 558.7 m | 45% | 772.8 m | 283.5 / 314.4 Hz |
| 300 Hz + epoch, Sacramento | 449.7 m | 1,220.6 m | 35% | 1,630.8 m | 287.2 / 319.0 Hz |
| 300 Hz + epoch, Reno | 449.7 m | 1,220.6 m | 35% | 1,630.8 m | 287.2 / 319.0 Hz |

The starts agree to numerical precision, which is useful as an optimizer
consistency check. The distribution shows why the earlier 369.9 m draw must not
be treated as the model's resolution: even in the noise-only stipulated model,
the median is above 300 m, fewer than half the seeds are below 300 m, and the
90th percentile is about 559 m. Adding the stipulated satellite shifts broadens
the upper tail substantially. The shift distribution is a sensitivity input,
not calibrated orbit uncertainty.

No fit, seed, start, or case was chosen by geographic error or held frequency.
The earlier single shifted-seed control remains separate and is not included in
these summaries. No measured frequencies, VAL/TEST observations, new RF,
deployment, or full-catalogue search were used.

`materialization.json` records the generation method and source bindings;
`materialized.npz` contains all paired frequencies and realized noise and shift
draws without the true coordinate. `results/inference.json` is the sealed blind
fit artifact. `results/results.json` adds every post-seal error, held residual,
and the four predeclared summaries. `SOURCES.sha256` binds the full report.

Reproduction requires read-only service access to the causal TLE archive for
exact shifted propagation. From the repository root, use fresh outputs:

```bash
MULTISEED_REPRO_DIR="$(mktemp -d)"

sudo -u leo env PYTHONPATH="$PWD/src" "$PWD/.venv/bin/python" \
  reports/2026_09_23_long_position_synthetic_multiseed/materialize.py \
  --base-materialized \
    reports/2026_09_23_long_position_synthetic_control/materialized.npz \
  --base-receipt \
    reports/2026_09_23_long_position_synthetic_control/materialization.json \
  --cache-root /tmp/leo-long-training-cache-first16 \
  --tle-root /var/lib/leo/tle \
  --output "$MULTISEED_REPRO_DIR/materialized.npz" \
  --receipt "$MULTISEED_REPRO_DIR/materialization.json"

uv run python \
  reports/2026_09_23_long_position_synthetic_multiseed/fit.py \
  --materialized "$MULTISEED_REPRO_DIR/materialized.npz" \
  --materialization-receipt "$MULTISEED_REPRO_DIR/materialization.json" \
  --fixed-fitter reports/2026_09_23_long_position_synthetic_control/fit.py \
  --output "$MULTISEED_REPRO_DIR/results"

uv run python \
  reports/2026_09_23_long_position_synthetic_multiseed/plot.py \
  --results "$MULTISEED_REPRO_DIR/results/results.json" \
  --output "$MULTISEED_REPRO_DIR/multiseed_sensitivity.png"

uv run python \
  reports/2026_09_23_long_position_synthetic_multiseed/test_control.py \
  --inference "$MULTISEED_REPRO_DIR/results/inference.json" \
  --results "$MULTISEED_REPRO_DIR/results/results.json"
```
