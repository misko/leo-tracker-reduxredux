# Publication checkpoint

This experiment is **in progress**, not a completed DS8/DS9 validation result.
The [protocol](PROTOCOL.md) freezes selection and scoring. Preparation and partial
baseline execution files are preserved at this publication snapshot; partial
rows must not be treated as the complete selected cohort or an accuracy result.

ARM comparisons and a final report. Execution can continue independently of this
report publication.
