# Executable preparation

`freeze.py` is the explicit metadata-only freezer. Execution waits for protocol
publication after parent review/authorization. The frozen protocol binds the
same110/117 random12 identities, sanitized107 public documents, inherited123/116
numerical/native source closure and new129 sources. It omits research errors from
inference membership and rejects reference/error fields in public inference inputs.

After freeze/publication, `execute.py LABEL search` runs one shared search slice;
`execute.py LABEL native` and `execute.py LABEL fixed` run one branch continuation
slice each. `batch.py 0` and `batch.py 1` are two serial shards; launching both uses
two workers total. Pending slices may resume within the frozen caps, but terminal
failed/incomplete/exhausted attempts never automatically retry. A crashed batch
claim is not silently reused; preserve it and inspect corresponding phase claims.

Run in the production47e Python environment with `PYTHONPATH=src:.` and
`OPENBLAS_NUM_THREADS=OMP_NUM_THREADS=MKL_NUM_THREADS=1`. Each invocation verifies
the frozen source/input closure first. There is no original-coarse import, no
archived parity assertion and no recording collection.

The fresh native fit and bootstrap cache is shared between native/fixed discovery
queues. Each receives400 evaluations and returns exactly three regions at12.5km
separation. Native and fixed scores change queue order; final processing keeps
each branch separate. Physical case identity is recorded at first reconstruction
and compared on every subsequent search/continuation slice. The public loader
independently verifies observations/evidence/TLE/bank membership against the frozen
sanitized document. No reference coordinates participate in this admission.

All point exceptions remain durable; any failed point marks the complete search
incomplete and blocks both continuations explicitly. A failed retained calibration
or final stays in branch receipts. Selected outcomes use unchanged105/B7
qualification and regional winner rules. No fallback endpoint is imputed. Both
final c arms share fitted-led support within their branch; zero c locks are inherited.

each continuation branch. These are between-call soft budgets. Existing fit limits
are bootstrap5s, native coarse5s/200iterations, direct calibration90s stage reserve,
association60s, regional finals20s/600iterations, B7 stage fits90s/600iterations and
at most two qualification rounds/100evaluations. Timing sigma common3s/relative2s,
frequency sigma125Hz and hard60 are inherited unchanged. Maximum allocation across
