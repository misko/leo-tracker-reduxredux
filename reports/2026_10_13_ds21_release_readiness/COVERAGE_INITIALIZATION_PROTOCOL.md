# Coverage-conditioned original initialization and model comparison

The sealed 100-point coverage control supplies three proposals selected by the
unchanged training rule. This protocol fixes the downstream comparison before
any downstream dataset fitting. The original DS21-013 failure, original discovery,
model receipts and all frozen numerical sources remain unchanged. Reference errors
and post-seal error artifacts never enter initializer authority or selection.

`tools/ds21_coverage_initialization.py` is a new authority adapter. It reads the
complete coverage-control seal and original case, then unions the selected
points' full-bank indices in catalogue-number order. Shape fitting uses that
subset. Fresh bootstrap still uses the original full regional bank, allowing
the original candidate-union expansion. Fixed-pool cold bootstrap and physical
exports preserve the resulting union. The original 49-candidate pool is not
silently reused, and no legacy discovery protocol is fabricated.

The exact stage chain and original bounds remain:

| Stage | Original numerical work | Internal / TERM / KILL seconds |
| --- | --- | --- |
| Shape | Three fitted-c starts in each of three views; 20 s / 600 iterations each | 240 / 255 / 260 |
| Fresh bootstrap | Nine original five-second bootstrap calls at fitted shape parents | 90 / 105 / 110 |
| Hybrid | Nine fitted-c absolute-frequency fits; 20 s / 600 iterations each, original 25 km disks | 240 / 255 / 260 |
| Cold bootstrap | Nine original fixed-pool cold calls at the three coverage-discovery points | 90 / 105 / 110 |
| Six proposals | Ordered physical exports for all/low/high; no position optimizer | 90 / 105 / 110 |

All operations call the original numerical ports directly. The original training
partition, observations, RF/time centers, clock nodes, priors, per-view proposal
parents, bootstrap donor/fallback rules and fitted-only selectors are retained.
The export order is `cold-0`, `cold-1`, `cold-2`, `shape-low`, `shape-high`,
`shape-all`, with each source identity preserved in all three views. Hybrid
parents remain required diagnostics; they do not replace bootstrap seed exports.

Each stage has a separate new freeze, own source archive, exact completed
predecessor bindings and numbered bounded slice. Original case and full-bank
authority are checked before and after numerical work. Failed and nonstationary
results remain visible; serializable invalid returned data are retained with the failed call.
Missing required parents stop dependent work. Failed/orphan claims are not retried.
An intact checkpoint needs an explicitly numbered continuation, retaining completed
calls without repeating them. Cached terminals require complete slice receipts.
No held preparation, locked inference or reference access is part of these stages.

A separately qualified model consumer will be required before the final A/B/C
comparison, because the immutable model reader accepts only the historical
initializer policy. It must preserve the original six dependent A paths and
independent B/C views: at most 54 calls across 12 explicit units, 20 seconds and
600 iterations per fit, with the original 25 km proposal-local radius and priors.
Initialization retains strict projection first; only its exact nonconvergence
error permits independently verified feasible source-function transfer. C derives
six receiver lifts once from new all-training physical proposals and reuses them
across views. There is no zero-c arm, additional search or alternative-seed retry.

All 12 scientific outcomes, including finalized failures, must be sealed before
seven configured-reference model rows are evaluated. Training objective selects
each start; reference error does not select starts or an algorithm. Shared discovery,
geography and physical seeds limit end-to-end half-view independence. Frequency
scores and position errors remain separate. A passing recording does not establish
the full-DS21 0.5 km target or independently surveyed accuracy.

The qualified initializer is implemented first and receives owned synthetic tests
and independent source review before dataset execution. A later model-consumer
commit needs its own source/parent/seed/reference-gate tests and review. Root owns
all actual freezes, bounded runs and post-seal evaluation. No downstream dataset
fits occurred during preparation of this protocol.
