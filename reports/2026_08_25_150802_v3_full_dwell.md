This extends the earlier 53 qualified-window comparison to all **537** trajectory-conditioned 75 ms windows selected by Standard segmentation across the 60 s dwell. The complete GLRT20ms series—2,400 probes per path at 25 ms cadence—is retained as the uniform full-duration context.

The source-bound result records replay commit

- V2 completed 320/537 windows and qualified phase lock on 55.
- V3 completed 266/537 windows and qualified phase lock on 54.
- 263 windows had at least three frame-CFO measurements for both trackers.
- V3 had lower absolute final-rate error versus its own frame-CFO line in 166/263 comparable windows.

- Of the 484 windows rejected by Standard V1, V2 phase-qualified 2 and V3 phase-qualified 12; these are exploratory recoveries, not promoted evidence.
- Of the original 53 qualified windows, V3 retained phase-lock qualification in 42.
- V3 changed the acquired epoch in 391/537 windows. This is dominated by weak,
  previously rejected evidence: 386/484 rejected windows moved by a median 14

  five moved, and the maximum shift was one sample.
- All 12 exploratory V3 phase-lock recoveries came from `stream-1/rx1`; the
  recovery is path-local rather than a broad full-capture gain.

## Interpretation

This is a full-dwell **evidence-conditioned** replay: GLRT covers every 25 ms epoch, while frame tracking is run on every bounded trajectory window supplied by Standard. It does not claim continuous signal availability between those windows. Each V2/V3 comparison uses identical IQ, seed model, candidate epoch, and edge template.

There is no external Doppler truth. The frame-CFO degree-one line is an internal local-consistency reference. V3 remains research-only and these are additive report artifacts; no Standard products or golden fixtures were changed.

The recording uses manifest V2 while this checkout's typed reader accepts V1. The replay therefore used a narrow read-only extractor and verified all 14 consumed compressed chunks against the manifest SHA-256 values.
