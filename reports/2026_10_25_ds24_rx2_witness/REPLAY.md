# Replay and artifact limits

This compact report publishes the exact new scientific source, tests,
protocols, causal input bindings, all three complete-owner arrays, catalogue
screen artifacts, 48 physical candidate results, six null/model comparisons,
independent audits and figures. `publication_manifest.json` records each payload's
original source, size and SHA256. Failed prelaunch/setup versions and superseded
source remain provenance; they are not alternate accepted outcomes.

The run assumes the original repository and DS24 research corpus under
`/srv/bulk/leo/research/ds25-20261024`; these are DS24 fast-scan inputs stored in
that shared directory. Its original bank, causal priors/history, graph/native
observations, accepted-ID ledgers and runtime dependencies are hash-bound by
`scientific/protocol02.json` and `context/checks.json`. Historical inputs are
not duplicated wholesale. The new owner-specific NPZ arrays support saved-result
inspection but do not constitute a standalone full scientific-input/runtime
closure. Prior input and methodological evidence is linked from
[the previous iteration](https://github.com/misko/leo-tracker-reduxredux/tree/1c65753ab91538d3ace88351d6fe9e18a99b14b9/reports/2026_10_25_ds24_identity_support).

The original numerical environment used repository `.venv/bin/python`, one
BLAS/OMP/MKL thread and the locally supplied NumPy/SciPy/Matplotlib dependencies.
Scientific runners require the original source/input protocol and independent
approval receipts and enforce the frozen budget. Do not rerun them over the
immutable outputs. No new run is part of this publication.

`context/check_context.py` is a stdlib metadata-only readback. The exact
upstream fast-tracking file named by the original input receipt is permission
denied in this process; the readable exported `tracking.json` matches the
receipt's source and tracking hashes. That is not current live-authority byte
verification. The access incident and failed attempts are retained explicitly.

The structure diagnostic uses the existing public `frequency_evidence` port
for the original fast wrapper, with the repository `src` on `PYTHONPATH`.
Its separately versioned `diagnose02.py` and two owned tests preserve the frozen
complete-source polynomial question. Earlier code called a public timing port
incompatible with the fast wrapper and stopped before polynomial calculation;
its source/protocol remain in `structure/preparation01/`.

Original absolute paths in scientific/audit seals and review notes identify
the source environment. They are not portable download links. The principal
report links its published context and prior studies. Hash readback verifies
the saved evidence and exact copies, not numerical replay in another environment.
No release archive or duplicate historical runtime closure is required here.
