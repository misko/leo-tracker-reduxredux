# Rejected local-prefix preparation experiment

Keep the original arithmetic sequence but hold the running prefix in a local
double instead of reloading the preceding output element. Host and physical
ARM component tests preserve every checked output exactly.

The matched ARM control/new/new/control microbenchmark is about 6% slower.
The original component header was restored byte for byte. This is a rejected
experiment, not a deployment change; source, binaries and measurements remain
here. No whole-detector timing claim is made.
