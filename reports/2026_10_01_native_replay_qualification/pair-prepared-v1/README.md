# Prepared conservative pair bound

Prepare sqrt(2N) and its conservative reciprocal alongside each track's bound
subset, outside the satellite loop. The fallback without a prepared subset
constructs the same values. The reciprocal is scaled by (1 - 2^-48), so
rounding uncertainty retains candidates for full scoring. No final score,
search policy, persisted contract or reference membership changes.

Both complete 400-point host traces equal the qualified controls. Host
research tests, physical ARM bound tests, and ASan/UBSan on the changed inline
helper pass; unchanged library objects are not sanitizer-instrumented.

The ordinary O3 control/prototype/prototype/control comparison preserves all
sixteen evaluation scores. Mean CPU changes from 12.583370 to 12.480623 seconds
(0.82% reduction). This short comparison is not a full-search or concurrent
deployment qualification. Fresh PGO evaluation follows separately in
`../pair-prepared-pgo-v1/`.
