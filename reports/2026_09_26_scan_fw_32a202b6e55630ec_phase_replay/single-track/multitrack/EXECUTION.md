# Real-data shared-instrument prototype

Two SOL agents own data extraction and joint modelling; root owns independent validation and integration. A third agent could not start because the task's agent-thread limit was reached. All numerical observations come from the existing scan. Synthetic tests validate algorithms but do not substitute for real results.

Root's full acquisition census found 18 admitted simultaneous-mode visits; the original 128-visit frozen cohort contained only two. This bounded extension chooses eight visits from acquisition metadata, without inspecting phase: prior1074/1711, consecutive73/74 and1734/1735, plus earliest remaining14/52. Metadata verifies that73/74 share CH4/target7, whereas1734/1735 change channel and cannot be treated as a repeated-source pair. Candidates remain modes rather than identified emitters.

The direct empirical question is whether a donor mode's simultaneous phase helps predict another mode after a relation fitted solely on early observations. It is not a forecast if current donor data are used. Any future-only or cross-dwell prediction is separately labeled. Joint smooth models retain their common-function ambiguity; no geometric result follows merely from assigning one smooth component to the LNB.

Use one physical phase coordinate across modes. The existing extractor can use independent seeds only because it explicitly restores the mixed phase and transports it to a common physical midpoint. Different per-mode frequency corrections must never be left silently subtracted when evaluating shared phase.
