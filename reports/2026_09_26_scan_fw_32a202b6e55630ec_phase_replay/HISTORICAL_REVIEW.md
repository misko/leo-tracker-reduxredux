# Historical phase-recovery approaches

These are outcomes reported on earlier recordings, not results for `scan-fw-32a202b6e55630ec`. The new replay keeps failures, conditional successes and distinct phase observables separate. Multiple rows are variants of a shared estimator and are not independent experiments.

| Approach | Historical report | Reported outcome |
| --- | --- | --- |
| 01. Integrated CFO boundary bridging | [2026 08 22 frame local phase qualification](../2026_08_22_frame_local_phase_qualification.md) | No defensible unique phase bridge across the tested segment boundaries; sample/reference authority and ordinary-frame predictability were prerequisites. |
| 02. Frame-local Qin phase | [2026 08 22 frame local phase qualification](../2026_08_22_frame_local_phase_qualification.md) | Exact Qin phase was measurable inside a frame, but held neighboring-frame prediction and epoch stability did not qualify either tested boundary. |
| 03. Adjacent-frame correlation | [2026 08 22 within segment frame phase](../2026_08_22_within_segment_frame_phase.md) | Held adjacent-frame prediction worked in P2 and parts of P1/P5; P4 failed. Comparability was confined to each independently acquired 20 ms container. |
| 04. Prompt phase versus integrated linear Doppler | [2026 08 22 pnt phase doppler comparison](../2026_08_22_pnt_phase_doppler_comparison.md) | Per-frame frequency supported a robust constant-rate line; phase innovations required explicit resets rather than a continuous carrier assumption. |
| 05. Five-state phase feedback | [2026 08 22 pnt kalman comparison](../2026_08_22_pnt_kalman_comparison.md) | Letting discontinuous phase update the five-state filter worsened Doppler-rate estimates; the frequency-only ablation stayed closer to the reference. |
| 06. Ordinary 2pi long tracking | [2026 08 22 kalman phase tracking comparison](../2026_08_22_kalman_phase_tracking_comparison.md) | Ordinary 2pi tracking suffered frequent slips: 87.81% exceeded the configured gate in one seven-track replay. Computational completion was not a phase pass. |
| 07. Full Qin phase slope | [2026 08 22 edge pilot phase slope](../2026_08_22_edge_pilot_phase_slope.md) | Full 300-symbol/eight-tone slopes recovered useful frame-local frequency with nuisance phase per frame; that did not establish inter-frame carrier continuity. |
| 08. Offline binary-pi batch fit | [2026 08 22 edge pilot phase slope](../2026_08_22_edge_pilot_phase_slope.md) | Modulo-pi batch interpretations explained local structure, but an offline branch fit alone was not evidence of causal or unambiguous 2pi recovery. |
| 09. Causal modulo-pi filter | [2026 08 23 five dwell modulo pi qualification](../2026_08_23_five_dwell_modulo_pi_qualification.md) | Causal modulo-pi treatment avoided many ordinary-2pi resets on qualified windows; shorter wrap interval and modulo-pi selection prevent treating lower RMS alone as neutral model discovery. |
| 10. Five-state modulo-pi PNT | [2026 08 22 pilot pnt kalman](../2026_08_22_pilot_pnt_kalman.md) | The five-state modulo-pi tracker qualified selected local windows, including 66/66 updates in the mechanism example, but only 3/40 in a separate phase-blind window sample. |
| 11. Production multi-window qualification | [2026 08 23 five dwell modulo pi qualification](../2026_08_23_five_dwell_modulo_pi_qualification.md) | Historical production audit found 419 inner locks and 216 fully qualified 75 ms segments among 2,691 windows; all five dwells had nonzero yield. |
| 12. Short segments versus long GLRT lines | [2026 09 23 long dwell multiscale phase](../2026_09_23_long_dwell_multiscale_phase.md) | Short independently processed chunks retained conditional phase information; the 120 ms scale itself did not explain all degradation. Long smooth CFO lines could absorb local changes. |
| 13. Scanner retune-bounded tracking | [2026 09 23 adaptive retune phase audit](../2026_09_23_adaptive_retune_phase_audit.md) | Within-visit simultaneous double differences were feasible in historical adaptive scans, but bookkeeping and retune-bounded support did not certify cross-retune absolute phase. |
| 14. Semi-coherent pooling | [2026 08 23 470384 semicoherent recovery](../2026_08_23_470384_semicoherent_recovery.md) | Pooling complex Qin evidence with independent frame nuisance phase improved held sequence support and rate repeatability over 20/50/100 ms. This was frequency recovery, not phase stitching. |
| 15.
