# Publication scope

This publication contains the [completed report](README.md), its four figures,
evaluation tables and details, frozen source snapshots, hash manifests and
validation receipts. It also includes the preceding
[radio/orbit report](../2026_10_18_dsx01_radio_orbit_followup/README.md) and its
linked artifacts. Frozen report products and receipts are preserved exactly.

The latest local validation used 408 source snapshots and 639 pinned numerical
and protocol inputs. The complete numerical input corpus remains in the original
research workspace; this report publication does not add the broad upstream
input archive to Git. Paths in input manifests identify those retained inputs
and are not promises that each input is hosted in this commit. The frozen replay
receipt documents evaluation of saved endpoints in that workspace, rather than
a new geographic search. Reproducing it requires the original matching inputs
and Python dependencies; this publication is not a self-contained replay bundle.

The 20 models preserve each scan's original curved observations; the 12,724
point denominator is the total across the five independently fitted scans.
Each comparison retains matched zero versus fitted RF-calibration arms.
Frequency-fit improvements do not establish improved position accuracy.
Satellite identities remain hypotheses, development used the same corpus, and
the uniform independent all-five sub-1 km goal remains open.
