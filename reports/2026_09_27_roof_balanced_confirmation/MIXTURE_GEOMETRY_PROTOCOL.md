# Fixed-coordinate geographic test after candidate-mixture calibration

The candidate-mixture model passed the predeclared conditional reception-calibration advancement gate on all six calibration holdouts. That gate did not use geographic errors. This next test asks whether those reception improvements translate into different location errors.

Use the four existing second-cohort roof recordings and each prior's exact saved 289-point local grid. These recordings are already unblinded; this is development evidence, not prospective confirmation. No new recording, new coordinate, cross-prior candidate sharing, recentering, timing change, track exclusion rule, frequency refit, or location-dependent calibration choice is permitted.

At each point compute the frozen zero-timing frequency shortlist once, independently for that prior/location. Apply three reception calibrations to the same shortlist: the original frozen geometry model as a numerical reproduction control; the accepted full-six same-objective mean-direction M1; and the accepted full-six candidate-mixture M1. The two new models retain their own fitted conditional-ratio variance. Both are scored candidate-wise by the same existing joint geographic likelihood; their difference is how reception calibration was trained, not the geographic scoring formula.

Require export parity between the new calibration tensors and the existing geographic feature adapter before a run. Preserve full-six feature names, categorical levels, centering/scaling, coefficients, receiver sign convention, ratio convention, and variance. Do not refit or calibrate on these recordings. The 5 MHz sample-rate level remains unseen in the six calibration recordings and uses the existing reference-level encoding.

Apply existing source-topology exclusions and primary reception contributions unchanged. Track weights remain occupied one-second bins, and joint scores retain full-reserve observation normalization and shared track identity. The original old-model scores must reproduce every saved point/arm to absolute tolerance 1e-7, and every reception variant's Doppler score must agree to 1e-12. Require exact finite coordinate inventories and bind all inputs, source grids, calibration outputs, model exporter, source code, and this protocol. Outputs are separate and must not overwrite earlier results.

Only after all four runs pass, select deterministic minimum scores on the common per-prior grid and report Doppler-only, old geometry, mean-calibrated geometry, and mixture-calibrated geometry distances for all eight scan/prior cases. Include separate prior means, all regressions/ties, selected coordinates, and grid/prior boundary flags. The main scientific contrasts are mixture versus matched mean calibration and mixture versus Doppler-only. Do not select a model using these distances and relabel this cohort as fresh confirmation.

Distances use the operator-supplied roof reference, not surveyed ground truth. Grid spacing is not calibrated resolution, the paired priors are correlated, and better conditional reception likelihood does not guarantee lower geographic error. Any eventual general improvement claim still requires a separately frozen estimator and disjoint confirmation recordings.
