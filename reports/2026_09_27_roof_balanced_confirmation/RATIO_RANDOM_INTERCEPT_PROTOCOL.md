# Calibration-only shared ratio-offset experiment

The detection-only shared-effect model improved held reception likelihood but failed the geographic development comparison. Independently, the calibration-only ratio residual audit found 5.7768-fold track residual-sum dispersion. Test a shared ratio offset on that calibration evidence; do not select an arbitrary reception weight using geographic errors.

For matched rows of track t and candidate K, let log ratio z_i = existing mean_iK + v_t + epsilon_i, with v_t ~ Normal(0,tau^2), epsilon_i ~ Normal(0,sigma_ratio^2). One v is shared by all matched rows of the track. Integrate v exactly, yielding covariance sigma_ratio^2 I + tau^2 11'. Tau zero is the unchanged independent Gaussian ratio model. A track with no matched rows contributes ratio log likelihood zero.

The existing shared detection offset u remains independent of v conditional on K. Both components retain the same single track-wide candidate. This is a bounded one-parameter uncertainty ablation, not a fully refitted joint response model: every coefficient, existing ratio variance, frequency prior, candidate ID/logweight, feature schema, and full-row normalization remains frozen. Detection sigma is taken from the accepted full or corresponding conditional-LOSO detection-effect fit, never from the held session or any geographic error.

For each M0, mean-direction, and candidate-mixture arm, learn only tau on the original training partition. Objective: sum over training tracks of negative logsumexp(candidate prior + integrated detection LL + integrated ratio LL), divided per track by its full reception-row count. Use all rows for detection and matched rows only for ratios. Precompute the fixed detection likelihood at 128-point accepted mode-centered quadrature. At tau zero, full/fold joint and detection scores must reproduce the accepted detection-only artifacts within absolute 1e-10.

Tau is a standard deviation in natural-log-ratio units. Bounds [0,4], fixed grid [0,.0625,.125,.25,.5,1,2,4], then bounded scalar refinement between neighboring grid points around the best grid point, including endpoint intervals. Keep the best of zero, grid, and successful refinement. Failed refinement, nonfinite values, or upper-bound selection prevents advancement. Do not silently expand bounds or alter the frozen independent variance.

Run the full-six fit first, then six conditional-LOSO fits with each tau learned on the other five recordings. Frequency priors still use all six sessions, as in previous conditional reception experiments. Report per-fold and pooled joint NLL/track, detection NLL/track, and their conditional ratio difference for all three arms, before and after adding tau. Report full/fold tau and existing detection sigma explicitly.

Advancement requires all fits valid and below the upper bound; pooled mixture joint NLL improves over the detection-only shared model; at least four of six folds improve; and pooled improvement remains positive after removing the largest-gain fold. This gate only licenses a geographic development check, not a resolution claim. No location distances may select tau, modify data, or choose a different model.
