# Standalone receiver, full-IQ confirmation and satellite assignment

The compact v5 position receiver now runs as a 78-source executable. A complete DS29-0082 replay used the prepared fractional GLRT and passed its actual output to this executable. It read all 14 segments of the five-minute recording and returned both calibrated fixes in **94.62 s** inside one 512 MiB, zero-swap x86 service. The coordinates and conditional Doppler RMS matched both earlier whole-IQ controls. The raw detector also ran faster in this particular replay. The four same-core position-stage comparisons below isolate the source-package change. The four complete optimized IQ replays cover 25,103 valid dual-receiver calls. Their raw outputs matched the ordinary detector after accounting for detector build identity. The DS26 and DS29 recordings came from the same physical receiver installation. The eight-site field experiment used a different narrowband beacon measurement. A second physical installation with compatible wideband IQ, causal orbits, clocks and truth, and a target-board runtime for this complete chain, are still missing. [Complete IQ evidence](full-held-pair/README.md) · [Measured anonymous transfer](anonymous-transfer/README.md) · [Source inventory](../streamlined/measured-transfer/source-inventory.md)

Against original no-repair v5, the full optimized pipeline was within 10% of the original error or better on **one of the four** recordings in each calibration setting. On the original detector outputs the compact solver met that target on **all four**. For example, on DS29-0082 the fitted errors were 0.517 km for original v5, 0.516 km for compact v5 with the original factors, and 2.654 km for compact v5 with the ordinary replay. Both detectors used a 0.025 peak threshold. On that recording the number passing the gate rose from 4,582 to 7,962. The individual contribution of each detector difference is still open.
