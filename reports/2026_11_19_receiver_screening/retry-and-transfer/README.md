# Antenna retries, frequency search and geographic transfer

The wider search on the antenna that initially misses is a small part of the detector with a large effect on the position. Turning it off raised fitted error from 262 to 780 m on DS26-0237 and from 516 to 1,279 m on DS29-0082. Both tests used the entire recording, the original 25 km search region and the same causal satellite catalogue. Ten new compact fits measured the effect of waiting two seconds between retries. On both recordings the only tested schedule that exactly reproduced the full conditional fit used advance knowledge of which retries would succeed. ## Reproduce the plots

Choose a new output directory when running the standard benchmark.

```sh
MPLBACKEND=Agg .venv/bin/python -m tools.pipeline_eval benchmark \
  --study reports/2026_11_19_receiver_screening/retry-and-transfer \
  --pack --out /var/tmp/leo-retry-transfer-benchmark
```

Each roof position distribution compares the same recording IDs across the four original v5 options and its measured variants. Every scheduled recording contributes to the curve denominator, and diamonds give the median among returned fixes. The calibration switch selects zero or fitted `c`. A detector-only change has a timing or measurement plot at the last stage it reached.
