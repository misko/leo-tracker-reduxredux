# Retry a physical frequency according to its last observed result

Test two fixed two-second retry intervals on DS26-0237 and DS29-0082. The primary 12-anchor search runs on both antennas on every valid visit. When only one antenna passes, the other is eligible for the original 22-anchor search. The receiver keys its memory by failed antenna and physical RF. A newly seen key can retry immediately.

In the first policy, an actual unsuccessful retry starts a two-second waiting interval on that key. An actual successful retry leaves the key immediately available. The other policy starts the interval on a successful retry instead. A skipped retry returns the original primary result, including rejected candidates, and produces no new clock or remembered outcome. The interval is fixed in seconds on the capture's monotonic delivery clock. Neither rule uses past positions, satellite identities or region coordinates.

Test both policies even if one looks better. In each recording and at each physical key, give a hashed visit selection the exact same number of retries as its corresponding policy. The hash control requires the full opportunity count and is an offline comparator. Also measure an oracle that runs precisely the retries which actually found a signal. It is an estimate of how much retry work could be removed with perfect foreknowledge of success. Fit its selected observations independently.

Use the 12-anchor and complete conditional native packets from authenticated raw replays. Verify the conditional retry branch, unaffected antenna, visit clock and capture exclusion on every physical visit. Run the five numerical comparisons through the compact position solver under its original causal orbit request and 25 km region. Use the same priors, budgets and observations for zero and fitted calibration. Seal results before joining survey coordinates and four v5 references. The DS26 outcomes, original DS29 position and aggregate DS29 rescue count were already known when the two-second interval was chosen. Report measured fits, candidate and retry counts separately from any timing model. Both recordings are from one roof.
