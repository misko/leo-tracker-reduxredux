# Where capture-era GLRT finds the missing starts

Seven of 16 missed wide-GLRT targets already had a nearby basin in the installed capture detector’s primary retained list. The other nine first appeared in the 22-anchor fallback. The highest-ranked primary basin alone supplied the right timing for just one target, which the hinted wide detector recovered. The known-start arm recovered 14 of 16 on those same IQ inputs. For all nine fallback wins, the target receiver lacked a primary gated positive and its primary retained list lacked the archived epoch within two samples. The other receiver’s primary hit enabled retry. The installed retry keeps the same coarse, fine, and fractional architecture while increasing the anchor set from 12 to 22. Across both attempts, the 16 archived winners originated in coarse ranks 1 through 7. Only one of the five rank-one origins came from the primary list. Unhinted wide never exported even an incomplete candidate within two samples of these 16 recorded targets. The first discriminator is therefore timing nomination. Fine CFO and fractional verification still matter after a near start is available, as shown by the two known-start trials that reached the right timing but missed the CFO. ## Trace and control boundaries

We used all 24 frozen oracle-start visits, 16 misses and eight already-matched controls. The installed capture detector reproduced **48 of 48** archived probe rows across three installed producer roots. Stock wide also reproduced 48 of 48 complete archived wide factor rows, including the matched control that the earlier benchmark withheld after its template-edge error. Capture used the actual edge from the authenticated raw manifest. Each selected raw input was read once from the indexed archive and copied to local scratch for the wide comparison. The stage trace follows all 384 stock wide candidates through their nearest installed coarse, fine-grid, conditioned-grid, acquired, and fractional rows, keeping literal and alias-folded CFO differences separate. These are diagnostic nearest rows. Exact winner attribution instead follows the archived candidate rank and the original retained coarse key through the measured installed path. [Input lock](input-lock.json) · [Execution hashes before scoring](prediction-lock.json)

The unprivileged prefix runs the installed primary coarse grid, original peak ordering, and original adjacent-cell timing correction. It emits a hint independently for each receiver and reads no target epoch, outcome or CFO. The paired intervention applies only the externally assigned diagnostic lane’s hint. The native wide detector still checks four centers, all 12 tested regional epochs on the missed panel, its full ±800 kHz CFO span, and the original fractional gate. The rank-one hint changed the fourth slot in all 16 missed trials. Stock and half-frame sham recovered 0/16; the rank-one prefix recovered 1/16 and made that target the wide winner. In labeled synthetic signed controls the independent prefix recovered epoch 735 on both receivers and both pilot edges, and the full wide detector retained the correct ±720 kHz signal. Two seeded noise cases produced coarse starts and zero gated outputs. [Synthetic controls](sanity.json)

## Cost of limiting the capture detector to its primary coarse prefix

Across all visits the median installed capture path used 2,302 ms CPU and 2,980 ms wall. The bounded coarse prefix used 1,184 ms CPU and 1,297 ms wall, before the roughly 16 ms hinted wide call. The stock wide call used around 17 ms CPU. Capture and prefix are single instrumented observations per CI16 input on CPU 2 or 3. Wide uses two counterbalanced calls per arm on the same bytes and core. Those measurements exclude archive decoding. The screened DS29-0519 producer kept its own integer-VNNI selector and exact column checks, which accounts for a separately faster prefix. Any throughput comparison should preserve that producer distinction.

The earlier exact folded FFT measures how to preserve the dense score, while its replacement of the installed screen increased full detector CPU. The short-tap proxy lost retained basins before fractionation. This trial therefore kept both installed coarse variants, testing only the prefix and its rank-one timing output. Its measured cost and coverage leave the capture primary prefix unsuitable as a general wide-detector hint source at the current budget. The evidence identifies a different target for a cheaper scout. It would need to reproduce much of the wider anchor support and preserve alternative coarse basins before choosing one. No location or physical board performance was measured. [Exact FFT study](../../acquisition-support/capture-fft/README.md) · [Short-tap study](../../receiver-core/complete-epoch-proxy/README.md)

## Reproduction

Run `tools.pipeline_eval.qualification.capture_starts` with `freeze <scratch>`. Use the exact source path recorded per case in that input lock first on `PYTHONPATH` and the installed capture Python for `capture <scratch> --case <id>`. Then use the repository Python and the original native libraries for `wide <scratch> --case <id>`. Run `tools.pipeline_eval.qualification.capture_starts_results <scratch>` to check all archived factors and regenerate the stage table and figure. Scratch and the original corpus are needed for a new raw replay. Existing traces, row links, and PDF can be inspected from the sealed artifacts.
