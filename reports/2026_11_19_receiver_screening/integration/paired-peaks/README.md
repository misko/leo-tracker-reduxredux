## Fused localization outcome

The receiver collapses each accepted same-pilot pair into one peak and allows aligned singleton alternatives to bridge poor receptions. A training path must still contain at least three paired peaks. Short CFO increments screen orbital hypotheses before the existing elapsed-time decoder traces them. Paths have disjoint physical visits and share the existing nonlinear orbit/receiver position fit. Both c arms use identical selected support. The scope contains two diagnostics, four previously untested paired-method reserves and two authenticated omitted offers. The comparison used exact archived controls for the diagnostics and DS29 omission and reran the others on the same GLRT, TLE and tile.
