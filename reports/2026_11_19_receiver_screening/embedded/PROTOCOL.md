# Embedded orbital projection check

Replay the full initial projection grid of the two original archived smoke recordings, DS26-0036 and DS29-0082. Use the frozen v5 worker to reconstruct the original orbit knot bank, all unique track observation times and the supplied screen center. Use zero orbit phase and the standard 0.05 s derivative step. The test covers one coordinate projection from this prepared grid. Acquiring detections, fitting `c` and selecting positions lie outside the projection boundary.

Build the same C source for host x86-64, for the Pluto firmware toolchain's Cortex-A9 hard-float target and for AArch64. Execute the two Arm binaries in QEMU using identical little-endian binary inputs. Compare all output bytes against the host C run and all cells against the frozen NumPy implementation after converting elevation sine to degrees. For each target the allowed maximum absolute errors are 10⁻⁵ Hz in Doppler, 10⁻⁸ degrees in elevation and 10⁻⁵ Hz/s in the phase derivative. Record differences even when they fall below these limits.

Record the live prepared input and output array bytes, their buffer counts, the single allocation in the standalone C harness, and the compiler's stack estimate for the projection function. Prepared-array accounting excludes transient preparation arrays and the surrounding process working set. Save compiler flags, architecture, input and output digests and the frozen reference binding. Measure no timing under emulation. A physical board run requires a verified idle device and an approved scratch-only replay procedure.
