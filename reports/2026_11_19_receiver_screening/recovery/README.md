## Accuracy on the common roof

The common panel has 127 DS26 and eight DS29 recordings from one receiving installation. Original no-repair v5 returned all 135 positions with fitted median / P95 errors of **0.988 / 2.819 km**. Compact v5 returned all 135 at **0.989 / 2.817 km**. A six-recording controlled host comparison measured a **1.52× median speedup** for its position optimizer change from stored GLRT observations through the compact decision. ## Location and withholding

A region is an offered search area. A receiver that returns a coordinate when that area excludes the receiver produces a false publication. The separate location figures distinguish measured roof recordings with shifted offers from synthetic recordings at new sites.

- On 26 physical recordings with four offers apiece, testing the best competing solution outside the offered area rejected six of seven false fixes and 24 of 35 valid fixes. The one remaining false fix was present in both calibration arms. A six-recording reserve finished 24 ordinary controls and four exterior checks under its time limit. The chart identifies the other tentative checks as unmeasured. [104-offer chart](charts/fitted_c/native_smooth_exterior_evidence-diagnostic-stress.png) · [Reserve chart](charts/fitted_c/native_smooth_exterior_evidence-reserve.png) · [Costs and selection](exterior-evidence/README.md)
- At six new **simulated** sites the combined clock-and-offset receiver published two of six original offers in both calibration arms. It withheld all 12 omitted offers and the shuffle. The sites have different geometry, while the signal model still uses synthetic GLRT factors. Independent physical wideband transfer requires compatible recordings from another installation. [Six-site chart](charts/fitted_c/native_clock_offset_ou-clock-transfer.png) · [Transfer evidence](clock-transfer/README.md) · [Physical data coverage](../physical/README.md)

## Rebuild or examine a single chart

Run the first command to render both arms for this round from the saved predictions. To select one change, add `--variant` with its method or chart ID. The second command reruns an actual stored-observation case through the new orbital-update rule and emits both PNGs beside its predictions and errors.

```sh
.venv/bin/python -m tools.pipeline_eval figures --panel screening \
  --evidence reports/2026_11_19_receiver_screening/recovery --out /tmp/recovery-charts
.venv/bin/python -m tools.pipeline_eval run --panel smoke --case DS29-0082 \
  --variant v5_stable_phase --pin --timeout 210 --require-inputs \
  --out /tmp/stable-phase-benchmark
```

For an automated performance gate, add `--require-v5`. It returns a failing exit status if a panel misses a strict v5 comparison. The charts and per-recording results are still written. The DS29-0082 smoke case passed the fitted gate and missed the zero-calibration gate by about 1.2 m of horizontal error against original no-repair v5.
