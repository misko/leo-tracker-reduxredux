# Bounded independent installation check

This review checked the existing local field manifests, staged external metadata and named public primary sources. It used no remote sample downloads. A new source needed independent location authority, recoverable signed carrier or complex IQ with a sample clock, nominal RF, enough orbital support, and a causal ephemeris join. No additional complete package was verified.

| Source | What the release supports | Missing authority for this replay |
|---|---|---|
| Grigg et al., Engineering Development Array 2 in Australia | Time-tagged detections for a distinct radio-astronomy receiving installation. The table includes per-fine-channel flux and fitted sky directions. | Individual fine images span 28.9 kHz. The release uses TLE-selected detections and gives no signed carrier history or complex waveform. [Primary data deposit](https://zenodo.org/records/15089853) |
| Watson, Altrincham Starlink and OneWeb monitoring | Prior-night catalogues and time-frequency power scans. Four hour blocks of the previously used input are staged locally. | The new matching preprint uses the same installation and a Doppler-alignment estimate of +19 s. It documents no independent timestamp truth and no raw IQ in the evaluated subset. Reusing it would extend the earlier spectral experiment at the same installation. [Publisher data](https://zenodo.org/records/8400658) · [Matching preprint, sections III–V](https://arxiv.org/pdf/2611.02377) |
| Qascom/Padova, Cassola | The authors report 600 seconds of wideband measurement and a positioning result. | The inspected supplement releases the recovered recurring sequence. A downloadable matched UTC, stationary receiver reference, causal elements and continuous signed Doppler or IQ bundle was not established. [Author paper](https://arxiv.org/abs/2602.06682) |
| Ohio State Starlink | The investigators published acquisition, tracker and navigation results from physical captures. | The inspected primary documentation has no measurement-file bundle that contains capture UTC, the independent survey and historical orbit snapshot. [Ohio State receiver experiment](https://people.engineering.osu.edu/media/document/2023-08-11/kassas_positioning_with_starlink_leo_satellites_a_blind_doppler_spectral) |

The local QNAP and corpus manifests had already been checked for alternate native wideband sites. They supplied the documented roof installation and test data without a new physical site join. The separately checked Bellaterra VHF and Austin IQ bundles retain their previously reported limits. The local StarLoc release has all eleven source-authenticated measured MATLAB tracks, published GNSS logs and source-provided capture-time orbital data. Its eight physical site groups make it suitable for the matched geometric fallback.
