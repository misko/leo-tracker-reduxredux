## Rebuild the figures

The standard command reads the saved predictions and references. It writes separate PNGs for each chart, PDF books, an HTML gallery and the rows behind every dot. Filtering by a chart ID or method and a calibration arm produces a smaller export.

.venv/bin/python -m tools.pipeline_eval figures --panel screening --out /tmp/receiver-screening
.venv/bin/python -m tools.pipeline_eval.qualification.gallery_check /tmp/receiver-screening
