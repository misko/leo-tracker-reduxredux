# DS26-0020 bounded arrival protocol

Use each signed hardware sample window and its recorded monotonic host delivery timestamp. Use the original detector validity gate and the configured RF target from the signed capture index. Preserve the distinction between hardware sample time, delivery, service start, and readiness. Anchor relative times to the first recorded delivery. Never give a queue access to candidate measurements, fitted results, or reference positions. Supply the service time to the simulator only when work starts.

Compare nonpreemptive queues with one and four workers. Each queue may retain eight waiting whole dual-receiver CI16 windows (12,800,000 payload bytes). All queues discard waiting visits whose age reaches 1.0 s and publish only jobs that finish within 1.0 s of their recorded delivery. Inference can use published packets at their hardware-counter observation times. At equal clock ticks, finish and dispatch waiting work before a new delivery. Include a zero-wait, next-delivery publication control on the same recording. Report queues separately at the last delivery and 1.0 s after it. In-flight jobs occupy their worker until completion even after their result misses the age cap.

- FIFO admits into free waiting space and drops a new visit when the queue is full.
- Replace-oldest removes the oldest waiting visit when a newer one arrives at capacity.
- RF round robin keeps at most the latest waiting visit per configured RF target, dispatching by cyclic signed RF target order. All eight fixed RF bins fit in the same total waiting budget.

First apply the frozen rules to the authenticated secondary accelerated replay CPU timings to check the scheduling path. Apply the same rules to CPU timings measured by standalone portable C. Report wall-clock timings separately and use them as a scheduling sensitivity. Predictions from either full simulation are counterfactual detector schedules. The follow-up position jobs themselves run on selected complete native probes, with the original capture validity exclusions preserved. Record each applied queue decision outside the capture validity set. Conventional full compact, original v5 no-repair, selective-gap, omitted-track-one and omitted-tracks are controls. Carry the archived omitted-tracks timeout in the comparison.

Run all six bounded native queue fits in the following order as dedicated cores become available. Start with four-worker RF round robin and one-worker RF round robin, then four-worker FIFO, four-worker replace-oldest, one-worker FIFO and one-worker replace-oldest. Each fit uses the measured full C archive as its sole probe source. Keep the same causal catalogue, original no-repair configuration and offered 25 km tile in the controlled c = 0 and fitted-c arms. Both arms share the same observations and search settings. Each solve has 512 MiB, no swap and 180 seconds. Report reference position error separately from RF RMS and frequency score. Retain failures and the empty next-delivery control. Open truth only after recording and sealing predictions, terminal receipts, and source bindings.

Run a bounded one-worker FIFO replay over the first signed chunk using the same C binary, pinned to one CPU. Authenticate and decode the IQ before starting the pacing clock to isolate detector and handoff. Compare measured readiness with the FIFO model using the same prefix and the independent full C timings.
