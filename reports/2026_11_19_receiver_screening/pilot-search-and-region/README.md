# Which detector work can be removed before positioning?

Assigning one of eight radio frequencies to the original GLRT and the other seven to the fast detector helped one difficult recording. Across all ten roof recordings the policy returned nine fixes, and four were within 10% of original v5 error or better. The fast detector alone returned ten fixes, with five within the allowance. A separate paired replay recovered the exact same complete-assignment inputs and positions on the two recordings the studies share. [Ten-recording distributions](rf-lane-panel/charts/README.md) · [Recording-clock positions](rf-lane-position/README.md)

The expensive conditional antenna retry also changed the final position. Omitting it on DS26-0237 lost 448 positive antenna measurements and 14 tracks. Fitted error rose from 0.262 to 0.780 km even though the fitted frequency residual fell from 80.61 to 77.70 Hz. In the other direction, speeding up the original fine-frequency arithmetic preserved the two positions on the complete DS29 replay. [Antenna retry through position](single-pass/position/README.md) · [Exact full DS29 replay](field-exact-waveform/README.md)

These experiments reuse saved radio data. The complete wideband acquisitions come from one physical roof. The six region tests change the coordinates the receiver is offered while keeping its actual measurements fixed. An independent UK installation supplies a different, single-band input and yielded no published fix in the earlier comparison. All host CPU and wall timings refer to the hardware and measurement boundary named in the individual study. [External station and its measurements](../receiver-deadline/external-spectrum/README.md)

## Rebuild the benchmark

From the repository root, choose a fresh output directory and run the following command.

```sh
MPLBACKEND=Agg .venv/bin/python -m tools.pipeline_eval benchmark \
  --study reports/2026_11_19_receiver_screening/pilot-search-and-region \
  --pack --out /var/tmp/leo-pilot-region-benchmark
```

The command validates the stored measurements and rebuilds the per-change figures and numeric tables. The individual studies document how to rerun the underlying saved-I/Q or position computations. Each roof error curve counts every scheduled recording, including failures, withheld positions and timeouts. Diamonds summarize the returned positions. Matched roof plots include the four capture-era v5 settings, and the two calibration views use the same visits, candidate sets, geographic priors and search budget. Stage plots show the last measured output for changes evaluated inside the detector. [Open the benchmark](benchmark/index.html) · [Download plots and CSVs](benchmark/modification-charts.zip)
