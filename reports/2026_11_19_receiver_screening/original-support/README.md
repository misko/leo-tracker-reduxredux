# How much original GLRT evidence does a position need?

The compact solver can reproduce v5-level position accuracy when it receives the original GLRT measurements. On 135 roof recordings it published every position. With fitted RF calibration, its median and 95th-percentile errors were 0.989 and 2.817 km. Original no-repair v5 gave 0.988 and 2.819 km. In each calibration setting, 129 recordings were within the individual +5% error allowance and 131 within +10%. Four same-core host pairs reached the compact position decision 3.42 times faster at the median. These measurements begin at the original GLRT output. [135-recording accuracy and all four v5 options](../secant-full/README.md) · [Matched timing boundaries](../deployment/same-core-baseline/README.md)

This series tests the earlier part of the receiver. One group of changes computes the original detector outputs more cheaply. Another spends a smaller number of original detector calls at selected frequencies and times. A complete five-minute DS29-0082 replay provides a reference. It reproduced 42,162 candidate records and gave 0.568 / 0.516 km error at zero / fitted RF calibration. Original no-repair v5 gave 0.567 / 0.517 km. All 4,868 valid detector visits exceeded 20 ms on the host. [Complete original DS29 replay](../antenna-confirmation/capture-whole/README.md) · [Position figures and stage measurements](index.html)

The complete Starlink recordings in these comparisons share one surveyed roof. The regional study uses prepared measurements from a separate beacon receiver. Repeated offers at those sites test the missing-region decision. A complete raw Starlink position on another physical site remains an open test. Position error is scored against survey separately from the frequency residual on the observations each fit retained. On DS29-0082, all three four-worker models lowered that residual and increased geographic error relative to the complete recording.

## Rebuild the position distributions

```sh
MPLBACKEND=Agg .venv/bin/python -m tools.pipeline_eval benchmark \
  --receiver original-support --out /tmp/original-support
```

Open `/tmp/original-support/charts/index.html` for the zero- and fitted-calibration plots. The upper curves count every scheduled recording, including withheld positions. The points and medians show returned positions. Each comparison uses its own matched roster. The published gallery contains 20 position comparisons in both calibration settings and ten acquisition or timing charts. [Browse the results](index.html) · [Download all 50 PNGs, PDFs and plotted values](modification-charts.zip) · [Benchmark protocol](benchmark/PROTOCOL.md)

The original detector can also run as a receiver on authenticated saved I/Q. Its command accepts either a benchmark recording or an explicit capture description, the offered region, causal orbit data and a truth-free request. It derives the masks from the capture metadata. Two first-chunk runs exercised different installed capture releases. A separate test used the command's full handoff on all 6,768 already decoded DS26-0237 visits. The command bound its newly assembled detector file to the request. Both positions and conditional RF residuals matched the complete waveform study.
