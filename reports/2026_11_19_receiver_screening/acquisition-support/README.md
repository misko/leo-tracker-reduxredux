# Position error and runtime for each receiver change

The [downloadable chart pack](modification-charts.zip) contains **96 individual PNGs**. It includes fitted and zero-calibration versions of 44 position comparisons, plus eight detector-stage figures. The position set covers the original ten, 33 later comparisons and the earlier fractional-interpolation position check. The ZIP includes 20,162 plotted data rows and an index. Extract it and open `index.html` to browse offline.

[Open the per-change index](index.html) to choose one modification and its calibration setting. The [position gallery](charts/index.html) shows both datasets side by side where DS26 and DS29 were measured. For the original ten changes there is a separate [ten-chart roof gallery](../../2026_11_19_position_atlas/original-ten.html). The [detector-stage book](stage-charts/stage-evidence.pdf) shows timings and signal retention for changes evaluated on individual waveforms.

Each roof curve counts every recording assigned to that method. Each dot marks an actual estimate, and each diamond gives the median for that row. An unissued fix contributes to the denominator and has no position-error dot. Rows labeled *forced* show where a receiver would have landed if required to guess. Both calibration settings use matched observations and budgets. The four original v5 settings provide the roof reference. Field-site and simulated-site figures identify their own available controls.

| Change | Measured inputs and result |
| --- | --- |
| [Four or sixteen proposed pilot starts](scout-full/README.md) | Eight complete saved I/Q pairs from one roof. Each detector returned 7/8 fixes and met the fitted v5 10% target on 4/8. Sixteen improved five of six jointly completed positions but added a median 28.51 s elapsed per pair. |
| [Repeat the two primary deadline failures](deadline-repeat/README.md) | Four fresh full services, with local scratch and the same limits. Both detectors reproduced their primary raw outputs exactly. Sixteen starts reached 0.149 km fitted on DS26-0237 and 2.025 km on DS29-0082, against original v5 at 0.271 km and 0.517 km. The primary plot retains both failures. |
| [One- or two-sample timing radius](radius-full/README.md) | Two additional complete roof recordings. Both versions returned both positions. The larger radius improved one in both calibration arms and worsened the other. |
| [Four-start receiver on additional waveforms](fresh-waveform/README.md) | Two recording IDs selected by input hash before replay. The existing fast receiver landed within 1 km on both. Only DS26-0014 met the 10% v5 threshold. |
| [Exact FFT implementation of the original GLRT](capture-fft/README.md) | All 352 candidate responses in the recorded and synthetic checks matched. The legacy full detector used 55.8% less CPU on the tested host. On the screened release the warmed detector used 8.2% more. Replacing four measured visits per recording preserved both position fits on two roof recordings. |
| [Stream only the winning pilot and required metadata](winner-stream/README.md) | Three full stored detector outputs. The position solver produced exactly the same positions and RF scores. The handoff shrank 91.7–94.7%. Including conversion, full wall time fell on two recordings and rose 0.50 s on one. |
| [Reuse the constrained fit’s time basis](fit-work/README.md) | Reduced CPU in the constrained stage on two branch-exercising measurements. The uninstrumented DS29-0247 whole service took 135.17 s before and 138.03 s after. Maximum observed position change was below one micrometer. |
| [Rank pilots against earlier rolled-pilot scores](peak-null/README.md) | Six full stored detector outputs. The candidate returned 5/6 positions and the existing ranker returned 6/6. On the four reserve recordings the fitted 10% count fell from 2/4 to 1/4. |
| [Keep probes where detectors agree](peak-support/README.md) | Four recorded inputs, three detector families and matched probe-count controls. Shared probes improved fitted position over random thinning in 8/12 comparisons and over the full inputs in 5/12. |
| [Selectively rerun the capture detector](selective-capture/README.md) | Four roof recordings, two selection rules and two visit budgets. All 16 downstream services returned positions. Each rule and budget met the fitted v5 10% target on 2/4, equal to the wide control. Detector workload estimates and four genuine selected raw replays are supplied separately. |
| [Position from Doppler derivatives](derivative-receiver/README.md) | Six roof recordings plus omitted tiles and field/simulated offers. Both variants withheld throughout. Removing each arc’s unknown frequency offset and drift reduced a modeled 25 km roof displacement from 6.60 kHz to 80 Hz RMS. |
| [Anonymous beacons with common clock drift](field-anonymous/README.md) | Four geographically distinct held field sites. When the correct region was offered, the receiver chose it on 4/4. The competing-point check withheld all four precise fixes. The worldwide forced search had a median error of 6,170 km. |
| [Test whether a point outside the offered tile predicts later Doppler better](outside-predictive/README.md) | Detected 4/4 simulated omissions and 1/4 measured roof omissions. All three earlier false roof fixes remained published. |
| [Simpler GLRT searches on recorded windows](stage-charts/README.md) | Per-change charts cover equivalent full-grid FFTs, thinning the original search, signed-phase screening, and timing proposals. Each page reports what was measured and the number of visits. |

All eight primary complete waveforms used the original roof. Two complete fingerprint-selected records exercise new signals at that site. The field-site results measure geographic transfer with a different recorded beacon frontend. Speed figures come from host or explicitly labeled emulation runs. These experiments have yet to demonstrate full receiver accuracy on new physical sites and real-time operation on the target board.
