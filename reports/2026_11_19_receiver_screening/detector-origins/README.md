# Detector changes with measured positions

On six complete five-minute IQ recordings, the wider GLRT search published all six positions and met the fitted-calibration v5 target on three. A separate change to the lifetime of the position solver's fit buffers recovered the narrow detector's missing fix. The gallery contains 15 roof comparisons and five region comparisons, each with both calibration settings.
