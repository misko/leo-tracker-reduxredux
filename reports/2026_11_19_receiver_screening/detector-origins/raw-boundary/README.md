## Recorded support, scaling, receiver order and clocks

Both manifests declare 10 MS/s, 20 ms, little-endian signed CI16 interleaved by sample, receiver and I/Q, receiver IDs `[0, 1]`, and a configured 40 dB gain. The actual held retune receipts declare AD9361 signed 12-bit codes carried in CI16 and a 200,000-sample minimum and observed post-recall guard. The gain readback field is invalid in those receipts, so 40 dB describes the configuration. Each accepted window begins at the attested valid hardware counter and contains all 200,000 sample times. The producer uses one probe starting at array index zero. The decoder turns the two CI16 components directly into the float32 real and imaginary parts of the complex64 dwell. Each refinement call consumed the same complete receiver column promoted to contiguous complex128. [DS26 ingress and guard records](DS26-0036-held.json.gz) · [DS29 ingress and guard records](DS29-0082-held.json.gz)

The complete capture-era and ordinary factor documents have identical clock anchors, delivery clocks and last hardware sample counters. All 13,530 DS26 and 9,736 DS29 probe rows have identical keys and metadata after removing only the candidate lists. That includes physical receiver ID, per-visit counter, channel, RF, and packed payload index. The packed index uses the scheduled visit rather than the hardware counter, which excludes gaps and guard samples from the contiguous factor representation. Across all 28 authenticated target manifests, requested RF minus recorded RF is exactly zero for every emitted receiver row. The installed wrapper therefore has zero RF-centre correction on these inputs. Its native capture policy is the declared ungated 10 MS/s V2 producer. The measured package and current runtime reconstructed each archived run identity. [Source ledger](source-lock.json) · [Whole-document clock and RF checks](comparison.json)

On one held visit per recording, half amplitude reproduced every candidate and gate field exactly. Swapping the ADC columns reproduced them once receiver labels were mapped back. Dropping one sample and appending zero changed each tested visit’s full payload. It also changed the DS26 positive payload while retaining its positive count. The genuine entry used the unchanged support on both receivers. On two DS26 held visits the authentic producer used the paired 22-anchor fallback. Disabling that branch changed rejected candidate rows on those two visits and retained every positive factor exactly. The fallback alone cannot explain the extra ordinary positives in this held set.
