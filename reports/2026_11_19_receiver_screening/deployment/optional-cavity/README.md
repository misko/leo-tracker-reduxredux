# Optional cavity family failure

The frozen v5 receiver fits an accepted paired history or signed incumbent before cavity nomination. The optional leave-family-out calibration refreshes c = 0 five times and can fail the original 0.01 s convergence test. Stock propagates that failure to the whole recording. The candidate skips just this family and gives the remaining nominations and paired replacements their ordinary deterministic search and loss comparison.

When a family was skipped and no replacement is selected, the candidate publishes the paired incumbent only if its existing RF, tile, phase convergence, and phase bounds checks pass. The curved-only incumbent stores its last phase change in its fit history, while the signed or linear incumbent exposes the same value at the top level. The separate confirmation adapter converts the original receipt shape for the shared check. It neither changes a numerical fit nor catches other physics and evidence errors.

The replay uses only authenticated stored GLRT, the original offered roof tile, and the original causal TLE histories. The legacy compact entry point accepts that roof offer. Geographic omission transfer was outside this paired replay. DS26-0046 was an earlier failure in the bridge initial-search variant. This replay uses the ordinary compact secant initial search.
