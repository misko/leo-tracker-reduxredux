# Concurrent recorded-clock acquisition

DS29-0082 and DS26-0237 exercise opposite pilot edges and two installed capture releases. This experiment measures which dual-antenna wide and prepared-original packets reach a receiver by the final recorded arrival when the detectors operate at the same time. The earlier DS29-0082 one-worker runs remain standalone controls.

Each capture was decoded once from the original authenticated chunks into a new read-only tmpfs stage. The stage checked all original byte hashes, hardware arrival clocks, counters and known RF centers. It then hashed the completed tmpfs file on readback and kept the data charged to its own zero-swap cgroup. The pacing publisher shared the stage core. It released each physical visit at its recorded monotonic offset, using one origin sent after both detector processes reached the same start barrier. Both detectors read the same staged inode and verified the bytes for each admitted visit. Each had a dedicated physical host core, one service reservation, one FIFO waiting slot, a 512 MiB cgroup memory limit and zero swap. Hardware exclusions bypassed the detectors. Each busy-queue drop belongs to a particular branch.

The scheduled last physical delivery includes both valid and invalid visits and is the primary cutoff. The trace records every scheduled and actual source delivery, each branch admission, actual worker start and finish relative to the shared origin, and every full dual detector packet including packets completed during drain. A packet can contribute to cutoff support only when its measured finish is at or before the last recorded arrival offset. Finish marks completion of the in-memory detector packet before report logging.

Both complete independent full-waveform ledgers were checked against every staged physical visit. Each measured full dual packet was compared exactly to its matching ledger packet. The wide ledger also reproduces the complete stock factors in the 22-case one-lane roster. The original reference is the full qualified combined waveform for DS29-0082 and the full independently prepared waveform for DS26-0237. Both concurrent original branches use the qualified persistent grid and the original refiners.

There is one paired host run per case. Both recording clocks ran concurrently. Startup, publisher pacing, and staged source charges are recorded separately from detector process charges. The staged-source allocation and host timings describe this replay. Position scoring and calibration ablation use a separate downstream measurement.
