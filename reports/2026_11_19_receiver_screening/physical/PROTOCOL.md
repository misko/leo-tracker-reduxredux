# Frequency-normalized curvature at independently measured sites

Replay the same four measured StarLoc site groups and twelve previously sealed anonymous track queries. Preserve their released one-band center-beacon measurements, timestamps, causal TLEs and supplied tiles. The worldwide mode receives no tile and searches equal-area Earth seeds. The supplied and omitted modes each receive only the already frozen single tile. Prior captures are frozen and earlier position outcomes are available. This is a retrospective new observable test with no source satellite IDs and no coordinate references available inside either search or holdout.

Compare measured and predicted Doppler as fractions of the nominal carrier. Select nine evenly spaced recorded indices from each arc. Project frequency in two disjoint blocks, first six and last three, onto the orthogonal complement of `[1,t]`. The training block determines position and satellite choices. Score the held block against those same satellite choices without estimating or transferring a carrier level, slope or clock shift. This projects out an arbitrary affine carrier error per track. A constant fitted calibration term cancels, so the two c arms are identical by construction. Use 1.5 kHz at 11.325 GHz as the fixed equivalent per-sample residual scale from the previous matched experiment. Retain the same search geometry, point budgets, 0° all-epoch horizon and three-orbit, held-score 0.35, separated lead 0.08 release thresholds. There is no tuning on the four sites.

Run once on CPU 7 with one numerical thread, retaining timeouts and failures. Hash the new source, unchanged geometry dependencies, old query plan and source packet bytes before evaluation. Seal the published and forced rows. Score GNSS errors and offered tile centers offline in the same twelve queries, and compare to the archived offset-only fit at the same sites and under the same priors. The boundary is the prepared measured beacon curves through position, with neither raw edge-pilot detection nor independent field qualification of the exact Qin receiver implied.
