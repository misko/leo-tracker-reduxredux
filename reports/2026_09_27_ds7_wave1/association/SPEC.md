# DS7 association/search smoke gate

Status: frozen reference-free preparatory specification; variant fits remain blocked until Direction A publishes a qualified baseline response.

The matched evidence is the first DS7 recording's exact track export and candidate bank. Every arm must consume the same track IDs, observations, whole-visit training masks, causal per-object element catalogue, 41-value timing grid, Student-t4 scale of 100 Hz, stationary training-profiled track offsets, and canonical 11.2 GHz Doppler carrier. `persistent_hop_trajectory.py` scales raw CFO by `canonical_rf_hz / actual_rf_hz`, stores the dealiased normalized value as `measured_cfo_hz`, and `prepare_adaptive_tle_position_inputs` exports that value as `measured_hz`. The 11.2 GHz prediction therefore matches the measurement normalization. Candidate likelihoods and winners use training observations only. Held observations and physical `rf_hz` metadata may not affect shortlists, basin choice, convergence, boundary status, or abstention.

The smoke comparison freezes these arms before any fit:

1. **Inherited shortlist/local search:** the exported five-anchor (`0/0`, four `+/-12 km` corners), per-anchor/per-tau training top-8 union; continuous `+/-12 km` east/north and `+/-5 s` timing bounds; timing starts `0,-2,+2 s`.
2. **Regenerated catalogue bank/local search:** regenerate from the same causal object roster and per-object elements, using the identical five anchors, 41 timing values, top-8 rule and compute cap. Its purpose is candidate reproducibility; a membership or normalization change is a failed control, not an ablation result.
3. **Matched multi-basin search:** keep the frozen bank and objective, add a predeclared coarse set of interior position starts. It gets the same maximum objective evaluations as arm 1; report unattempted starts rather than widening the budget. Compare search completeness separately from identity mixture.
4. **Source null:** replace each candidate's Doppler curve by a time-reversed curve about the recording midpoint while retaining candidate count, visibility support, timing grid, masks, offsets, starts and evaluation cap. This tests whether generic smooth curvature wins.
5. **Association controls:** a simultaneous permutation of candidate labels and their complete state rows is a required invariance control; it must leave mixture likelihood exactly unchanged and cannot serve as a wrong-association test. The physically mismatched control reverses each candidate state trajectory over observation time while preserving candidate count, timing-grid membership, masks and normalization. A synthetic injected trajectory must strongly prefer the correctly ordered states before the mismatch control is admissible on DS7.
6. **Explicit outlier/null support:** add one fixed per-track null component whose training density and prior mass are frozen before fitting. Candidate catalogue normalization remains `log(catalogue_size)`; the null mixture weight is declared separately and cannot be learned from held data.

All arms report candidate and observation digests, training-selection digest, catalogue size, per-track union sizes, objective-evaluation accounting, winning start, convergence, position/timing boundary flags, null responsibility, and deterministic replay. No arm advances with a catalogue gap, undeclared hypothesis truncation, changed observation membership, held-data selection, non-finite likelihood, edge winner, or unequal compute accounting. A scientific smoke requires Direction A's baseline to be interior, converged, and reproducible before these variants run.

The matched search comparison freezes a total cap of 180 objective/gradient evaluations. Local search uses starts `(0,0,0)`, `(0,0,-2)` and `(0,0,2)` with 60 evaluations each. Multibasin search uses position starts at the center and the eight combinations from east/north values `-8,0,8 km` other than repeated center, all at zero timing, with 20 evaluations each. Both wrappers consume the exact baseline bank and observation membership. Exhaustion is retained as a failed or unconverged run; the cap is never widened after seeing the objective.

The export contains physical channel metadata at 10.94, 11.19, 11.44 and 11.69 GHz, but its CFO measurements have already been normalized to 11.2 GHz. Candidate prediction must use 11.2 GHz. Substituting per-track RF only in prediction would put measurements and predictions on different scales and is invalid. A physical-carrier experiment would have to undo or consistently change the upstream measurement normalization; it is outside this association/search comparison.
