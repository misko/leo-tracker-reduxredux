# Preprocessing dependence audit

The approved predictive protocol replaces empirical point scales and family powers with the existing **150 Hz engineering base scale**, unit likelihood powers, and training-only fragment precision posteriors. It starts both c arms and both SD models at regional coordinates `[0, 0]` with zero phase reference. Causal phase means remain in the coefficient prior. The adapter performs no RF fitting, family selection, or GPS access.

This is conditional validation of an already discovered graph. It removes inherited RF initialization and empirical scale/weight dependence from the numerical training fit. It cannot establish blind generalization of the graph, satellite identification, or original mask decisions. The five requested scans are development examples, not an unbiased cohort.

| Quantity | Existing dependence | Approved treatment |
| --- | --- | --- |
| Point noise | `ds23_radio_noise.estimate` chooses polynomial residuals using full-track curvature, saved piece boundaries/degrees, and a margin-dependent variance/BIC rule. `FreshScan(radio)` loads that full-scan artifact. | Replace metadata before constructing a problem and replace `p.point_noise` before calculation or caching; all native base scales are 150 Hz. No polynomial estimator is newly fitted. |
| Family likelihood powers | `confidence_for` uses full-data position, hardware and receiver state and RF competitor costs. `family_weights(cross_rx_support)` combines this confidence with full retained support. | All fragment powers are one. Held predictive density is also unpowered. |
| Position and phase starts | Frozen solver defaults use the published fitted-c endpoint and its full-data phase reference. | Pass `initial_conditions(dd)` explicitly: position zero and phase reference zero. The approved zero reference is a computational start; it does not reset the causal prior mean. |
| Phase intercept | `absolute_phase_linearization` evaluates the orbital frequency and derivative at the current reference, retaining an absolute prior coordinate. | Initial reference zero; subsequent half-damped references depend only on training posterior phases. No empirical residual intercept is added. |
| Alias integers and graph | `FixedFamilies` and `AnchoredFamilies` originally choose aliases using full-data seed calibration and curve means. `JointMarginal` overrides these with saved `node['aliases']`. Curvature, joins, peaks, identities and mask eligibility were discovered on the complete graph. | Keep these declared conditional inputs fixed and verify native ID order and aliases after factory construction. A discarded temporary alias is still computed by the frozen constructor; it does not replace the explicit saved alias. |
| Receiver smooth basis | `projected_receiver_basis` projects Gaussian columns against a fixed 301-point grid on `[0,300]`; it does not fit the measured CFO or the observed time distribution. | Keep it. Restricting the basis to training rows equals evaluating it on those times alone. Receiver/band offset and drift columns likewise use fixed engineering coordinates. |
| Phase and physical priors | `phase_widths`, `forecast_phase_mean` and `build_modes` use causal nominal/previous TLE geometry. Multiplier, tail degrees and shrinkage come from the pre-RF TLE history model; nomination and available mode support remain graph-conditional. | Retain the causal prior model, coefficients and nominal support. SD4 scales only the selected family's existing physical mode bank. No extra free slopes or intercepts. |
| Noise and coefficient posteriors | The hierarchical bound uses all rows selected by `keep`. Gamma precision updates and optional Student phase-prior updates use those residuals. | `keep` is the training subset. Fragment noise prior remains Gamma(shape=2, rate=2); only present groups receive training updates. Gaussian engineering coefficient priors and declared phase-prior hyperparameters remain fixed. |
| Ancillary likelihoods | Attached linear entries and recovered families were selected with full-scan calibration and have separate likelihood implementations. | Omit them from fitting and scoring. Report this reduced evidence inventory explicitly. |

The 150 Hz scale predates this experiment: `evaluate_ds23_phase_refreshed.NOISE_HZ` is 150, `FreshScan(noise_mode='fixed150')` uses it, `JointMarginal(variant='fixed')` fixes the same scale, and the radio estimator uses it when no polynomial residuals qualify. It was not selected against held frequencies or position error. With a Gamma(2,2) precision prior the prior mean precision is one and the prior expected inverse precision is two. The predictive runner must treat wholly absent groups as prior-only; the engine's zero placeholders are not fitted precisions. A Gaussian using that variance is a declared moment approximation, not the exact Student mixture density.

A full reconstruction would need to withhold acquisition opportunities before peak/track assembly, reevaluate curvature and joins, search satellite/alias candidates and establish masks with training data, preserve alternative peaks as competing measurements, and rebuild ancillary evidence. The current fixed-graph test cannot repair these decisions by changing a noise estimator. A new polynomial scale fit would itself require predeclared degree, sample-count, graph-piece and fallback rules; it is not part of this approved bounded test.

`adapter.prepare_context(d, z, train_mask)` returns `(dd, zz, receipt)`. It preserves an existing `problem_factory`, including its family SD wrapper, removes ancillary likelihoods and selection refresh, and enforces a nonempty boolean subset of the original eligible native mask. `initial_conditions(dd)` supplies the required explicit solver starts. `context_inventory(d)` records inherited RF preprocessing values without evaluating an objective or accessing measured frequencies. Apply preprocessing after composing the SD context. No changes to production modules or persisted contracts are needed.

Five synthetic tests passed: held-out outcomes and saved empirical noise/powers leave the training posterior unchanged; the override retains the complete normalized bound; starts and prior means remain distinct; malformed masks are rejected; and the receiver basis restricts consistently. These are component checks, not RF outcomes. The predictive runner owns case receipts, model fitting, qualification and held scores. Source bindings are recorded in `source_audit.json`.
