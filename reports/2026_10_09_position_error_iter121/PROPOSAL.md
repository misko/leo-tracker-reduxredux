# Causal stationary-position fusion: bounded diagnostic proposal

Source/report review only; no filter implemented, recording reconstructed, reserve opened or inference evaluated. [Iteration109's prior-fusion audit](../2026_10_09_position_error_iter109/PRIOR_FUSION_AUDIT.md) already reviews this direction. A causal B7 geographic filter was not demonstrated in that review; it remains untested rather than a newly discovered solution.

The positive clue is retrospective DS16 coordinate aggregation: mean-position error 0.737 km and coordinate-median error 0.484 km in iteration1. These are future-aware aggregate estimates, not mean per-scan error. The strongest warning is the reference-free DS3/DS4 surface experiment: full-batch errors 0.693 and 1.667 km, combined147 scans1.303 km, eight-scan group medians4.545/3.891 km and one15.046 km group. Changing normalization did not reliably remove shared bias. Thus averaging can help random dispersion while preserving geometry/TLE/receiver bias. See the source links and method contract in iteration109; no newer independent fusion result was found in this bounded report review.

## Smallest useful comparison

For an **independently documented stationary installation**, compare the unchanged ordinary B7 fix with two parameter-free causal summaries: the arithmetic mean and coordinate median of all prior qualified fixes including the current fix, in one fixed geographic chart chosen from the first ordinary fix. Never initialize from reference coordinates. A geometric median is rotation invariant but introduces an iterative algorithm; coordinate median is the lean initial comparator and should disclose chart dependence. Report a cold start immediately from the first available fix, then every update. No error-based outlier gate, future-aware smoothing, sliding-window-width search, learned covariance or Kalman uncertainty claim is needed for this first diagnostic. A coordinate median can resist isolated failures but still lock onto a persistent wrong basin.

Do not fuse clock coefficients yet. B7 satellite/common timing gauges and receiver clock origins differ between scans; transfer requires explicit physical hardware/LO/stream continuity and coefficient transport to one absolute time origin. Captures after retune, reset, unknown clock continuity or uncertain device identity must not inherit a clock state. A position-only summary avoids pretending these nuisance parameters are a persistent calibrated sensor state. Stationary position can remain common across hardware resets only when that operating mode is independently established.

Use the complete existing DS16/DS17/DS18 authority (63/51/34), ordered by **result availability**, with capture times and acquisition gaps also reported. Capture start alone cannot certify a result was available online; when availability receipts are absent, label the exercise a causal-in-capture-order retrospective replay, not a deployment latency test. Include every member: unqualified or missing fixes produce an explicit outage/held-state row, never an excluded member. Verify no repeated IQ/session evidence is counted twice. Dataset boundaries are reporting groups, not automatic physical resets; freeze reset rules from independently known installation changes. For a cleaner sensitivity, additionally report each dataset from a fresh cold start, without calling these consumed datasets independent validation. Do not open the newer reserve or relabel diagnostic scans unseen.

Run each c arm separately with matched membership, qualifications, timestamps, reset rules and causal algorithm. Report standalone B7 mean/median/p95/worst alongside per-update fusion errors over **all** updates, cold-start curves by elapsed time and number of fixes, outages and held-state age. Truth enters only this final evaluation, never qualification/reset/selection. Frequency-fit statistics stay attached to the original single-scan fix; geographic fusion creates no new frequency fit. No standalone accuracy gain may be claimed from a multi-scan estimate.

Only after this bounded comparison should a robust Kalman filter be considered. It requires externally justified motion/process noise, calibrated correlated measurement noise, reference-free innovation gates and reacquisition rules. Iteration117's nuisance-confounded local information is not a ready-made covariance. Moving operation needs position/velocity dynamics and motion-lag evaluation; a cumulative stationary median is inappropriate there. The goal of mean standalone error below0.4 km remains separate and unchanged.
