Nominate **DS24-0011 and DS24-0097**, the development cases currently tied for
the most newly curved native owners (four each); chronological tie breaking

Run three complete input variants per case, each containing both matched c arms:

1. **Fresh unchanged baseline:** exact original observations/graph/noise inputs,
   causal full catalogue and original physical priors. No saved discovery nodes,
   phase references, fitted radio state or localization endpoint initializes it.
2. **Additions with existing proxy:** exact original measurement rows and margins
   plus independently audited new native owners; original graph_rf_lanes and
   observation-dependent radio-noise proxy rebuilt. This is exploratory because
   timing-selected confirmation margins and donor-centered bins are not newly
   calibrated measurement covariances. Report all incumbent-weight changes.
3. **Additions with one-bin floor:** same observations, graph and all other inputs
   as variant2. Materialize its effective per-ID noise scales, then set only
   new owners' sigma to `max(proxy_sigma, 443.89204545454544 Hz)`. Preserve all
   incumbent effective scales exactly as in variant2. This isolates a conservative
   engineering floor sensitivity, not a calibrated error distribution or complete
   donor-error covariance. Keep the same constant discovery sigma and physical
   priors. Explicitly activate the existing per-ID override with
   `extra_parameter_BIC_gain=1` and a `research_override` label so a false BIC
   branch does not silently ignore the floor. The value1is an override switch,
   not a newly measured BIC gain.

The original FFT spacing is443.892Hz; an idealized uniform-bin sigma would be
128.141Hz, which is not calibrated here. A full-bin floor is deliberately more
conservative. Donor-origin dependence remains a limitation even with that floor.
Do not describe the floor variant as statistically independent precise Doppler.
If a large movement appears only after global incumbent reweighting, a later
fixed-incumbent-scale diagnostic may be justified; it is not an automatic fourth
variant in this lean initial comparison.
