# Downstream reconstruction review before new RF outcomes

Root review, 2026-10-26. This records a possible integration route, not a ready candidate or completed position run.

The original preparation path is `tools/prepare_algo02_ds23.py:prepare` -> `tools/evaluate_ds23_phase_refreshed.py:prepare`. It converts the immutable exported tracking document into observation rows, runs `graph_rf_lanes`, learns the existing radio-noise proxy from polynomial residuals, constructs a causal ephemeris bank, and prepares the causal orbital/phase prior. `tools/algo02_scan.py` then performs regional discovery and ALGO02 fitting; the frozen DS25 engine adds signed phase means and equal-prior family cavity selection.

New research detections must not be inserted into the historical production tracking export and mislabeled as original public measurements. Preserve that export and receipt unchanged. Stage a separately versioned observation ledger with provenance, then call the existing graph's row interface on the original plus qualified new native owners. Rebuild graph tracks and any observation-dependent radio-noise inputs. A new observation can alter track joins and therefore satellite association; attaching it directly to a known family is not an end-to-end test.

The existing bank contains propagated regional causal catalogue states, not only the accepted satellites. Reuse may be valid if the complete candidate inventory and causal provenance are identical and its time grid covers every new track plus the original phase search margins. Check those conditions explicitly. A bank whose temporal/candidate support differs must be regenerated. Keep c arms on the same bank, graph observations, candidate set and search budget. Existing causal history and phase-prior files are independent of newly recovered target scores but require their ordinary source/cutoff validation.

Important interpretive limit: `ds23_radio_noise.estimate` learns a proxy from curved graph residuals and GLRT margins. It is already labeled an uncertainty proxy, not a calibrated error bar. A timing-search-selected margin has selection conditioning that must remain explicit. Relearning this model can change weights on old observations as well as new ones. Report whether a position change comes with such reweighting; an exploratory fixed-existing-precision comparison can isolate the contribution of added evidence if needed, with matched c arms. Do not claim that an uncalibrated margin proves a physical covariance.

A sparse target panel cannot itself guarantee a new curved track. If a proposed extension survives raw support controls, freeze a small consecutive-visit expansion policy before opening additional target samples. Preserve native IDs and donor dependence, then test the original graph support/curvature and causal all-catalogue association gates. If none survives, the evidence should locate that obstruction rather than claim an unperformed geographic result.

Archived baseline endpoints are not substitutes for matched fresh search budgets when comparing a changed full pipeline. Any regional run must retain capped/unavailable outcomes and compare an unchanged control executed under the same new bounded budget, or explain precisely why reconstruction is exact and no search comparison is claimed.
