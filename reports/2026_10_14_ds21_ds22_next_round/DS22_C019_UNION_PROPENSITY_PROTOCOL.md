# DS22-019: propensity qualification and bounded profile/release control

The completed 67-satellite coverage experiment and exact conditional-density replay leave the training-selected geography far from the configured reference. This new control tests the native satellite-selection propensity model on the actual expanded bank. It does not reuse the old 36-satellite qualification or assume that better training likelihood improves position.

Four source states are fixed by the minimum accepted training objective within each native-model × source-group pair: no-clock original ordinal 0, no-clock coarse ordinal 16, common-clock original ordinal 0, and common-clock coarse ordinal 12. Every source retains its complete physical, timing and nuisance state and its original geographic disk. Original-source disks have radius 25 km; coarse-source disks have radius 100√2 km. No state or domain is selected using reference distance.

Each independent qualification reconstructs the exact original native model on all 67 satellites. It performs at most 139 objective evaluations, zero fits: original, legacy wrapper, conditional wrapper, zero-propensity wrapper, nonzero-propensity wrapper; central finite differences on all 66 orthonormal propensity coordinates; and independent conditional/zero-propensity full-domain audits. Finite-difference step is 1e-4 at theta=0.1*cos(index). Checks cover original objective/NLL and all gradients, posteriors and dense prediction gradients, exact normalization correction, shared-coordinate zero-tail nesting, theta gradient chain and prior, feasibility, and absence of initializer projection. Bounds are ±2, prior standard deviation 1 and scaling 0.5, with all original calibration/timing/clock priors unchanged. Each unit is bounded to 180 seconds, TERM195/KILL200. A failure remains a failed attempt; no automatic retry is permitted.

Only after all four qualifications pass will a separately source-frozen numerical driver run one fixed-geography propensity profile from each exact source state with zero added propensity. Every profile has 60 seconds and 600 iterations. All four profiles must terminate before any free release. Only accepted profiles may produce one complete-state free release under the same original disk and same 60-second/600-iteration cap. Thus this control adds four profiles and at most four releases. Strict full coupled KKT remains 0.001; no threshold is relaxed.

The zero-tail conditional source is a feasible objective bound. It is not automatically a stationary expanded-model incumbent: propensity gradients generally are nonzero. Only independently strict accepted expanded states can be selected. An accepted expanded winner worse than a feasible zero-tail source is explicitly incomplete search, not improvement. Conditional incumbents and expanded free-release selectors are reported separately. All four profile outcomes and all accepted-source release outcomes must be sealed before any configured-reference join.

There are no held/locked accesses or predictive claims. This is conditional development using full-data discovery and existing training states; later fold prediction is required before any model promotion. DS22 station continuity remains unconfirmed. Historical half fits do not become matched controls merely because they share the recording.
