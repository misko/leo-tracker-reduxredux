# DS22 A full-prior coverage and matched timing handoff

This development experiment retains original sequential A and fitted c. It changes the candidate/search inventory and compares two final timing initializations within that common inventory. It does not free A's learned band shift or substitute Model B.

DS22-059 has a fixed 75-satellite union; DS22-105 has 92. Each union contains the original model bank and every candidate from all sixteen original 100 km coarse discovery cells. The start inventory contains all six genuine original A starts plus every cell in the Cartesian grid {-150,-50,50,150} km squared. Original starts retain their 25 km disks. Coarse starts receive radius 100 sqrt(2) km. The original 250 km global prior disk remains active for every call. Every coordinate in [-250,250] is at most 100 km from its nearest grid coordinate, proving that the coarse disks cover the entire prior bounding square and hence the prior disk. No configured position, score filter, or chosen quadrant selects cells or banks.

The accepted original full-view coarse fit supplies each added physical correction/timing function. Its restriction to each original half-view frame must close numerically before fitting. All original satellite shifts are retained by catalogue identity; added satellites receive that source's common shift. The original shared-seed projection port converts physical functions, rather than reinterpreting centered coefficients. Original view frames, observations, clock nodes, priors, and native orbit arrays remain unchanged. The rejected original DS22-105 high-view coarse fit is retained in the source inventory; the accepted full-view coarse function supplies that cell, rather than retrying the rejected half fit. A's unused full shape donor comes from the transported low common function. Final geography, common calibration, clock and timing are overwritten by the declared stage handoff as in original A.

For every start, fit a fresh low stage and original geography-locked high stage on the union. Require strict independent stationarity <=0.001 at each prerequisite. If accepted, construct one common final objective with that path's learned receiver high-minus-low offsets frozen. Both final seeds use the low geography and transported complete low common calibration/clock function. The original method uses high-stage satellite timings; the matched method restores low-stage satellite timings. Fit both without selecting between methods by configured accuracy. A failed prerequisite prevents both final calls; every attempted failure is retained without retry.

Each call uses unchanged original SLSQP, fitted c, 20 seconds, 600 iterations, and a new explicit 600 actual objective-evaluation ceiling. Reserve one evaluation for independent endpoint J/NLL/domain/projected-KKT replay: the optimizer wrapper permits at most 599 calls. This actual cap is tighter than historical iteration-only runners and applies equally to both methods. No accepted endpoint is grandfathered across a changed union. The inherited fitter's at-most-1e-8-second timing margin normalization is explicitly measured; other initializer projection is forbidden.

There are at most four unique optimizer calls per path: low, high, original final, and restored-low-timing final. Each method has three scientific calls with the first two shared. Thus 22 starts times four calls equals at most 88 new calls per case, 176 for the pair. No old-bank fitted endpoint counts as a new union fit. Run separate bounded case waves with at most six single-thread workers. Each path has 165 seconds internally, 180-second TERM and 185-second KILL bounds, including preparation bounded at 60 seconds. Qualification has 120 seconds and zero optimizer calls.

Qualify all 66 initializers per case, exact physical correction transport, all candidate identities/timings, original/global/local feasibility and finite full gradients before any fit. Preserve all original stages, failures, sources and new receipts. Seal every path in both cases and each method's original-six and covered-twenty-two training selectors before reference joins. Rank only within a declared method and fixed union objective; never compare MAP across original and union banks. Path-specific frozen learned shifts are part of original A's selector, not a common generative calibration model. Report frequency NLL, prior, eligibility and configured position errors separately; configured DS22 station continuity remains unconfirmed.
