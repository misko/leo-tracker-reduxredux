# C019 60-second control: explicit zero-objective guard recovery

The first 60-second wave preserved both original SLSQP repeat outcomes (13/22 objectives, still nonstationary). Its two Newton units failed before any objective evaluation: the reused immutable numerical core rejected a requested time allowance above 20 seconds. The wrapper tests mocked the core and failed to catch this integration defect. These are pre-objective guard failures, distinct from the earlier 20-second Hessian timeouts after 267/272 actual evaluations.

This separate recovery changes only the numerical core's maximum permitted time argument from 20 to 60 seconds; its Newton/Hessian/PD, feasibility, stationarity, line search, and 600-call math are unchanged. A real integration test reproduces the old zero-call failure, executes the new unmocked PD step, rejects time above60, and compares the complete mathematical result to the old core at20 seconds. The frozen first wave and both completed repeats remain immutable and pinned.

Only the two never-evaluated Newton calls are issued in this namespace, from the exact original rejected profile states. The two completed repeat outcomes are reused by exact receipt validation and cannot be rerun. The same fixed geography, own domains, native likelihood, all priors, 60-second/600-actual-call cap including terminal replay and strict KKT apply. Four-objective actual qualification precedes these two calls. All four combined outcomes must be available before any accepted-only free continuation under the already declared60-second/600-iteration budget. Global sealing includes exact original repeat receipts, failed guard receipts, recovered calls and free/skip outcomes before reference reporting. No threshold relaxation, retries of evaluated Newton work, or held/locked inference is introduced.
