# C053 satellite frequency-offset conditional development comparison

This pilot tests whether a satellite-common frequency offset explains measurements across time better than the existing receiver-clock and satellite-timing model alone. It does not identify fitted corrections as transmitter clocks or ephemeris errors.

The fixed design is eight optimizer calls: two alternating 20-second training folds, two fixed training-derived positions, and two models. Positions are the current second-anchor-cycle training winner and that cycle's high-band position after a fixed-position full-likelihood nuisance profile. Both use the current full winner's common non-position physical state and nuisance initialization. These positions are chosen by their training roles, not reference proximity. Original 50 km disk, bank, native branches, timing priors, receiver-clock prior, calibration frame and fitted c remain unchanged.

The baseline is the existing singleton native-clock C likelihood. The extension adds a constant-Hz correction per satellite shared across all receiver/channel/native-time rows. It uses an orthonormal zero-sum catalogue basis, independent coefficient prior sigma 50 Hz, coefficient bounds ±2000 Hz and fitter scale 50 Hz. The 50 Hz prior follows existing `hard60_satellite_correction.py`; bounds/scales follow its original generic clock fitting convention. These are prespecified rather than tuned against position truth or pilot results. All new coefficients start at zero. The exact original model must be recovered there. Timing priors are retained, so any redistribution between timing and frequency-offset penalty must be reported separately.

Only original training windows are split, by `floor(time_s / 20) % 2`. Singleton-family likelihood and gradients from excluded windows contribute zero. All physical/calibration parameters and new offsets fit only the selected fold. Full-derived discovery, metadata, clock nodes, initializers and fixed positions remain in use: this is conditional development cross-validation with information leakage through those fixed inputs, not untouched validation. Original held and locked data are not read.

Each call has 20 seconds and 600 iterations. Use the original fitter, exact fixed XY, original disk and projected KKT threshold 0.001; no retries or failed-fit fallback. Each fold is a four-call unit bounded to 180 seconds, with at least 30 seconds remaining before admitting a fit. At most two workers may be used within the global worker ceiling. All eight outcomes, including failures, must be sealed before opposite-fold prediction. Missing accepted outcomes leave comparisons incomplete.

First qualify real-data source replay, zero-tail objective/gradient/posterior closure on full and both fitting folds, and nonzero offset derivatives. Component tests also check every physical/clock/group/offset derivative, exclusion of withheld native branch measurements, original fitter metadata and unchanged fixed positions. Qualification runs zero fits in a separate frozen namespace.

Predictive reporting must keep raw likelihood NLL separate from all priors. Report both original native emission NLL and its visibility-support-normalized diagnostic, because native emission mass can be below one. Include per-band/window-block scores, timing/clock/group/offset prior components, physical satellite offsets and accepted status. Do not infer better localization from lower training NLL or promote a new model from this pilot alone. Any free-position evaluation requires a subsequent explicit matched experiment and post-seal reference evaluation.

Implementation `ddbba146d` passed eight component tests and Ruff. No pilot fit had run when this protocol was written.
