# C075 matched native coverage pilot: 44 prespecified fits

The same fixed 87-satellite union is used for both original-no-clock native C and native C with common receiver clocks. Each arm uses all sixteen original coarse-grid starts plus all six recorded original native endpoints: 22 starts per model, 44 new fits total. These inventories are fixed before fitting and do not use configured position errors. No propensity coefficients are fitted.

Only original endpoint starts 2 and 4 were accepted. Starts 0, 1, 3 and 5 were nonstationary (KKT 0.002879, 80.361, 0.002758 and 0.002757 respectively). All six are initializer-only controls in this explicit new-bank experiment; original failed outcomes remain failed, and no endpoint gains selector eligibility without a new accepted union-model fit. The initial pre-freeze guard incorrectly assumed all six accepted and stopped before creating a namespace or numerical call; that assumption was corrected before freezing.

Original six controls retain their original own 25 km disks. Their exact native receiver offsets are preserved, with no second alias lift; added satellite timings receive the source mean. Their clock extension begins at zero. Shared `native_coverage_control.qualify` performs four objectives and two explicit orbit predictions per control, no numerical calibration projection. It verifies source replay, common satellite ephemerides/derivatives, native-time calibration identity, and exact zero-clock objective/NLL/physical-gradient/group-gradient/posterior nesting. The only declared canonicalization is the existing fitter's inward timing margin, at most 1.1 ns in absolute satellite shifts. Geography/calibration are untouched and both paired starts must then be initializer-stable.

Each coarse start uses its original grid center and a geometry-derived radius 100 sqrt(2) km. Its paired projected/complete-clock states come from completed coverage qualification `20621912f`: identical union, satellite timing and source-derived receiver alias integers. Projection residuals are retained; the complete clock arm preserves source function. The 250 km original regional prior remains active. This changes search coverage and candidate bank relative to the original cohort, not only model clocks.

Each fit uses fitted c, nominal 20 seconds, 600 iterations, original priors and strict independent KKT acceptance at 0.001. One unit runs the two model arms for a single start, under 120-second internal / 135-second TERM / 140-second KILL bounds. Up to six single-thread units run concurrently, subject to the research-wide 16-worker limit while other services consume cores. Each call records CPU and wall time. Failures remain ineligible and are never retried automatically.

Within each model, report both the accepted original-six selector and the accepted all-22 selector, minimizing training objective then start ordinal. Their six endpoint inputs are not automatically eligible after changing bank: eligibility requires acceptance of the new matched fit. The all-22 inventory contains the same six actual fitted outcomes, so its training selector is a nested search comparison. Never compare raw objective magnitudes across different model arms as evidence of accuracy.

All 44 returned call receipts, source states, model/domain options, durable claims, raw fits and row files must validate before the global seal. Configured-reference reporting follows only after this seal; unavailable arms remain unavailable. Historical original halves have different banks/search domains and are context only. No held or locked observations are used, and no claim of verified station accuracy or cohort promotion is authorized by this pilot.
