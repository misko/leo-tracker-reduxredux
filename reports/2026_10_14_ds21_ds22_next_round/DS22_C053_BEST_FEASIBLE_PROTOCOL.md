# C053 fixed-geography matched solver control

The preceding LOW-to-full fixed profile selected a strict stationary trajectory point with objective55704.856 despite a feasible initializer50365.839. This experiment tests numerical search policy without adding statistical parameters, changing geography, choosing a reference-derived start, or relaxing acceptance.

Two arms use the identical qualified complete LOW-to-full state, original full native model, fixed geography, original25 km disk, and all original physical/nuisance bounds and priors. Both have a single shared60 second budget and600 total SLSQP iterations. Five seconds are reserved within that budget for strict-pool selection and independent objective/gradient/KKT audits. Arm0 runs uninterrupted until the55 second optimization deadline. Arm1 runs at most30 seconds/300 iterations, then starts from the minimum-objective feasible recorded complete state with only the remaining shared optimization time and remaining iterations. If phase1 finishes early, the overall deadline does not move. No more than three SLSQP invocations occur across the two arms.

The private native port uses the same `_Problem`, parameterization, bounds, constraint Jacobian, analytic gradient, SLSQP ftol and strict stationary-pool criterion as the original fitter. SciPy callbacks record completed iterations across phases. Every actual objective invocation is counted, including independent audits;600 is an iteration cap, not an objective cap. The minimum feasible state is preserved separately and never automatically accepted. Deadline exhaustion during the audit leaves no accepted result. Fixed geography is checked exactly; both qualified starts and independent endpoints retain the original domain.

Each arm has two explicit native oracle objective calls before optimization, verifying objective, full physical/nuisance gradients, NLL, prior, responsibilities and exact fixed geography. Component tests exercise actual native functions and a real SLSQP execution, as well as restart accounting. The original source and prior failed receipts remain immutable.

At most two single-thread workers run. Units use180 second internal and195/200 second external TERM/KILL bounds. Both outcomes seal before any further decision. This numerical control reads no reference or held evidence, performs no free-geography release, and makes no accuracy claim. A further release requires separate review.
