# Standalone shared fast-scan inference adapter

Commit `232ab808f` supplies `python -m leo.cli.shared_fast_position --input PATH --output FRESH_PATH --maximum-seconds 1200`, model version `shared-scan-q-v1`. It accepts the existing exported public TrackingInput document, reconstructs its recorded UTC authority, uses the supplied causal TLE archive and the existing declared 250 km regional prior, and produces a separately versioned terminal result. It accepts no configured reference, DS label, cohort inventory, saved fit or accuracy target. Fitted c is the only arm.

The mathematical shared objective is the exact compact-quintic smooth horizon v2 selected-singleton density with learned shared satellite detection probabilities. The transition width is the existing numerical regularization 1e-5, not a hardware uncertainty claim. Signal and density-normalizer derivatives, satellite timing, receiver calibration, common clock, q prior and the once-only frozen receiver-band contrast prior are preserved. The extracted component imports only components within this repository, never the reference repositories or research tool runners.

The production initializer is explicitly new: `generic-cold24-shape3-fresh-six-ab-v1`. It runs bounded public cold discovery (24 points / 240 seconds), one declared training-best cold shape initializer per view (three 20-second shape calls), fresh bootstraps at three cold and three shape geographies, then the original A sequential low/high/final architecture and joint B architecture on the same bootstrap candidate union. A missing shape or bootstrap is a recorded unavailable source, not a fabricated replacement. A stopped discovery ranks only completed durable points with the original separation rule. It does not retry incomplete points.

The six potential A sources retain their own learned frozen shifts and 25 km disks; B uses the six corresponding complete joint initializers. The minimum full zero-q A score plus the genuine joint B training winner supplies the same two sources used by the capped shared policy. Both shared calls are fresh. Selection uses only the lowest objective among new independently strict accepted endpoints. Original A/B states are initializers, not shared-q estimates or incumbents.

This production search is **not the completed DS21/DS22 initialization recipe**: point budget, shape-start inventory and full available inference observations differ. No development median or accuracy promise transfers to this deployment. The production high stage preserves the original sequential architecture's satellite-timing freedom; it is not the later locked-high prototype.

The whole attempt is bounded to 1,200 seconds, with durable exclusive stage launches/results and no automatic failed retry. Source admission preserves 40 seconds for both final shared calls. Every counted A/B/shared fit uses 15 seconds for the original fitter, an independent strict audit within 20 seconds total, 600 iterations and at most 2,000 actual objectives. KKT stays at 0.001. No accepted endpoint is invented from an unreturned fit. A path's failed final physical-function export is isolated so the independent B path and other starts can continue.

`terminal.json` binds the exact public input hash, version, session, original input/analysis manifests, preparation evidence, clock nodes, prior, causal TLE and candidate numbers. A complete result has finite `position` coordinates and an accepted `selection` with objective, NLL and strict stationarity. Unavailable/failed results have null position and selection. The output stores no configured-reference error. A failed or launch-only attempt remains separate from older legacy output.

Cost fields have an explicit scope: A/B/shared counted optimizer calls and objectives, separate source-prescreen objectives, and durable discovery/shape/bootstrap stage receipts. The original high-stage offset/timing diagnostic also performs an objective replay outside its fitter counter. These fields must not be described as an exact total of every upstream optimizer or diagnostic call. Unfinished stage launches are listed, and external termination does not fabricate their unknown numerical cost.
