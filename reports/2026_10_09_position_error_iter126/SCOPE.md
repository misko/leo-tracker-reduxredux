# Scope and source convention

This is an unexecuted, fixed-endpoint diagnostic. It creates no fit, new selected position, reference-based policy or covariance. Both c arms use the same twelve members and reconstruction as117. It compares the original likelihood before admitting an alternative frame model; failures remain receipts, not exclusions. Common timing remains a timestamp shift, relative timing becomes constant-rate orbital phase. Prior values are unchanged and cancel in the score difference. Reported temporal gradients are the frequency-likelihood data term only; discontinuous horizon gradients remain omitted explicitly, as in the original model.

Bank propagation is `regional_position_bank.build_regional_bank` → `adaptive_tle_prediction.propagate_candidate_states` → `sky.frames.teme_to_ecef`. The last implements Rz(-GMST) and the rotating-frame velocity correction minus omega cross position. Therefore Rz(+omega relative_shift) undoes only the relative Earth's rotation under the constant-rate approximation. It does not turn the approximation into an exact direct-SGP4 phase propagation. The native quarter-second bank interpolates position and velocity separately, and the helper preserves separate secants. Three pure synthetic tests validate zero-relative parity, actual frame-sign identity, timing derivatives and observer displacement off the equator.

The driver inherits117's immutable legacy loader provenance (archived error equality checks for source admission, never inference selection), full source closure, endpoint reconstruction and append-only result policy. It uses a512MiB conservative fixed array estimate, two shards and one BLAS thread per worker. No recording call has run; protocol below is a draft until parent review/publication.
