# SOL conditioned-CZT implementation

The qualified production revision is host v2 (`/var/tmp/leo-host-conditioned-czt-v2`) and ARM v3 (`/var/tmp/leo-arm-conditioned-czt-v3`). Both contain the same `full_search.c`, `conditioned_czt.c`, and `conditioned_czt.h`. Later v7 host builds change only tests and build receipts; they do not change the qualified executable sources.

The FP32 FFTW chirp-Z path screens every regular 100 Hz bin. It caches the input chirp, convolution kernel FFT, and FFTW plans by rate and template length. Frame energy and template energy remain in the original FP64 loops, the base-frequency modulation remains FP64 before conversion to interleaved FP32, and the existing `128 * FLT_EPSILON` near-maximum FP64 recheck and final FP64 GLRT remain unchanged. Irregular grids, unsupported bin counts, and allocation or FFTW-plan failures use the complete original screen.

`builds/host-tests-v7` and `builds/host-asan-v7` contain the build receipts, exact compiled source trees, test output, and SHA-256 manifests. The normal and ASAN/UBSAN runs cover all four rates at their actual template lengths (3333, 6667, 10000, and 13333), one and 41 bins, arbitrary base modulation, zero input, impulse, exact-bin coherent tone, a near tie, and unsupported-bin fallback. The maximum normalized error against FP64 was `2.5958999e-7`. Integration tests cover finite zero scores for zero data and zero template energy, the original irregular-grid fallback, and a 1550.001 Hz near tie whose top two bins fall within the guard, both receive FP64 rechecks, and produce the same final winner as the all-FP64 batch.

The revised 64-dwell saved-IQ cohort has no audit errors and matches all 1669 positive candidates. The 704-dwell cohort matches all 19581 positive candidates and reports one `ordered_field` difference against the older original oracle at `scan-fw-43e84176a367910b`, visit 693, receiver 0, probe 3. The selected scoped FP32-coarse/FFTW baseline already contains the corresponding negative-rank mismatch against that oracle, so this experiment does not claim universal byte equivalence to the older original implementation. The paired selected-baseline audit is the relevant inheritance check.
