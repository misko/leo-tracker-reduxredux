Use six disjoint frequency changes from twelve evenly spaced observation indices
per curved track. Pair sample indices 0–5 with 6, 8, 10, 7, 9, 11 respectively.
The different baselines sample different parts of a pass. Each observed endpoint
appears in one pair, so independent, equal-variance endpoint errors would give
independent difference errors with twice the endpoint variance. The 180 Hz
endpoint scale is a nominal study scale. Graph errors can be correlated.

Use at most the 64 longest curves and nominate up to twelve TLE satellite
hypotheses per track from all satellites visible at the sample times. Nomination
compares each observed frequency change with the satellite's expected change
modulo the detector's 1 / 4.4 μs CFO period, including an orbit-time prior of 2 s.
A 7 × 7 grid in the declared 25 km box votes with profiled track time shifts.
Four robust least-squares updates refine the position with grid associations held
fixed, a common shift per satellite, and a shared drift per receiver/side lane.
The linearized Doppler bank uses causal TLEs at 5 s knots. Position and detection
time are distinct parameters. The endpoint is a scan-end fix using archived
anonymous graph tracks through that scan's end. Bank linearization accuracy and
early-fix latency are outside this prototype.

Subtracting within a track annihilates a constant offset, including c times the
track's constant channel RF. The fitted-c arm has a zero data column for c and
the same objective, shortlist, associations and endpoint as c=0. It reports c
as unidentifiable. The matched level control keeps the same six changes and
nominees, adds the wrapped track mean as an observation, and fits four constant
lane offsets. It initializes each active lane's offset with a 73-point circular
grid and nine local offsets. Its two c arms use the same winning associations
and budgets. The fitted-c arm uses a zero-centered 200 kHz/GHz Gaussian scale.
Both methods report paired-change RMS. The control also reports absolute
track-mean RMS. RMS uses each method's fitted inlier track associations, which
can differ between the primary and the control.

Source inputs are the declared DS26 anonymous candidate track JSON and causal
TLE snapshots at the protocol paths. Archived graph tracks are conditional on
the recorded LNB reference hypotheses. Fits use only the current scan's
observations and causal orbit elements. The control estimates are available for
independent comparison against the held-out geography.
