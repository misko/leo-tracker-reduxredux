# Eight-scan development panel

The two-scan conditional geometry pilot passed its declared primary error gate.
Extend, without recalibration or model changes, to remaining indices
4, 8, 12, 20, 24, 28 of the existing uniformly spaced eight-scan panel. These
are development recordings previously examined for other methods, not a blind
external holdout. Verify exact 5MS/s and calibrated RF support before scoring.

Run the same Doppler, receiver-only, signed, swapped, permuted models and the
same numerical qualification and 90-second limits. Keep all failed cells in
denominators. Reuse the two sealed pilot results. No multi-start or reference
selection. Seal all training fits before scoring this extension geographically.
Require all eight signed and baseline fits qualified, at least six signed wins
against Doppler, median error reduction >=10%, and no worse P90 error. Compare
receiver-only and both negative controls explicitly. Only a passing extension
supports a separate broader confirmation; neither a failed extension nor a
single attractive scan supports promotion. No new orbit uncertainty is added.
