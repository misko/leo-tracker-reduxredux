# Two-scan marginalized-CFO position pilot

Scans0 and16 are fixed from the preceding numerical audits, not selected by
new geographic outcomes. Keep all retained candidates, visibility rules,
original causal banks, measurements, masks, timestamps, bounds and independent
Student-t4/100Hz errors. Integrate each candidate's CFO with its normalized
1MHz Gaussian prior using order32 quadrature. No candidate pruning or new data.

Four starts per scan: original IID endpoint plus(-2,0,0),(0,0,0),(2,0,0).
Use existing L-BFGS-B settings and qualification. Each of eight processes has
a90second cap; at most three single-thread workers. No retries. Audit endpoint
finite-difference gradients and order32/64 value agreement<1e-6 and gradient
agreement<1e-3 in addition to existing numerical gates. Save failures and
timeouts. Original endpoints' marginal scores must replay the benchmark.

Select the best qualified marginal training score independently in each scan;
seal both selections and all attempts before geographic scoring. Profile and
marginal scores are different objectives: never choose between them by score.
Report both baseline and marginal errors. Advancement to a wider screen
requires qualified outputs for both and lower error on both. This small exposed
pilot cannot establish generalized improvement. No held score is computed;
a later one must use joint/training integrals, not a training-fitted CFO.
