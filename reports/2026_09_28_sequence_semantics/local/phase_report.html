This is an algebraic representation of received patterns, not a decoded satellite ID, UTC or literal six-bit field.

Across fixed windows, 2,779 of 2,780 accepted window observations match the same model; one shorter DS window differs by one bit and is retained as a discrepancy. These windows overlap earlier evidence and are not independent trials. Multiple accepted UT windows in each of 338 frames agree exactly on the same word. Window position is not causing those word changes.

Chronological tests do not establish a counter or simple state recurrence. Applying the post-header phase correction to the early header does not reveal stable fields in this assay. The function of phase selection remains unknown; no user payload is decoded.
