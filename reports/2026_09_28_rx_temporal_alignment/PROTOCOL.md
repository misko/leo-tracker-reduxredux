# Frozen temporal alignment diagnostic

This descriptive follow-up uses the six calibration recordings already scored by
the frozen temporal-transfer experiment. It does not fit, select, or promote a
model, change nominations, or collect radio data.

Inputs are the original geometry-association dataset and completed temporal-transfer
results. Verify the previous evidence index before execution; bind input and
diagnostic source hashes in the launch receipt.

For each retained nominee and receiver, measure the nearest observed candidate's
periodic distance from its saved canonical frequency forecast. Use the lane's
alias period. Summarize the normalized retained-prior mass with a visible forecast
and a candidate within 500 Hz and 1500 Hz. Empty candidate sets contribute zero;
invisible nominees contribute zero without redistributing their prior mass.
These are descriptive alignment fractions, not calibrated identity probabilities.

Join the existing within-centered D and T model scores and posterior presence by
recording, lane, and source window. Preserve all calibration windows in both roles.
Summarize candidate counts, visible prior mass, alignment, presence, and predictive
scores by role and elapsed time from each lane's first reception window. Fixed
elapsed bins are [0,30), [30,60), [60,90), [90,120), [120,180), [180,infinity)
seconds. Average windows within each recording and then recordings equally;
report contributing recording and window counts for every group.

Run component tests before a bounded, single-thread execution (maximum 120 seconds).
Independently audit periodic distances, joins, and aggregation before interpreting
results. Report missing time-bin support explicitly. Role and elapsed time may be
confounded; an alignment decline does not identify its cause. Detector thresholds,
candidate populations, handoffs, forecast errors, and actual absence remain possible
explanations. These diagnostics do not establish satellite direction or identity.
