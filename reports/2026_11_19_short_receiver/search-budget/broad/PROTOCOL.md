# Broad first-ranked compact v5 qualification

Freeze the 127 DS26 and eight DS29 roof recordings used by the compact
projector. Read only the original audit's authenticated winning branch ranks
and the public frozen input bindings to choose the replay roster. For every
recording where the original best-of-three winner had a rank above zero,
measure `v5_first_ranked` from the full native GLRT observations through the
same compact projection and paired cavity decision. Reuse the exact
DS26-0036 run from the independently scheduled six-pair study. Keep all six
paired-study candidate attempts in the evidence with their original elapsed
times and run provenance.

Replay three additional rank-zero controls outside those six. Sort agreement
IDs by SHA-256 of the UTF-8 string `v5-first-ranked-broad-v1:` followed by the
case ID and take the first three. No geographic error or position endpoint
enters this selection. Use a single pinned CPU and the existing one-thread
worker environment for each run, with no more than six overlapping workers.
Use the standard runner's 600-second deadline per attempted candidate. Record
every failure and timeout and retain its reason and wall time.

For any remaining agreement, admit an earlier compact-projector position only
if the archive verifies the exact native data, causal catalogue, request,
component and scientific sources, and that its compact first-ranked start and
initial gate equal its chosen best-of-three start and gate. Original noncompact
winning rank alone cannot establish those equalities. When the archive lacks
that proof, retain an explicit unmeasured case and avoid assigning it a
candidate position, a success, or a timing. The original compact projector is
the paired stock comparison for the same recording in every group. Its archived
times remain archived. A failed fresh replay cannot inherit the stock outcome.

Seal prediction rows before loading geographic scores. Report both calibration
arms using identical candidate observations and budgets. Compare published
error, counts at 1, 2, 5 and 10 km, and matched position deltas against no-repair
v5 and compact projector. Report conditional RF RMS separately. Give the full
fixed roster and the separately measured disagreement, agreement-control and
timing groups with their denominators. Any position distribution on a subset
must communicate which recordings it describes. No RF is collected.
