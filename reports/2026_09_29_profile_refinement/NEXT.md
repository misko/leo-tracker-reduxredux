# Next investigation: transferable residual structure

Proposed, not executed here. Additional local starts mostly return to the same
inaccurate solutions, and the one better training solution increases reference
error. Do not repeat broad search grids without a new mechanism.

Before introducing an orbit/receiver hierarchy, inspect whether residual
structure repeats across independent recording groups. Use the existing
training-only candidate distributions rather than converting conditional MAP
assignments into asserted satellite identities. Any fitted correction must
transfer from donor recordings to disjoint target recordings, with the original
uncorrected model and RF/receiver-only alternatives on the same targets.

The first bounded step should census usable repeated candidate support across
records and review existing residual-transfer studies. Determine whether
uncertain satellite grouping carries information beyond receiver, RF and time
grouping. Record missing support explicitly; do not borrow across incompatible
catalogue snapshots using row number as identity. Catalogue row alignment must
be validated from authoritative snapshot metadata before cross-record pooling.

Only if that support exists should a training-only correction be frozen and
tested for held prediction, followed by geographic fitting on all eighteen
panels. A useful correction must improve short-set geographic performance
across DS7/DS8/DS9, not merely reduce frequency residuals. Avoid tuning against
the exposed location or selecting only favorable panels.

Independent satellite identity, orbit calibration, receiver pose and reference
survey remain unresolved. The earlier orbit-hierarchy gate's limitations still
apply. A support census cannot resolve these by itself. No new RF collection is
proposed, and no calibration measurement is claimed.
