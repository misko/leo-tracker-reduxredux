# Two discriminating next tests

This note follows the cumulative
[ambiguity/information review](https://github.com/misko/leo-tracker-reduxredux/blob/main/reports/2026_10_25_ds24_ambiguity_position/REVIEW.md)
and the completed [0015 conditioning contrast](FINDINGS.md). It proposes no
new run or operational change. The current cached position comparison and
single-window pilot-only detector control should finish before another branch.

The main new distinction is concrete: the 0015 physical pull survives full
parent conditioning, but the archive supplies no separate complete unused
owner with an explicit own 68904 nomination in the audited fields. That does
not make 68904 false. It prevents treating a target-trained correction as
independent corroboration. More covariance, more points or another optimizer
start does not remove this evidence gap.

1. **Carry known source identities through several detector windows and the
   actual graph constructor.** The current pilot-only control tests selection
   within a 20 ms window, including close sources and a chirp. It does not test
   whether the detector's winners and alternative peaks become a coherent
   single-source track over time. That transition is the measured unknown.
   Freeze a small sequence of original metadata timestamps and original
   detector/graph configurations; generate two known, smooth CFO trajectories
   with one crossing and fixed independent epochs/noise seeds. Preserve every
   returned peak and run the existing public graph port without injecting
   source labels or oracle associations. Include a separated-trajectory
   control with the same noise. Use the current continuous-time pilot law;
   retain its missing-payload/multipath limits and do not claim a full radio
   simulator. First verify the narrow graph input contract; stop if it cannot
   be reproduced within a fixed short budget, rather than expanding a campaign.

   Report pointwise CFO error, dropped points, source switches, and whether
   an accepted polynomial/track mixes the known identities. A smooth mixed
   track would demonstrate a specific mechanism that more orbit flexibility
   cannot authenticate. If ownership remains correct in the declared weak/
   crossing controls, close that tested mechanism; do not extrapolate to real
   multipath or all signal conditions. This differs from the earlier polynomial
   coverage comparisons and current single-window selection test because it
   scores **known identity continuity after peak selection**. No position fit
   is needed to decide whether that failure mechanism exists.

2. **Test whether the 0015 correction forecasts held observations, while
   keeping the identity claim unresolved.** A separate owner is unavailable
   in the audited archive. A cheap lower-level check can still distinguish
   persistent physical-model structure from an all-point fit: predeclare a
   chronological split of the same 29 IDs, predict the second block from the
   first, then reverse the split as a symmetric diagnostic. Retain every ID
   across the two folds; do not trim or choose the split from residuals. Fix
   68904 as the already selected *hypothesis*, with the full D-excluded parent,
   original Student/alias law and matched c arms. Compare the existing nominal
   model against the existing three-mode model, without changing prior widths
   or gates. The two portions are the same physical owner, so share its phase,
   modes and **one** source constant, and retain old-radio train/held covariance.
   No held CFO may set phase weights, aliases, noise or mode coefficients.
   Reuse bounded D-only phase/prediction machinery; if the fixed numerical
   check fails, mark the forecast unavailable without extending integration.

   The outcome is held conditional score and residual structure in Hz/z,
   not position accuracy or satellite truth. If both forecasting directions
   favor the same correction and remove held structure, the model has a more
   specific predictive role than the all-point RMS suggests; an actual
   independently nominated whole owner is still required before identity
   qualification. If the correction does not forecast, close this addition
   under the current source/model law rather than fitting positions from it.
   The archived polynomial block diagnostics test a different model; grouped
   new-family and CH5 whole-owner work already provide the shared-nuisance
   machinery, but do not establish this particular correction's held-data
   predictive behavior. Neither split is an independent validation set.

Any resulting position policy still needs a frozen no-addition fallback,
matched c=0/fitted-c controls and an exposure-audited later recording block.
All current DS24 and eight RX1V outcomes are development evidence. A recording
outside those lists is not automatically an untouched benchmark; inspect
exact recording identity and geographic-use provenance before opening errors.
