# Can the current identity code support a complete nomination test?

Yes for a bounded conditional falsification test, after a small input-separation
adapter; the current executable is not already an end-to-end simulator or
calibrated identity decision rule. This note proposes no search or execution.

The reusable numerical pieces are in
`/srv/bulk/leo/research/ds24-identity-components-r01/identity/challenge.py`:
`conditional_costs`, `score`, `null_score`, `adaptive`, `alias_diagnostics`, and
the complete-catalogue Gaussian `coarse_phase_scores` call inside `screen`.
They provide matched finite alias mixtures, nonlinear causal phase integration,
physical covariance, common parent conditioning and a proper unresolved-curve
comparator. `exact_job` applies the union cavity after shortlist discovery.
The latest experiment froze at most eight candidates from 1,405–1,487 causal
entries; it did not establish that the shortlist preserves all relevant mass.

The present `screen` hard-loads real target values and saved parents, always
includes the archived nominee, and explicitly reserves 0012/66259. The 0013
witness list was historically selected under the assigned 60108 label. Those
are useful real-data diagnostics, but they must not become hidden truth or
witness-selection oracles in a synthetic nomination test. Inject the complete
synthetic observation context through a new study-owned adapter, rather than
editing production or replacing only the final candidate score.

A discriminating protocol should freeze the entire causal catalogue and native
source/time/RF/noise design before generating observations. Choose generating
identities from a response-free, visibility-qualified subset with a recorded
random seed, and include an explicitly generated unresolved-curve condition.
The algorithm must receive the same observation fields as for real data, not
the true identity, phase, physical coefficients or which outcome was generated.
If an incumbent is supplied, generate that initializer by the normal nomination
procedure; do not force either the true identity or a convenient wrong identity
into the final shortlist. A separate declared regression control may preserve
the real 0011 and 0012 candidate pairs, but cannot stand in for this test.

Run the original full-catalogue screen for every generated recording, freeze
the resulting pool, then perform the unchanged symmetric alias/cavity/null
comparison. A true identity omitted by the screen is a nomination failure, not
a reason to backfill it. A false winner, null winner, blocked prior, visibility
failure and numerical failure are all retained. For a whole-owner challenge,
define discovery and witness channels/times using metadata before drawing or
examining either owner's CFO. Do not select a witness because an archived or
new fit assigned it the simulated label.

There is a material parent-generation issue: the shared radio posterior is
currently reconstructed from real, label-conditioned calibration. Simulating
only a new target against that frozen posterior is a **conditional prediction
test**, not closure of the entire association pipeline. It may still falsify
the score or shortlist, but must state that scope. Full closure requires
generating parent observations and rerunning their unchanged inference and
selection too. Holding out the true family only because the simulator knows it
would give the estimator privileged information. A fixed response-free cavity
for all generating possibilities is possible only if enough independent parent
calibration survives; otherwise the fully synthetic parent is necessary.

Report true-label shortlist recall, rank among exact candidates, unknown versus
physical density, candidate gaps, alias/phase numerical qualification, and
native ownership. Without a preregistered and separately calibrated identity
decision rule, report ranks and failure rates rather than invented false-accept
probabilities. The declared broad polynomial null is not empirical clutter or
an IQ-level false-peak simulator. Avoid claiming full SBC or real-data identity
validation from this conditional test.

A small first pilot can reuse a fixed metadata-defined source panel and a few
seeded known-label/null draws, matched across c arms and fixed artificial
positions, with the same 600-second cap and no position fits. Nomination and
reference-integration costs belong inside that cap. If generating matching
parent data or a response-free witness is unavailable, publish that explicit
scope limitation rather than substituting handpicked incorrect labels.
