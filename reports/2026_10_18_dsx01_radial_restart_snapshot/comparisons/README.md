# Original and independent-start 10 km plots

Both plot types use the same regional center (37.906°, −122.545°), 10 km plotting radius, and 25 × 25 km localization bounds. Every figure shows c = 0 and fitted c. GPS markers are post-fit evaluation only.

**Original:** conditional position loss with a selected satellite/alias hypothesis. **New:** separate discovery, association, calibration, and localization from each starting position, using cached GLRT measurements and graph tracks. The new plots are convergence samples; their colors are not probabilities. Restart counts indicate exactly what has completed; partial and pending entries will update as the numerical campaign advances.
