# Artifact and replay limits

This report preserves the new scientific code, protocols, owned tests, saved
outputs, independent audits, witness inventories, geometry inputs and figures.
`publication_manifest.json` records each published payload's original path,
byte size and SHA256. Files are copied byte-for-byte; failed attempts, partial
checkpoints and superseded reports remain provenance. The final narrative uses
`scientific/report03/`, `audit/terminal02.json` and `witness/availability02.png`.

The [scientific replay guide](scientific/REPLAY.md) gives the original environment
and owned-test command. Numerical replay additionally requires the original
saved observation/cavity arrays, shortlists, causal banks and repository sources
bound by [scientific/protocol.json](scientific/protocol.json). Those historical
inputs are not duplicated here. Their prior experiment is documented in the
[nomination/information report](https://github.com/misko/leo-tracker-reduxredux/tree/79f8bc300848c930e1a2879f8e268362cd97f232/reports/2026_10_25_ds24_nomination_information).
This compact report is not a standalone scientific-input or runtime closure.

The witness metadata branch requires the original canonical graph/native-owner
and accepted-ID inputs bound by its protocols. It uses no CFO scores or new
position inference. The geometry branch includes the sliced nominal bank and
fixed RF observer in `witness/geometry_input.npz`, its exact support-port source
snapshot, source hashes and results. Its tests cover the support calculation;
its certificates concern nominal-bank visibility, not uncertainty over physical
orbit modes or a calibrated detection process. See the [geometry protocol](witness/geometry_protocol.json)
and [geometry findings](witness/GEOMETRY_FINDINGS.md).

Original absolute paths in protocols, source, seals and historical review notes
identify the source environment. Review-note links to other local studies
remain provenance references; the main report links the published review.
Restoring these report bytes verifies the saved evidence, not a successful
numerical rerun on a different environment. Scientific runners enforce the
original freezes and deadlines and must not be rerun over these immutable
outputs. No additional run is part of this publication.
